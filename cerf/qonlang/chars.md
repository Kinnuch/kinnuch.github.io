# 字符面板

[← 指南目录](/cerf/qonlang/) · 导航栏左下角的键盘图标，或任意文本框里按 `Ctrl+I`

字符面板是一个浮动窗口（可拖动、可缩放），点一个符号就插入到**最后聚焦的输入框**的光标处，不打断输入。任何页面都能用。

## 1. 页签

| 页签 | 内容 |
|---|---|
| 肺部辅音 | 按部位 × 方式的 IPA 表 |
| 非肺部音 | 搭嘴音、内爆音、挤喉音 |
| 元音 | 元音图 + 其他元音 |
| 附标 | 全部 IPA 附标（显示为 ◌̥ 形式） |
| 超音段 | 长音、重音、音节界等 |
| 声调 | 声调字母与曲拱符号 |
| 符号 | 其他常用符号 |
| 拉丁扩展 | 常见带变音的拉丁字母 |
| 组合 | 见下 |
| 最近 / 收藏 | 最近插入过的；右键任意符号可收藏 |
| 项目字符 | 当前语言的**音位**和各套**文字的字形**，字形按该文字的字体显示 |

顶部搜索框可按名称或特征搜（「卷舌」「nasal」「voiced」）。悬停符号显示名称与码位。

## 2. 组合区

选一个基字，再依次点附标，预览区实时显示叠加结果；可以叠多个附标。「规范化」开关决定输出是否做 NFC 合成（能合成的预组字符会合成，如 `e` + `́` → `é`）。满意后「插入」或「复制」。

## 3. 提示

- 面板打开时点击不会让输入框失焦，可以连续插入。
- 在皮肤里给「语言数据」槽选一款 IPA 覆盖完整的字体（Charis SIL / Gentium Plus），附标叠加才显示正确。
