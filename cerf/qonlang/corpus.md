# 语料

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/corpus/) · 导航栏第八项

语料页收例句，并给每个词自动做**行间 gloss**（interlinear gloss）。三个子页：**例句**、**统计**、**缩写表**。

## 1. 例句卡片

列表里每句一张卡：文字行（若定义了文字；文字的转写来源是检视器模块时逐词查词库写，见[文字](/cerf/qonlang/script/)）、原文（照写的样子显示，标点、空格都在，词可以逐个悬停 / 点击）、gloss 行（全部确认后才出现）、译文、出处与标签、已确认计数徽章。卡片按住拖到另一张上，松手就换到那个位置。点卡片在上方展开**行间编辑器**，检视器里编辑原文、译文（多语言）、其他正字法写法、出处、标签、自由行（任意标签 + 文本，会进入导出）、备注，以及导出面板。

**查重合并**：标题旁的「查重合并」找出当前语言里原文相同或相近（≥80%）的例句。只差出处的直接合并，出处写成「A & B」；相近但不完全一样的（或译文冲突的）弹窗列出来，勾选要合并的。合并时保留上面那条的原文与分析，译文、标签、自由行补缺。

### 译文工作台 {#workbench}

意思有了、原文还没想好怎么写的时候，可以从译文倒着组句：

1. 新增一句例句（或选中一句），在检视器「译文」旁点「工作台」，左边整块换成工作台。
2. 在中间写译文（写进当前界面语言那一栏）。软件按译文去词库里找可能用到的词——比对词条的义项和语素的意义，汉字这类不分词的文字按字串找，拼音文字按词找；语料和短语里译文带着同一个意思、原文又用过这个词的，会优先挑它——以泡泡浮在下面。译文里在词库、语素表中都没有对上的部分，会列在译文框下面（「这些部分没有找到对应的词」），一段一个按钮：点击即可跳到词库新建一个词条，释义已经填好那一段；填完点击「返回上一页」回到工作台，刚才拼好的内容都还在（从别的模块切回来也一样）。有的意思是靠构形表达的（比如用位格表示「在…里」），这时不必新建。
3. 把要的词拖到上面一行，或点一下接在末尾；「全部按顺序添加」把下面的一次全接上。上面一行里拖动可以调顺序，每个词下面写着它的 gloss。词库里没有的词，在「词库中没有？直接输入」里写好按回车（写的正好是某个词头或存下来的屈折形时，会自动挂上那个词条；不是的话，可以在附着台上挑它算作哪个词类，就能按那个词类的构形变化）。泡泡里的语素（前缀、后缀这类）拖到哪个词上就贴在哪个词上。
4. 点上面的某个词，下面展开**附着台**，给它挑形式、加时体态式这些东西（见下）。
5. 点「添加到语料」。选中的那句原文还空着就填进去，不然在最上面新加一句；挑定的词连同拼好的各段直接确认挂好，不用再逐词核对。点「取消」回到列表，什么都不改。

#### 附着台：给词挑形式、加东西 {#bench-attach}

最上面写着点中的词是什么词类（手打的词在这里挑），下面按类列出能跟它搭的东西。每一类一种颜色，上面词块里对应的那一段也是这个颜色：

- **构形**：这个词自己的构形，每个维度一排（数、格、焦点……），每个取值下面写着挑了会是什么形式；「用原形」回到词头。
- **由「某词类」表达**：有的维度写明了能给这个词类用（「词类与维度」里维度的「适用词类」），这个词自己的构形里却没有，而是在另一个词类的构形里——比如动词的式、体、时放在「动词头」上。这时把那个构形也摆出来，挑好的那一截贴在词上（推出来的形式以「·」这类连接符结尾的贴在前面）。
- **可以附着的成分**：前缀、后缀、中缀、环缀、附着词、小品词，还有词库里的虚词——词类名叫小品词、介词、量词、标记、缀这类的，它的词都算；别的词类只算释义说得出是哪个范畴的标记（「完成体标记」「工具格缀」这种）。分组先看项目自己的维度——语素的语法特征、标签就叫维度名、gloss 对得上维度取值——对不上再按莱比锡缩写（和项目缩写表里写的名字）归到时、体、式、态、否定、数、格……，再不行按标签、按语素类型。点一下就加上，再点一下去掉；单独成词的（虚线框）放在词前还是词后，也看语料里它惯常挨着哪一边；隔开写的（`ne…pas`）前一段放在词前、后一段放在词后。

  摆的先后：语料和短语里跟这类词一起用过的、维度的「适用词类」写着这类词的，排在各组前面。语料里分析得还少时，会照项目的结构推测——这个词类的构形用到哪些维度、维度的「适用词类」、词类名（名词、动词这类叫法），大致给名词这一类的配数、格、限定，给动词这一类的配时、体、式；什么线索都没有就先全部摆出来。推测的颜色淡一些。每一组先摆有根据的，其余点击「+N」展开；看着是给别的词类用的，收在「其余」里。
- **作用于所有词**：词首音变、连读变化这类构形，整个词最后过一遍。

中间那条色块是拼出来的样子：一段一段写着写法和 gloss，附加的几段可以拖着换先后、点 × 去掉。几个前缀谁在外层，按语料里它们离词干有多远自动排好。

附着台太高、挡住下面的译文和泡泡时，点击右上角的「收起」即可收成一行（只留词类、词和释义）；换一个词、跳到别的模块再回来都还收着，点击「展开」恢复。

## 2. 自动分析

选中一句还没分析过的例句时自动分析；也可点「自动分析」（只补未确认的词）或「重新分析全部」。

每个词先看**已确认的分析**：项目里其他句子中同一个词已确认过的分析排第一。然后把整个词切成几块，每一块从这些地方找：

1. **词头**：词库里的词位。
2. **屈折形**：词条存下来的 forms（gloss 会带上槽位的缩写，如 `房子.PL`）。词条没点过「推导」时，构形里只加前后缀、重叠这类不跑音变的槽位也会现推出来找。
3. **词干槽**。
4. **语素**：词根、前缀、后缀、附着词；小品词、中缀这类只能单独成词。一个词整个就是一个附着词时，也按这个附着词 gloss。

一个词可以是「前缀 + 词干 + 后缀」，词缀可以叠好几层（`kaso-lar-da`），词干也可以有几个（两个词连写再接词缀：`yvpli-hemelia-xete-s`）。几种切法按下面的规则排，第一个默认选中：

- **块少的优先**：整个词在词典里对得上时不会去乱切；用词缀切开比拆成几个词优先。
- **单字母的块扣分**。
- **异体形看出现环境**：语素的异体形写了环境的，环境对得上的排前面，对不上的排后面（不删掉，免得环境写得不准时漏掉）。
- **跟确认过的学**：同一段文字在别的句子里确认成了哪个词条或语素、连着几段确认成了怎么切（`don` 确认过是 `do-n`，下次就这么切）、哪个语素后面常接哪个，都照着排——语料确认得越多越准。
- **看译文**：几种切法里，词条释义跟本句译文对得上的排前面。

匹配忽略大小写与 Unicode 组合方式的差异；本语言里找不到的语素会退到祖语链上的语素表去找（词根表放在祖语时照样能识别）。

另外还会试：

- **撇号缩略**（先在「设置 → 语素边界符号」里写上 `'`；很多语言拿撇号当字母，所以默认不切）：`t'am`、`m'nem` 按撇号切开，前半补上一两个元音去找词（`t'` → `ta`），后半照常找；悬浮时对应的词条取最长的那段。
- **作用于所有词的构形**：词首音变这类（见[构形](/cerf/qonlang/paradigms/)），把表层词（或词缀之间的那段词干）换回原形再找，gloss 后面接上音变的缩写。
- **去掉附加符**：原文写了重音、长音记号而词典没写时照样找得到。

下面几种是**猜出来的**，确认之前卡片标黄，覆盖率也不算它认出：

- 去掉附加符才对上的；
- 拼了两个以上词干的（复合词、连写），除非这几个词连着在别处确认过；
- 用到单字母语素、而这个语素在语料里还没确认过的——确认过一次，别的词里的同一个语素就不再算猜测。

**带空格的屈折形**：词典里写成两个词的形式（限定词 + 名词的 `ar mae` 这种）会把原文里连着的几个词并成一个词再分析，悬浮、gloss 都按这一个词走；已经确认过的词不会被并进去。

**隔开写的词**：词头里用 `…`（或 `...`）分成几段的词条（`ma…gò`），在句子里是隔着别的词写的（`ma 某某某 gò`）。分析时在一句里**按顺序**找这几段：对上第一段之后，往后最多隔 12 个词找下一段；段多的词条先试，一个词只归一处，已经确认过的词不占用。几段全找齐了才算数，那时每一段都挂上同一个词条、gloss 也一样。只找到 `ma`、后面没有 `gò` 的，这个 `ma` 不算。文字那一行每段只写自己那一半——词条的「文字写法」也按 `…` 拆开对上。

原文里写了语素边界（设置里定义的符号，默认 `-` `=`）时直接按边界切开，每一段再照上面的办法切（段里可以只有词缀，词干在别的段）；每段留几个不同词条的候选，拼出几种分析放进候选下拉。反推出的词首音变会正着推回来核对一遍，对不上的不给。

每个词得到若干候选，默认选第一个。找不到的词 gloss 为 `?`，卡片标黄。gloss 取释义的第一小段，截到分号、逗号、句号、冒号或括号前（「动词头：式 × 体 × 时……」只取「动词头」；开头就是括号注的「（植物）生长」取「生长」）。

## 3. 行间编辑器

每个词一张小卡，从上到下：原文、切分（`kaso-da`）、gloss（`房子-LOC`）、候选下拉、确认 ✓、刷新候选、以及找不到时的「建词」按钮（直接在词库建一条并确认）。

- 切分与 gloss 两个框都能手改，改完成为一条自定义分析并排第一。分隔符写 `-` 还是 `=` 就照写的显示（没写的按语素类型定：附着词是 `=`）。
- 鼠标悬停 gloss 框可看到缩写的全称（来自缩写表）。
- **全部确认**：所有有候选的词一次确认。编辑器渐隐收起（检视器仍停在这句上，再点一下卡片展开），列表卡片长出 gloss 行并闪一下绿色。
- 已确认的词有绿色边框；确认过的分析会成为其他句子里同一个词的首选。

## 4. 悬浮词卡

编辑器和列表里的词，只要分析里对应到了词条，悬停就弹出词库显示模式的词条卡；点「在词库中查看」或直接点词，跳到词库并选中它。

**几个候选分不出来时**：一个词整词对得上好几个同形词条（比如同一个拼写既是「星」又是「支持」），软件先看这句自己的译文，只有一条对得上就是它；再看别的例句——同一个词在别处确认成了哪条、出现它的句子译文里提到了哪条——有一条明显胜出也直接用它。仍然分不出来时，原文下画**警告色波浪线**，悬停把候选并排列出（最多四个，每个带词类与前几条释义），点「就是这个」写进分析并确认，之后这个词就固定是它；这次确认又会成为别的句子里同一个词的旁证。

**认错了的词**：卡片底部「在词库中查看」旁边有「改」：点了卡片换成同一个搜索框，标题是「应该是哪个词？」，搜索框先填好这个词（卡片正显示切分里的某一段时填那一段，只改那一段），点一个就写进分析并确认。几个候选并排时，顶上有「都不对，自己找」。开始页画廊里悬浮出来的卡片也有「改」：先打开那个项目、跳到语料里那一句，直接在那个词上打开搜索框。

**换成别的义项**：词条对了、只是意思挑错了时不用走「改」——卡片里**点一下那个义项**就换成它。卡片顶上正显示切分里的某一段时（点一下 `delì-hi` 的 `delì`），点义项只改那一段，所以一个词由几个语素组成时，也挑得出某一段是哪个意思。下方的候选下拉里同样每个义项各占一条。

搜索框下面还有「**同时改语料原文**」，默认不勾（勾过之后这次一直记着）：勾上再挑词条，例句原文里的**这一处**也换成它的写法（挑的是屈折形就写屈折形，大小写照原来的），同一句里别处的同一个词不动；原文和分析一起改，`Ctrl+Z` 一步撤回。只有换**整个词**时才有这一项：换切分里的某一段、挑中的是语素或者一种切法，都不动原文。

**分不出来的词**：整个词找不到，或者拆出来的某一段找不到（gloss 是 `?`，或者有 gloss 却挂不上任何词条和语素）时，悬浮也会弹出卡片，写着「没有找到」。拆出来的段先按写法找词条，找不到再按意思找：释义对得上这段的 gloss、某个形式（词头、词干、屈折形）整个出现在这一段里就算，所以带了前缀、重音写法不同的词干也认得出来（`wéñgaus` 里有弱焦点形 `eñgaus`）。下面的搜索框先填好这个词本身，按写法、释义或 gloss 搜这门语言的词条和语素，点一个就指定给它；输入的写法能切开时（几个词、词根加一串词缀连写），最前面先列出几种**切分**，挑一个就把这个词（或没找到的那一段）换成这几段。拆出来的几段排在卡片顶部，没找到的那段是黄色虚线框，点它就换过去指定；认出来的那几段照样点得开。每一段都认出来之后，这个词记为已确认。

## 5. 导出（检视器）

| 格式 | 说明 |
|---|---|
| 莱比锡纯文本 | 文字行（若有）、切分行、gloss 行（列宽对齐，中文按双宽处理）、自由行、译文 |
| Markdown | 表格 |
| HTML | `gloss__row` / `gloss__w` / `gloss__m` / `gloss__g` / `gloss__script` 等 class，贴进网页自己写样式 |
| LaTeX | `gb4e` 的 `\gll` 格式 |
| 自定义模板 | `{{text}} {{translation}} {{source}} {{morphs}} {{gloss}} {{script}}`，逐词块 `{{#tokens}}{{sep}}{{surface}} {{morphs}} {{gloss}}{{/tokens}}`；模板可保存进项目 |

复制按钮直接复制当前格式。预览里的文字行用这套文字的字体显示，拉丁部分仍按等宽对齐。

### 导入与整批导出

标题栏的「导入」「导出」：

- **从表格导入**：在页面主区打开导入面板，选 CSV / TSV 文件或直接粘贴（一行一条也行）；右侧检视器是导入样例——前几条导入后的原文、译文、出处、标签，会跳过的标出原因（原文为空、已经有了、跟前面重复），改了分列、表头、列字段马上跟着变，变了的地方先高亮再慢慢褪掉。「分列」默认自动：不是每行都有同一个分隔符时当成一行一条，句子里的逗号不会把句子切开，也可以手动指定逗号、制表符、分号、竖线。导入后在新句子里查一遍重，只差出处的直接合并。勾上「第一行是表头」后按表头猜每列是原文、哪种语言的译文、出处、标签还是备注，可以逐列改；原文为空或这门语言里已经有的跳过。
- **从 JSON 导入 / 导出 JSON**：千语集自己的格式，连分析一起搬；导入也走上面的面板，选了文件先看样例再点「导入」；换了项目时对不上的词条、语素引用会丢掉分析，选中时重新分析。
- **导出 CSV**，以及把当前列表（跟着当前语言和搜索走）整批导出为莱比锡纯文本、Markdown、HTML、LaTeX。

#### 表格格式 {#table-format}

| 表头（任选其一） | 字段 |
|---|---|
| `text`、`原文`、`例句`、`句子`、`sentence` | 原文（必须有） |
| `translation:zh`、`译文`、`翻译`、`释义`，后面带上语言（`译文(英)`、`translation en`） | 这种语言的译文；只写「译文」的依次给还没占用的释义语言 |
| `source`、`出处`、`来源` | 出处 |
| `tags`、`标签` | 标签（逗号隔开） |
| `notes`、`备注`、`注释` | 备注 |
| 正字法名（如 `转写`） | 这套正字法的写法（主正字法以外的） |
| 文字名 | 这套文字的写法（覆盖自动转写） |
| `自由行`、`直译`、`literal` | 自由行，列名当标签，几列就是几行 |

导出的 CSV 另有 `morphemes`（切分）和 `gloss` 两列，只供查看，导入时不读——要连分析一起搬请用 JSON。没有表头时第一列当原文、第二列当第一种释义语言的译文；一行一条的纯文本就是只有原文。导入面板右上角的「格式说明」打开这一节。

## 6. 统计

版式与操作见[通用操作习惯](/cerf/qonlang/#通用操作习惯)；需先在顶栏选一门语言。本页：

- **数字卡**：例句数、词次（平均每句）、不同词形（只出现一次的数量）、已识别 / 已确认词次、全句确认、有译文 / 出处 / 手填文字的句子数、词库与语素覆盖率、未识别的词。
- **分布**：按出处、标签、gloss 缩写用量、句长。
- **排行**：词频（按表面形，屈折形各算各的）、最常用的词条（按词位）。
- 点出处、词形或未识别的词回到例句列表并按它搜索；点词条跳到词库。

## 7. 缩写表

gloss 里的缩写（`PL`、`LOC`……）及其全称（多语言）。「填入莱比锡标准缩写」一键导入 Leipzig Glossing Rules 的常用缩写；自定义缩写随便加。缩写表随项目保存，悬停 gloss 时显示全称。

## 8. 与其他模块的关系

- **词库 / 语素 / 构形**的任何改动都会影响下一次分析；已确认的分析不会被自动改写。
- 悬停例句里的词会弹出词条卡。分析没认出词条时，软件会先查词头、词干与屈折形，再按**构形里写过的词缀**剥一层重查，所以屈折得比较厉害的词也能找到出处；认出的是语素时弹语素卡。
- 词卡底部列出这个词的**组成部分**（复合词的各个词、词根语素），点一下就切过去看那一部分。点词卡上的「在词库中打开」会跳到词库，左侧列表滚到那个词并短暂高亮。
- **文字**定义后，卡片与导出多一行文字。
- **主题**里可以分别指定原文、译文、gloss 行的字体。
- 顶栏「当前语言」决定显示哪些例句。

## 9. 提示

- 例句原文里的标点在分词时剥掉，不影响匹配；列表里照原样显示。
- 附着台列得准不准，看语料里分析得多不多：确认过的例句越多，哪些语素跟哪类词搭、放前放后、谁在外层就越清楚。还没有语料时，它照构形和维度推测个大概；维度填好「适用词类」、语素的 gloss 用莱比锡缩写（PL、PST 这种），都能帮它分得更准。
- 同一个词在不同句子里意义不同时，分别选候选并确认即可；首选只是默认排序。给例句填好译文，悬停时要挑的就少很多。
- 想批量整理，先把词库补全再「重新分析全部」，比逐词手改快。
