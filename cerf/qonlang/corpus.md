# 语料

[← 指南目录](/cerf/qonlang/) · 导航栏第八项

语料页收例句，并给每个词自动做**行间 gloss**（interlinear gloss）。三个子页：**例句**、**统计**、**缩写表**。

## 1. 例句卡片

列表里每句一张卡：文字行（若定义了文字）、原文（逐词可悬停 / 点击）、gloss 行（全部确认后才出现）、译文、出处与标签、已确认计数徽章。点卡片在上方展开**行间编辑器**，检视器里编辑原文、译文（多语言）、其他正字法写法、出处、标签、自由行（任意标签 + 文本，会进入导出）、备注，以及导出面板。

**查重合并**：标题旁的「查重合并」找出当前语言里原文相同或相近（≥80%）的例句。只差出处的直接合并，出处写成「A & B」；相近但不完全一样的（或译文冲突的）弹窗列出来，勾选要合并的。合并时保留上面那条的原文与分析，译文、标签、自由行补缺。

## 2. 自动分析

选中一句还没分析过的例句时自动分析；也可点「自动分析」（只补未确认的词）或「重新分析全部」。分析每个词时，候选来源依次是：

1. **已确认的分析**：项目里其他句子中同一个词已确认过的分析排第一。
2. **词头**：词库里的词位。
3. **屈折形**：词条的 forms（gloss 会带上槽位的缩写，如 `房子.PL`）。
4. **词干槽**。
5. **语素**：词根 / 词缀，最多两层剥离（`kaso-lar-da`）。
6. 原文里显式写的语素边界（设置里定义的符号，默认 `-` `=`）会直接按边界切分。

匹配忽略大小写与 Unicode 组合方式的差异；本语言里找不到的语素会退到祖语链上的语素表去找（词根表放在祖语时照样能识别）。

整词对不上时还会依次试：

- **撇号缩略**（先在「设置 → 语素边界符号」里写上 `'`；很多语言拿撇号当字母，所以默认不切）：`t'am`、`m'nem` 按撇号切开，前半补上一两个元音去找词（`t'` → `ta`），后半照常找；悬浮时对应的词条取最长的那段。
- **作用于所有词的构形**：词首音变这类（见[构形](/cerf/qonlang/paradigms/)），把表层词换回原形再找，gloss 后面接上音变的缩写；剥过前缀的余部也会试。
- **去掉附加符**：原文写了重音、长音记号而词典没写时照样找得到。
- **拆成两个词**：以上都不行时，试着把它拆成两个整词（复合词、连写）。

「去掉附加符」「拆成两个词」是猜出来的：确认之前卡片仍然标黄，覆盖率也不算它认出。

**带空格的屈折形**：词典里写成两个词的形式（限定词 + 名词的 `ar mae` 这种）会把原文里连着的几个词并成一个词再分析，悬浮、gloss 都按这一个词走；已经确认过的词不会被并进去。

按边界符切开的每一段，也会先整词找，再反推词首音变，再剥一层词缀；每段留几个不同词条的候选，拼出几种分析放进候选下拉。反推出的词首音变会正着推回来核对一遍，对不上的不给。

每个词得到若干候选，默认选第一个。找不到的词 gloss 为 `?`，卡片标黄。

## 3. 行间编辑器

每个词一张小卡，从上到下：原文、切分（`kaso-da`）、gloss（`房子-LOC`）、候选下拉、确认 ✓、刷新候选、以及找不到时的「建词」按钮（直接在词库建一条并确认）。

- 切分与 gloss 两个框都能手改，改完成为一条自定义分析并排第一。
- 鼠标悬停 gloss 框可看到缩写的全称（来自缩写表）。
- **全部确认**：所有有候选的词一次确认。编辑器渐隐收起（检视器仍停在这句上，再点一下卡片展开），列表卡片长出 gloss 行并闪一下绿色。
- 已确认的词有绿色边框；确认过的分析会成为其他句子里同一个词的首选。

## 4. 悬浮词卡

编辑器和列表里的词，只要分析里对应到了词条，悬停就弹出词库显示模式的词条卡；点「在词库中查看」或直接点词，跳到词库并选中它。

**几个候选分不出来时**：一个词整词对得上好几个同形词条（比如同一个拼写既是「星」又是「支持」），软件先看这句自己的译文，只有一条对得上就是它；再看别的例句——同一个词在别处确认成了哪条、出现它的句子译文里提到了哪条——有一条明显胜出也直接用它。仍然分不出来时，原文下画**警告色波浪线**，悬停把候选并排列出（最多四个，每个带词类与前几条释义），点「就是这个」写进分析并确认，之后这个词就固定是它；这次确认又会成为别的句子里同一个词的旁证。

**分不出来的词**：整个词找不到，或者拆出来的某一段找不到（gloss 是 `?`，或者有 gloss 却挂不上任何词条和语素）时，悬浮也会弹出卡片，写着「没有找到」。拆出来的段先按写法找词条，找不到再按意思找：释义对得上这段的 gloss、某个形式（词头、词干、屈折形）整个出现在这一段里就算，所以带了前缀、重音写法不同的词干也认得出来（`wéñgaus` 里有弱焦点形 `eñgaus`）。下面的搜索框先填好这个词本身，按写法、释义或 gloss 搜这门语言的词条和语素，点一个就指定给它。拆出来的几段排在卡片顶部，没找到的那段是黄色虚线框，点它就换过去指定；认出来的那几段照样点得开。每一段都认出来之后，这个词记为已确认。

## 5. 导出（检视器）

| 格式 | 说明 |
|---|---|
| 莱比锡纯文本 | 文字行（若有）、切分行、gloss 行（列宽对齐，中文按双宽处理）、自由行、译文 |
| Markdown | 表格 |
| HTML | `gloss__row` / `gloss__w` / `gloss__m` / `gloss__g` / `gloss__script` 等 class，贴进网页自己写样式 |
| LaTeX | `gb4e` 的 `\gll` 格式 |
| 自定义模板 | `{{text}} {{translation}} {{source}} {{morphs}} {{gloss}} {{script}}`，逐词块 `{{#tokens}}{{sep}}{{surface}} {{morphs}} {{gloss}}{{/tokens}}`；模板可保存进项目 |

复制按钮直接复制当前格式。预览里的文字行用这套文字的字体显示，拉丁部分仍按等宽对齐。

### 导入与整批导出

标题栏的「导入」「导出」：

- **从表格导入**：在页面主区打开导入面板，选 CSV / TSV 文件或直接粘贴（一行一条也行）；右侧检视器是导入样例——前几条导入后的原文、译文、出处、标签，会跳过的标出原因（原文为空、已经有了、跟前面重复），改了分列、表头、列字段马上跟着变，变了的地方先高亮再慢慢褪掉。「分列」默认自动：不是每行都有同一个分隔符时当成一行一条，句子里的逗号不会把句子切开，也可以手动指定逗号、制表符、分号、竖线。导入后在新句子里查一遍重，只差出处的直接合并。勾上「第一行是表头」后按表头猜每列是原文、哪种语言的译文、出处、标签还是备注，可以逐列改；原文为空或这门语言里已经有的跳过。
- **从 JSON 导入 / 导出 JSON**：千语集自己的格式，连分析一起搬；导入也走上面的面板，选了文件先看样例再点「导入」；换了项目时对不上的词条、语素引用会丢掉分析，选中时重新分析。
- **导出 CSV**，以及把当前列表（跟着当前语言和搜索走）整批导出为莱比锡纯文本、Markdown、HTML、LaTeX。

#### 表格格式 {#table-format}

| 表头（任选其一） | 字段 |
|---|---|
| `text`、`原文`、`例句`、`句子`、`sentence` | 原文（必须有） |
| `translation:zh`、`译文`、`翻译`、`释义`，后面带上语言（`译文(英)`、`translation en`） | 这种语言的译文；只写「译文」的依次给还没占用的释义语言 |
| `source`、`出处`、`来源` | 出处 |
| `tags`、`标签` | 标签（逗号隔开） |
| `notes`、`备注`、`注释` | 备注 |
| 正字法名（如 `转写`） | 这套正字法的写法（主正字法以外的） |
| 文字名 | 这套文字的写法（覆盖自动转写） |
| `自由行`、`直译`、`literal` | 自由行，列名当标签，几列就是几行 |

导出的 CSV 另有 `morphemes`（切分）和 `gloss` 两列，只供查看，导入时不读——要连分析一起搬请用 JSON。没有表头时第一列当原文、第二列当第一种释义语言的译文；一行一条的纯文本就是只有原文。导入面板右上角的「格式说明」打开这一节。

## 6. 统计

版式与操作见[通用操作习惯](/cerf/qonlang/#通用操作习惯)；需先在顶栏选一门语言。本页：

- **数字卡**：例句数、词次（平均每句）、不同词形（只出现一次的数量）、已识别 / 已确认词次、全句确认、有译文 / 出处 / 手填文字的句子数、词库与语素覆盖率、未识别的词。
- **分布**：按出处、标签、gloss 缩写用量、句长。
- **排行**：词频（按表面形，屈折形各算各的）、最常用的词条（按词位）。
- 点出处、词形或未识别的词回到例句列表并按它搜索；点词条跳到词库。

## 7. 缩写表

gloss 里的缩写（`PL`、`LOC`……）及其全称（多语言）。「填入莱比锡标准缩写」一键导入 Leipzig Glossing Rules 的常用缩写；自定义缩写随便加。缩写表随项目保存，悬停 gloss 时显示全称。

## 8. 与其他模块的关系

- **词库 / 语素 / 构形**的任何改动都会影响下一次分析；已确认的分析不会被自动改写。
- 悬停例句里的词会弹出词条卡。分析没认出词条时，软件会先查词头、词干与屈折形，再按**构形里写过的词缀**剥一层重查，所以屈折得比较厉害的词也能找到出处；认出的是语素时弹语素卡。
- 词卡底部列出这个词的**组成部分**（复合词的各个词、词根语素），点一下就切过去看那一部分。点词卡上的「在词库中打开」会跳到词库，左侧列表滚到那个词并短暂高亮。
- **文字**定义后，卡片与导出多一行文字。
- **皮肤**里可以分别指定原文、译文、gloss 行的字体。
- 顶栏「当前语言」决定显示哪些例句。

## 9. 提示

- 例句原文里的标点会在分词时剥掉，不影响匹配。
- 同一个词在不同句子里意义不同时，分别选候选并确认即可；首选只是默认排序。给例句填好译文，悬停时要挑的就少很多。
- 想批量整理，先把词库补全再「重新分析全部」，比逐词手改快。
