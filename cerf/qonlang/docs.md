# 文档

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/docs/) · 导航栏第十项

文档页放**项目内的 Markdown 或 HTML 页面**：语法说明、文化背景、翻译笔记、造词日志。Lexicanter 的 Docs 与 Inflections 表导入后也变成这里的 Markdown 页面。

### 工程共享目录 {#shared-folders}

**工程共享目录**：语料、短语和文档现在使用同一棵多级目录树。在任一页新建、改名或移动文件夹，另外两页立即使用同一个目录。旧语料与文档文件夹会保留内容和层级；没有目录的记录归 `Default`，同名旧目录会自动编号以免混并。记录的语言不随目录移动而改变。

点击路径中的「根目录」进入目录视图。它左侧的小三角可以展开或收起整列侧栏，默认收起。选定文件夹即可浏览其中的内容，打开例句、短语或文档会进入相应页面。可切换「图标视图／详细信息」，在「设置 → 根目录」选择标签、创建时间、文件大小和类型等列。大小是记录数据的 UTF-8 估算值，不是磁盘占用，也不含独立附件；旧记录没有创建时间时显示「—」。

「根目录」与 `Default` 不同：根视图只列出 `Default` 和顶层文件夹；打开 `Default` 才查看未归档记录。`Default` 不是其他顶层目录的父层。目录数字汇总本层与所有后代中的例句、短语和文档，根数字则是全工程合计；点击树中箭头可展开或收起某一分支，数量不随折叠改变。面包屑从根目录开始，可逐层返回。

`Default` 不接收子目录；请在根目录新建、移动或粘贴文件夹，也可将文件夹拖到根目录图标上。记录仍可拖入 `Default`。在根目录粘贴只有记录的内容时，会自动进入 `Default` 展示实际落点。

右键文件夹或记录可「复制」「剪切」「粘贴」，也可在选中记录后使用页面工具栏及 `Ctrl/⌘+C`、`Ctrl/⌘+X`、`Ctrl/⌘+V`。文件夹复制包含整棵子树和其中的三类记录；粘贴建立新 ID，保留分析与已有词条、语素引用。剪切只在成功粘贴时移动原对象，取消或失败不会先删内容。整条记录剪贴板仅用于当前打开的工程会话；重新打开工程或重新启动软件后，请重新复制。文本框中的普通文字复制粘贴不受影响。只读项目不能改动目录或记录。

## 1. 布局

左栏按多级文件夹列出页面（当前语言的页面 + 整个项目通用的页面），中间是编辑区，三种视图：**编辑**、**分栏**（左编辑右预览）、**预览**。打开文档页默认停在预览，新建页面直接进编辑。顶栏搜索可跨文件夹按标题或正文找页面，结果标出所在目录。检视器设置标题、所属语言（或「整个项目」）、文件夹、标签与导出。标签可在这里录入，并在共享目录的「详细信息」中显示。

旧文档和未指定目录的页面都在 **Default**。点击「新建文件夹」在当前目录下建子文件夹；文件夹右侧菜单可新建子层、重命名、移动或删除。文档可拖入目录，或在检视器选择目标文件夹；文件夹可拖到另一个目录下，也可用菜单选择目标，不能移进自身或子树。目录是整个项目共用的，切换语言只筛选其中的文档，不改归属。删除文件夹会把其中直接文档及子文件夹提升到上级（顶层文档回到 Default），不会删除正文或改变文档 ID；提升时遇同级重名会自动编号，用「撤销」可恢复原名与位置。

从项目链接、命令面板或语料反向引用打开文档时，会定位到它实际所在的文件夹并显示实际路径；「返回」恢复原目录、文档和阅读视图。

编辑区上方的工具条把常用语法插到光标处：粗体、斜体、标题、列表、`[[ ]]` 链接、表格、代码块。

**正文格式**在检视器单独设置。默认仍为 Markdown；「设置 → 应用 → 新建文档的默认格式」可选 HTML，只影响本设备之后在文档页新建的页面，不改变已有、导入或示例文档。切换一篇文档的格式只改变解析方式，不自动改写正文，切回即可按原格式继续编辑。

## 2. 支持的语法

| 语法 | 写法 |
|---|---|
| 标题 | `#` 到 `#####` |
| 列表 | `- 项`、`1. 项` |
| 引用 | `> 文本` |
| 代码块 | 三个反引号包围 |
| 表格 | `\| a \| b \|`，第二行 `\| --- \| --- \|` |
| 粗体 / 斜体 / 删除线 / 行内代码 | `**x**`、`*x*`、`~~x~~`、`` `x` `` |
| 链接 | `[文字](https://…)`，在外部浏览器打开 |
| 分隔线 | `---` |
| **项目内链接** | `[[名字]]`、`[[前缀:名字]]`、`[[前缀:名字#子目标]]`，后面都能再加 `\|显示文字`。见下 |

Markdown 使用极简语法，原始 HTML 一律作为文字显示。选择 HTML 格式后，支持安全的标题、段落、列表、表格、粗体、斜体、代码等文字排版；不支持用户 CSS、脚本、媒体、表单、嵌入网页或自动网络资源。输入内容不会作为网页执行，HTML 属性中的事件、样式和伪项目跳转均被移除；普通 HTTP(S) 链接只有点击后才在外部浏览器打开。HTML 的普通文字节点也可写 `[[项目链接]]`，属性和代码中的文字不参与链接。

### 项目内链接 {#links}

不写前缀就照旧先当**词条**找（老文档照样能用），找不到再依次找语素、文档页、短语、例句、语言、构形、音变、文字。写了前缀就只在那一类里找：

| 写成 | 链到哪 |
|---|---|
| `[[kaso]]` | 词条 |
| `[[语素:-lAr]]` | 语素（词缀前后的连字符写不写都认） |
| `[[语言:Merun]]` | 语言（名字或缩写） |
| `[[音变:Proto → Aelith]]`、`[[音变:Proto → Aelith#现代语]]` | 音变规则集，`#` 后面是某个阶段 |
| `[[构形:名词]]`、`[[构形:名词#单数.位格]]` | 构形，`#` 后面是某个槽位（槽位名、gloss 缩写、另一种界面语言的取值名都认） |
| `[[文字:Aelith 刻文]]` | 一套文字 |
| `[[例句:…]]`、`[[短语:…]]` | 语料里的一句、短语簿里的一条 |
| `[[文档:语法概要]]` | 另一个文档页 |

前缀**中英文都认**（`[[morpheme:-lAr]]` 跟 `[[语素:-lAr]]` 一样），大小写、空格、连字符不计较，中文冒号也行——中文界面写的文档换成英文界面照样能点。

点一下就跳到对应模块并高亮那一条。找不到的链接画成虚线，鼠标停上去说清楚是哪一类没找到（名字对上了、`#` 后面那一段没对上时，仍然链到大的那一个）。

工具条上的「**插入链接**」不用自己记写法：挑类型、搜名字、回车插入；音变规则集会连它的各个阶段一起列出来，构形会连槽位一起列。

例句链接优先查文档所属语言的例句；同一层有多条同文例句时，不会随意跳到其中一条。请为文档设置正确的所属语言。语料检视器中的「**提到这条例句的文档**」可反向跳回这篇文档，预览会滚到并高亮提及处；多篇文档分别列出标题和语言。普通正文把独立成段、成对引号内或 HTML `<q>` 元素中的完整原句记为「完整原句」：至少八个字符，并具有词间空白、句末标点或足够长的汉字原文。例如 `本文以“ilenler kasoda jatdu.”为例`，或 HTML 的 `<p>本文以<q>ilenler kasoda jatdu.</q>为例</p>`，都可按引号内的完整原句反查；支持中文弯引号、直引号、日文括号引号及 `«…»`。短词、代码、HTML 属性、只有相近字串的段落不算引用；要可靠关联短句，请使用 `[[例句:原文]]`。

## 3. 导出

- **Markdown**：标题作为一级标题；Markdown 正文原样，HTML 正文按基本结构转换为 Markdown。
- **HTML**：导出安全预览并保留内置样式；标题、正文都经过处理，不携带用户 CSS、脚本或自动加载的资源。
- **PDF**：A4，桌面版直接出文件，网页版走打印对话框。

「设置 → 导出为文件夹格式」把文档源文件导成 `docs/<标题>.md` 或 `.html`，另存 `docs.json` 保留文档 ID、所属语言、格式与目录归属，`project.json` 保存目录树，重新导入时一并恢复。逻辑目录通过这些元数据保存，源文件仍按原有命名方式写入 `docs/`。旧文件夹仅有 `docs/*.md` 时也可恢复为项目通用文档并归入 Default。文件夹里的 HTML 是可编辑的原始源文件；在应用中预览及导出 HTML/PDF 时才做安全过滤。

## 4. 与其他模块的关系

- `[[…]]` 跳到词库、语素、语言、音变、构形、文字、语料、短语或别的文档页。
- 语料的反向引用列表也可从译文工作台打开文档；「返回上一页」会恢复工作台草稿。文档跳到某条例句时先显示目标例句，避免被上次打开的工作台或导入面板挡住。
- 命令面板可按标题或正文内容搜到页面。
- 主题「语料译文」字体槽也用于预览区正文。
