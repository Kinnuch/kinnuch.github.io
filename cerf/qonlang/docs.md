# 文档

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/docs/) · 导航栏第十项

文档页放**项目内的 Markdown 页面**：语法说明、文化背景、翻译笔记、造词日志。Lexicanter 的 Docs 与 Inflections 表导入后也变成这里的页面。

## 1. 布局

左栏页面列表（当前语言的页面 + 整个项目通用的页面），中间是编辑区，三种视图：**编辑**、**分栏**（左编辑右预览）、**预览**。打开文档页默认停在预览，新建页面直接进编辑。顶栏搜索可按标题或正文筛页面。检视器设置标题、所属语言（或「整个项目」）、导出。

编辑区上方的工具条把常用语法插到光标处：粗体、斜体、标题、列表、`[[ ]]` 链接、表格、代码块。

## 2. 支持的语法

| 语法 | 写法 |
|---|---|
| 标题 | `#` 到 `#####` |
| 列表 | `- 项`、`1. 项` |
| 引用 | `> 文本` |
| 代码块 | 三个反引号包围 |
| 表格 | `\| a \| b \|`，第二行 `\| --- \| --- \|` |
| 粗体 / 斜体 / 删除线 / 行内代码 | `**x**`、`*x*`、`~~x~~`、`` `x` `` |
| 链接 | `[文字](https://…)`，在外部浏览器打开 |
| 分隔线 | `---` |
| **项目内链接** | `[[名字]]`、`[[前缀:名字]]`、`[[前缀:名字#子目标]]`，后面都能再加 `\|显示文字`。见下 |

渲染是自家的极简实现，文本一律转义，不接受原始 HTML。

### 项目内链接 {#links}

不写前缀就照旧先当**词条**找（老文档照样能用），找不到再依次找语素、文档页、短语、例句、语言、构形、音变、文字。写了前缀就只在那一类里找：

| 写成 | 链到哪 |
|---|---|
| `[[kaso]]` | 词条 |
| `[[语素:-lAr]]` | 语素（词缀前后的连字符写不写都认） |
| `[[语言:Merun]]` | 语言（名字或缩写） |
| `[[音变:Proto → Aelith]]`、`[[音变:Proto → Aelith#现代语]]` | 音变规则集，`#` 后面是某个阶段 |
| `[[构形:名词]]`、`[[构形:名词#单数.位格]]` | 构形，`#` 后面是某个槽位（槽位名、gloss 缩写、另一种界面语言的取值名都认） |
| `[[文字:Aelith 刻文]]` | 一套文字 |
| `[[例句:…]]`、`[[短语:…]]` | 语料里的一句、短语簿里的一条 |
| `[[文档:语法概要]]` | 另一个文档页 |

前缀**中英文都认**（`[[morpheme:-lAr]]` 跟 `[[语素:-lAr]]` 一样），大小写、空格、连字符不计较，中文冒号也行——中文界面写的文档换成英文界面照样能点。

点一下就跳到对应模块并高亮那一条。找不到的链接画成虚线，鼠标停上去说清楚是哪一类没找到（名字对上了、`#` 后面那一段没对上时，仍然链到大的那一个）。

工具条上的「**插入链接**」不用自己记写法：挑类型、搜名字、回车插入；音变规则集会连它的各个阶段一起列出来，构形会连槽位一起列。

## 3. 导出

- **Markdown**：标题作为一级标题，正文原样。
- **PDF**：A4，桌面版直接出文件，网页版走打印对话框。

「设置 → 导出为文件夹格式」会把每个文档页导成 `docs/<标题>.md`。

## 4. 与其他模块的关系

- `[[…]]` 跳到词库、语素、语言、音变、构形、文字、语料、短语或别的文档页。
- 命令面板可按标题或正文内容搜到页面。
- 皮肤「语料译文」字体槽也用于预览区正文。
