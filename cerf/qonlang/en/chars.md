# Character panel

[← Guide index](/cerf/qonlang/en/) · [中文](/cerf/qonlang/chars/) · the keyboard icon at the bottom left of the navigation bar, or `Ctrl+I` in any text box

The character panel is a floating window (movable and resizable). Clicking a symbol inserts it at the cursor of **the input that last had focus**, without interrupting your typing. It works on every page.

## 1. Tabs

| Tab | Contents |
|---|---|
| Pulmonic consonants | The IPA chart by place × manner |
| Non-pulmonic | Clicks, implosives, ejectives |
| Vowels | The vowel chart + other vowels |
| Diacritics | Every IPA diacritic (shown in the ◌̥ form) |
| Suprasegmentals | Length, stress, syllable boundaries, etc. |
| Tones | Tone letters and contour marks |
| Symbols | Other common symbols |
| Latin extended | Common Latin letters with diacritics |
| Compose | See below |
| Recent / Saved | Recently inserted symbols; right-click any symbol to save it |
| Project characters | The current language's **phonemes** and the **glyphs** of each of its scripts, shown in the script's font |

The search box at the top searches by name or feature ("retroflex", "nasal", "voiced"). Hovering a symbol shows its name and code point.

## 2. Compose

Pick a base character, then click diacritics one after another; the preview shows the combined result live, and several diacritics can be stacked. The **Normalize** switch decides whether the output is NFC-composed (precomposed characters are used where they exist, e.g. `e` + `́` → `é`). When it looks right, click **Insert** or **Copy**.

## 3. Tips

- Clicking in the panel doesn't take focus away from the input, so you can insert several symbols in a row.
- In Theme, choose a font with complete IPA coverage (Charis SIL / Gentium Plus) for the "language data" slot so that stacked diacritics display correctly.
