# 开始使用

[← 指南目录](/cerf/qonlang/)

## 1. 安装与启动

- **Windows 免安装版**：解压后双击 `Qonlang.exe`。数据目录在 `%APPDATA%\Qonlang`（偏好设置、最近项目、自动备份、下载的字体都在这里）。
- **Windows 安装包**：`Qonlang-<版本>-setup.exe`，可选安装目录，桌面快捷方式叫「千语集」。
- **macOS**：从 [GitHub Releases](https://github.com/Kinnuch/Qonlang/releases) 下载 `Qonlang-<版本>-mac-arm64.dmg`（Apple Silicon）或 `-x64.dmg`（Intel），拖进「应用程序」。应用没有签名与公证，首次打开会被 Gatekeeper 拦：**右键应用 →「打开」**，或在终端执行 `xattr -cr /Applications/Qonlang.app`。数据目录在 `~/Library/Application Support/Qonlang`。
- **从源码运行**：`git clone` 后，Windows 双击仓库里的 `dev.cmd`（不经过 PowerShell，不受执行策略限制），macOS / Linux 执行 `sh dev.sh`，首次会自动 `npm install`。

每个版本的 Windows 安装包与 macOS dmg 都由 GitHub Actions 在打 tag 时同时构建，挂在同一个 Release 下。

如果系统提示「禁止运行脚本」，那是 PowerShell 的执行策略在拦 `npm.ps1`，用 `dev.cmd` 或直接用 exe 即可。

## 2. 首页

首页三块内容：

1. **横幅**：链接到 Gilatod Wiki。
2. **起步模板**：
   - **空白单语**：一门语言，从零开始，先验语默认选这个。
   - **语系**：一门祖语加若干子语言（每行一个名字），之后用音变把词从祖语推到子语言。
   - **从 Lexicanter 导入**：读取 `.lexc` 文件，词库、义项、方言、发音规则、字母表、词源、短语、文档一次进来。
   - **从 CSV 导入**：先建空白项目，然后自动打开 CSV 列映射向导。
3. **最近打开**：文件不存在时会自动从列表移除。

左侧四个按钮：新建项目、打开项目、**示例工程**、使用指南。「示例工程」带两个虚构项目，合起来把每个模块的功能都摆了一遍——想看某个功能长什么样、数据该怎么填，打开翻一翻最快：

- **Aelith**（黏着先验语）：祖语→现代语的语系、元音和谐、多槽位后缀、流水线构形的八种步骤、变体与继承、屏蔽槽位与手填表、词源链与关系图、配图与方言、已 gloss 并确认的语料、卢恩刻文。
- **Tsahun**（孤立声调语）：五个声调、罗马化与西里尔双正字法、音节文字的拼合与**竖排**、重叠构形、量词与整套借入的数词。

打开后随便改；它们没有文件目标，保存时会问你存到哪，示例本身不会被覆盖。

底部六个按钮：请我喝咖啡、更新日志（就是仓库里的 `CHANGELOG.md`）、开发者、友链、致谢、规则语法；再往左是「使用指南」，也就是本站。

## 3. 项目文件

- 一个项目 = 一个 `*.laim.json` 文件，里面是全部语言、规则集、词类维度、语素、词条、构形、例句、短语、缩写表、文档页与项目设置。文字里内嵌的字体也以 data URL 存在里面，所以换机器打开仍能显示。
- **设置 → 导出为文件夹格式**：每个集合一个 JSON、规则集另出一份纯文本、文档页导出为 `.md`，便于放进 git 看 diff。
- **自动保存**：设置里的间隔（秒，0 关闭）。另外每 5 秒会写一份快照到数据目录，意外崩溃后重启会提示恢复。
- **备份**：每次保存前，旧文件会复制到数据目录的 `Backups/`，默认保留 20 份。
- **关闭保护**：有未保存改动时关窗口或点导航栏的「千」回首页，会弹提示条让你选保存或丢弃。

## 4. 推荐的建库顺序

1. **语言**页：确认语言名、缩写、颜色；语系项目先把树画对。
2. **音系**页：点 IPA 表建音位表，一键生成 C / V 音类，写「正字法 → IPA」规则。
3. **词库**页：先录一批词（或 CSV / Lexicanter 导入），词类与维度在「词类与维度」子页定义。
4. **语素**页：词根与词缀。
5. **构形**页：把维度组合成槽位，写生成器，绑定词类，推导写入。
6. **音变**页（语系项目）：规则集、阶段绑定语言、整库演化。
7. **文字**页：如果有自己的书写系统。
8. **语料**页：例句自动 gloss，确认后成为其他句子的首选。
9. **文档 / 短语**：语法说明、常用语。
10. **词库 → 导出**：词典 HTML / Markdown / PDF。

顺序不是强制的，任何页面随时可以回头改，联动都是自动的。

## 5. 顶栏

- **项目名**与「已保存 / 未保存」徽章，右边是**搜索框**（词库、语素、语料、短语页面才出现，占位文字跟着模块走，换页面自动清空）。
- **当前语言**下拉：多数页面只显示当前语言的数据；选「全部语言」看整个项目。语料、短语、文档等页面新建内容时默认归属当前语言。
- 保存按钮、检视器开关、关闭项目。

## 6. 网页版

同一套代码可以用 `npm run build:web` 打成静态站点，在浏览器里用 File System Access API 读写本地项目文件，IndexedDB 存快照与字体。功能一致，只是 PDF 导出走浏览器打印对话框。
