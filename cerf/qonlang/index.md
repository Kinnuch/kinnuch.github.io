# Qonlang 千语集 · 使用指南

千语集是一个**面向所有造语者**的桌面应用（Windows 免安装版与安装包，同一套代码也能跑在浏览器里）。它不内置任何一门语言的术语：词类、格、维度、缩写、方言、文字全部由你在项目里定义，软件只负责把它们串起来——录入词汇与词根、制订音变规则、按音系自动标音、自动 gloss 例句、自定义文字、导出词典。

- 源码与下载：[github.com/Kinnuch/Qonlang](https://github.com/Kinnuch/Qonlang)（MIT）
- 界面语言：中文 / English，默认中文；浅色 / 深色主题
- 项目文件：单个 `*.laim.json`，另可导出为按集合拆分的文件夹（便于 git）

软件里每个页面标题旁都有「使用指南」按钮：先在界面上做一遍**图文引导**——高亮要点、箭头加说明，（1/N）一步步往下，讲完弹窗问要不要来本站看对应章节。每个模块默认只自动讲一次，之后再点就直接打开本站；想每次都先讲，勾上弹窗里的选项，或在[设置](/cerf/qonlang/settings/)里打开。首页左栏的「使用指南」跳到本页。

## 一张图看懂模块之间的联动

```
音系（音位 / 音类 / 多合字母）──→ 音变规则、正字法规则、文字映射规则都能引用
正字法规则（拼写 → IPA）────────→ 词库「发音」列、语料 IPA、短语发音
文字映射规则（转写 → 字形）─────→ 词库「文字」列、词条卡、语料与短语的文字行、词典导出
语素（词根 / 词缀）────────────→ 构形生成器里的 @语素、语料自动切分、词源来源
构形（维度 × 槽位 × 生成器）───→ 词库录入模式的槽位面板、词条卡的屈折形、语料 gloss 的形态标签
音变规则集（阶段绑定语言）─────→ 构形「拼接后跑音变」生成器、整库演化
词库（词头 / 义项 / 屈折形）───→ 语料自动 gloss、悬浮词卡、文档里的 [[词头]] 链接、词典导出
```

每个页面顶部都有一条可关闭的蓝色提示，写明本页数据会被哪些页面用到；关掉后不再出现，想重看可以在设置里恢复。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做上一步项目改动（焦点在输入框里时先撤销输入）；顶栏也有按钮 |
| `Alt+←` | 返回（顶栏「返回」按钮）：一步步退回走过的位置——页面、当时的当前语言、选中的那一条、打开的子页或窗口（统计、关系图、录入模式……）、列表滚到哪、搜索框里写的字；离开页面前的筛选、排序、子页、选中项和测试输入也都记着，点导航回到这一页同样接着用 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+O` | 打开项目 |
| `Ctrl+K` | 命令面板：跨页面搜索词条、语素、例句、短语、文档、规则集、构形、语言；输入页面名直接跳转 |
| `Ctrl+I` | 字符面板（IPA 与自定义字形，插入到当前光标处） |
| `Ctrl+\` | 折叠 / 展开右侧检视器 |
| `Esc` | 关闭命令面板、输入框、字符面板 |

## 通用操作习惯

- **三栏布局**：左侧导航、中间主区、右侧「检视器」。检视器宽度可拖动分隔条调整；左侧导航里再点一次当前模块停在原地不动；皮肤、设置再点一次回到上一页。
- **一切改动都可撤销**：`Ctrl+Z` 撤销上一步项目改动（改字段、删词条、推导写入、整库演化……都算一步），`Ctrl+Y` 重做，最多回退 60 步；删除类操作另有 8 秒内的「撤销」提示条。没有二次确认对话框。
- **右键菜单**：任意位置右键有剪切 / 复制 / 粘贴、撤销 / 重做 / 返回、命令面板、字符面板、保存、使用指南。
- **下拉菜单**点击展开，点空白处或 Esc 收起。
- **横向滚动**：表格、链图这类只横向溢出的区域，普通滚轮即可横向滚动，不必按 Shift。
- **自动化只出草稿**：自动标音、自动屈折、自动 gloss 都能逐格改成不规则值，改过的会有标记，重跑不会覆盖。
- **一切都是项目数据**：词类、维度、缩写表、方言、导出模板全部存在项目文件里，换机器打开即得。皮肤和界面语言是应用级设置，不进项目文件。
- **文本框都能唤出字符面板**：任何输入框里按 `Ctrl+I`，点符号即插入光标处。
- **搜索框**统一在顶栏，项目名与保存状态的右边，每个模块都有；占位文字与筛选口径跟着当前模块走（语言、音位与音类、字形、规则行、语素、词条、槽位、例句、短语、文档、字体、设置项），换页面自动清空。还有高级写法：`字段=内容` 只在一个字段里找（如 `gloss=PL`、`word=kam`，写中文字段名「释义=」也行），`字段==内容` 要整个相等，`/正则/` 按正则找；多个条件用空格隔开、要全部满足，内容里有空格就加引号。搜索框旁的「?」列出本页有哪些字段。
- **规则语法统一**：音变、正字法、文字映射、构形的微调、语素异体形的环境都用同一套规则写法。首页的「规则语法」或顶栏右上角的翻开的书图标（检视器按钮与关闭项目之间）会在右侧检视器里打开完整说明；在音变、构形、文字、音系、语素页打开时直接滚到相关的那一节。
- **书签页签**：文字、音变、构形里你自己建的多套内容（每套文字、每个规则集、每个构形）以书签页签排在标题右边，选中的那张与下方页面连成一片；「新建」按钮统一在最右。鼠标放到页签上，右侧会出现一支**铅笔**，点它把检视器里的「名称」聚焦，直接改名；构形的变体同理，点铅笔就地改名。
- **板块可以收起**：内容多的板块（词类与维度、音位表与元音表、文字的音节拼合与自动映射、皮肤的词条卡与字体库……）标题右边有个平时不显示的三角，鼠标放上去才出现，点一下把整块收起来，下次打开还是收着。
- **长列表分批画**：词库、语素、语料、构形槽位、字形表先画一屏，滚到快见底再画下一批，切页面、改筛选都不卡。
- **第一次打开软件**会在开始页先走一遍图文引导（新建 / 打开、起步模板、最近打开、底部那排），最后交代右上角的「规则语法」；以后想再看，点各页标题旁的「使用指南」。
- **表格表头**（词库、语素）：点列名循环 ▼降序 → ▲升序 → 取消；列名右侧的漏斗打开筛选面板（全选 / 全不选 / 单选，第一列按首字母）；筛空了表头仍在，随时能取消；表头**最左侧**的小按钮切换自定义顺序，切换后同一列里出现上下移动按钮。
- **导入样例**：各页的导入（词库、语素的 CSV，语料、短语的表格与 JSON，字形，Lexicanter，音变规则文件）都先在右侧检视器里显示导入后的样子；改了设置马上跟着变，变了的地方先高亮再慢慢褪掉，确认无误再点「导入」。
- **统计面板**（词库、语素、语料各一份）：同一套版式——数字卡、分布柱、排行；点分布里的一项会回到列表并按它筛选或搜索；并排的两块按矮的那块对齐，长的那块在里面滚动，鼠标放上去那块边框略微亮起。

## 示例项目

首页的「示例工程」按钮直接打开两个虚构语言项目（改动不会覆盖示例文件本身）。两种完全不同的语言类型，合起来把每个模块的功能都摆了一遍：

- **Aelith**：黏着语，祖语 → 现代语的语系，元音和谐，多槽位后缀与流水线构形的每一种步骤、变体（基础那套改名叫「书面」）与继承，作用于所有词的连读浊化，复合词类与义项的词类，检视器模块（文化注释、用刻文字体显示的刻文异体），词源链与关系图，一套卢恩刻文和已 gloss 并确认的例句（人名 Mira 故意没进词库，悬浮时是「没有找到」）。
- **Tsahun**：孤立声调语，声调、双正字法、音节文字拼合与竖排、文字的括号设置，`@词条` 引用推出带空格的屈折形（`ngo21 tui55`），同形词 hok33 的候选，用音节文字字体显示的「异体字」模块。

两个项目文件也在仓库的 `examples/` 里。
