# Qonlang 千语集 · 使用指南

[English version](/cerf/qonlang/en/)

千语集是一个**面向所有造语者**的桌面应用（Windows 免安装版与安装包，同一套代码也能跑在浏览器里）。它不内置任何一门语言的术语：词类、格、维度、缩写、方言、文字全部由你在项目里定义，软件只负责把它们串起来——录入词汇与词根、制订音变规则、按音系自动标音、自动 gloss 例句、自定义文字、导出词典。

- 源码与下载：[github.com/Kinnuch/Qonlang](https://github.com/Kinnuch/Qonlang)（MIT）
- 界面语言：中文 / English，默认中文；浅色 / 深色主题
- 项目文件：单个 `*.laim.json`，另可导出为按集合拆分的文件夹（便于 git）

软件里每个页面标题旁都有「使用指南」按钮：先在界面上做一遍**图文引导**——高亮要点、箭头加说明，（1/N）一步步往下，讲完弹窗问要不要来本站看对应章节。每个模块默认只自动讲一次，之后再点就直接打开本站；想每次都先讲，勾上弹窗里的选项，或在[设置](/cerf/qonlang/settings/)里打开。首页左栏的「使用指南」跳到本页；界面切到 English 时，这些按钮打开[英文版指南](/cerf/qonlang/en/)。

## 一张图看懂模块之间的联动

```
音系（音位 / 音类 / 多合字母）──→ 音变规则、正字法规则、文字映射规则都能引用
正字法规则（拼写 → IPA）────────→ 词库「发音」列、语料 IPA、短语发音
文字映射规则（转写 → 字形）─────→ 词库「文字」列、词条卡、语料与短语的文字行、词典导出
语素（词根 / 词缀）────────────→ 构形生成器里的 @语素、语料自动切分、词源来源
构形（维度 × 槽位 × 生成器）───→ 词库录入模式的槽位面板、词条卡的屈折形、语料 gloss 的形态标签
音变规则集（阶段绑定语言）─────→ 构形「拼接后跑音变」生成器、整库演化
词库（词头 / 义项 / 屈折形）───→ 语料自动 gloss、悬浮词卡、文档里的 [[词头]] 链接、词典导出
```

每个页面顶部都有一条可关闭的蓝色提示，写明本页数据会被哪些页面用到；关掉后不再出现，想重看可以在设置里恢复。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做上一步项目改动（焦点在输入框里时先撤销输入）；顶栏也有按钮 |
| `F5` | 刷新当前页（顶栏重做右边的按钮）：导入、新增之后哪里没跟上时点一下，这一页整个重新加载，筛选、选中都还在；不会动项目数据 |
| `Alt+←` | 返回（顶栏「返回」按钮）：一步步退回走过的位置——页面、当时的当前语言、选中的那一条、打开的子页或窗口（统计、关系图、录入模式……）、列表滚到哪、搜索框里写的字；离开页面前的筛选、排序、子页、选中项和测试输入也都记着，点导航回到这一页同样接着用 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+O` | 打开项目 |
| `Ctrl+K` | 命令面板：跨页面搜索词条、语素、例句、短语、文档、规则集、构形、语言；输入页面名直接跳转 |
| `Ctrl+I` | 字符面板（IPA 与自定义字形，插入到当前光标处） |
| `Ctrl+\` | 折叠 / 展开右侧检视器 |
| `Esc` | 关闭命令面板、输入框、字符面板 |

## 通用操作习惯

- **三栏布局**：左侧导航、中间主区、右侧「检视器」。检视器宽度默认跟着窗口走（主区留够内容宽，其余给检视器），拖动分隔条可以自己定，双击分隔条恢复；左侧导航里再点一次当前模块停在原地不动；皮肤、设置再点一次回到上一页。
- **框里的灰字提示**：检视器里的输入框写不下提示时，鼠标停在框上，系统提示里能看全。
- **一切改动都可撤销**：`Ctrl+Z` 撤销上一步项目改动（改字段、删词条、推导写入、整库演化……都算一步），`Ctrl+Y` 重做，最多回退 60 步；删除类操作另有 8 秒内的「撤销」提示条。没有二次确认对话框。
- **右键菜单**：任意位置右键有剪切 / 复制 / 粘贴、撤销 / 重做 / 返回、命令面板、字符面板、保存、另存为、使用指南。
- **页面出错不会整页崩**：某一页出错时，底部挂一条红色的条，写明哪一页出的错、报错信息，要手动关掉；项目自动退回到上一次操作之前（刚改的那一步撤掉），这一页重新画出来，可以接着用。退回之后马上又出错（跟改动无关）就停在出错卡片上，那里能重试、回到「语言」页或保存。
- **下拉菜单**点击展开，点空白处或 Esc 收起。
- **一排排小圆框超过五行就在那一块里滚动**：规则表单里能插入的音类与语素、音类面板、语素「用到它的词条」这类可能很长的列表，不会把表单撑得老长。
- **横向滚动**：表格、链图这类只横向溢出的区域，普通滚轮即可横向滚动，不必按 Shift。
- **自动化只出草稿**：自动标音、自动屈折、自动 gloss 都能逐格改成不规则值，改过的会有标记，重跑不会覆盖。
- **一切都是项目数据**：词类、维度、缩写表、方言、导出模板全部存在项目文件里，换机器打开即得。皮肤和界面语言是应用级设置，不进项目文件。
- **文本框都能唤出字符面板**：任何输入框里按 `Ctrl+I`，点符号即插入光标处。
- **搜索框**统一在顶栏，项目名与保存状态的右边，每个模块都有；占位文字与筛选口径跟着当前模块走（语言、音位与音类、字形、规则行、语素、词条、槽位、例句、短语、文档、字体、设置项），换页面自动清空。还有高级写法：`字段=内容` 只在一个字段里找（如 `gloss=PL`、`word=kam`，写中文字段名「释义=」也行；词库、语素里语法维度的名字也能当字段，如 `性=阴`），`字段==内容` 要整个相等，`/正则/` 按正则找；多个条件用空格隔开、要全部满足，内容里有空格就加引号。搜索框旁的「?」列出本页有哪些字段。搜出来的结果里**命中的那几个字标黄**，翻页、滚动、改一条之后都跟着走；只标页面上看得见的文字，所以靠发音这类没显示出来的字段命中的行不会有标记，只打一个拉丁字母时太碎，也不标（中日韩文字一个字就标），`字段==内容` 这种整个相等的条件同样不标。
- **规则语法统一**：音变、正字法、文字映射、构形的微调、语素异体形的环境都用同一套规则写法。首页的「规则语法」或顶栏右上角的翻开的书图标（检视器按钮与关闭项目之间）会在右侧检视器里打开完整说明；在音变、构形、文字、音系、语素页打开时直接滚到相关的那一节。
- **书签页签**：文字、音变、构形里你自己建的多套内容（每套文字、每个规则集、每个构形）以书签页签排在标题右边，选中的那张与下方页面连成一片；「新建」按钮统一在最右。鼠标放到页签上，右侧会出现一支**铅笔**，点它把检视器里的「名称」聚焦，直接改名；构形的变体同理，点铅笔就地改名。按住页签左右拖，放到另一张页签上就换到那个位置。
- **拖着换顺序**：有先后的一串小圆框——构形的维度与流水线步骤、词类的组成与适用词类、检视器模块的适用语言、音位表里的音位、正字法、音变规则里的音类与多合字母、各处的标签，还有短语、语料的卡片——都可以按住一个拖到另一个上，松手就换到那个位置。拖的时候被拖的那个变淡、落点描一圈虚线；按在圆框里的输入框、下拉框上照常打字选字，不会拖起来。
- **板块可以收起**：内容多的板块（词类与维度、音位表与元音表、文字的音节拼合与自动映射、皮肤的词条卡与字体库……）标题右边有个平时不显示的三角，鼠标放上去才出现，点一下把整块收起来，下次打开还是收着；词类与维度里每个词类、维度、检视器模块还能单独收成一行。
- **长列表不卡**：词库只画看得见的几十行，滚到哪画到哪，滚动位置照旧记着（行高对齐到整数个物理像素，滚得再深表格也不发虚）；语素、语料、构形槽位、字形表先画一屏，滚到快见底再画下一批，切页面、改筛选都不卡。
- **第一次打开软件**会在开始页先走一遍图文引导（新建 / 打开、起步模板、最近打开、底部那排），最后交代右上角的「规则语法」；以后想再看，点各页标题旁的「使用指南」。
- **表格表头**（词库、语素）：点列名循环 ▼降序 → ▲升序 → 取消；列名右侧的漏斗打开筛选面板（全选 / 全不选 / 单选，第一列按首字母）；筛空了表头仍在，随时能取消；表头**最左侧**的小按钮切换自定义顺序，切换后同一列里出现上下移动按钮。双击一行打开检视器的录入模式。
- **导入样例**：各页的导入（词库、语素的 CSV，语料、短语的表格与 JSON，字形，Lexicanter，音变规则文件）都先在右侧检视器里显示导入后的样子；改了设置马上跟着变，变了的地方先高亮再慢慢褪掉，确认无误再点「导入」。
- **统计面板**（词库、语素、语料各一份）：同一套版式——数字卡、分布柱、排行；点分布里的一项会回到列表并按它筛选或搜索；并排的两块按矮的那块对齐，长的那块在里面滚动，鼠标放上去那块边框略微亮起。

## 示例项目

首页的「示例工程」按钮列出两个虚构语言项目，打开随便改但不能保存，想留着就「复制一份」（见[开始使用 · 首页](/cerf/qonlang/getting-started/#2-首页)）。两种完全不同的语言类型，合起来把每个模块的功能都摆了一遍：

- **Aelith**：黏着语，祖语 → 现代语的语系与姊妹语 Merun（kaso、teli 的关系图里点「对比」看同源词的音变与意思），元音和谐，多槽位后缀与流水线构形的每一种步骤、变体（基础那套改名叫「书面」）与继承，作用于所有词的连读浊化，复合词类与义项的词类，检视器模块（文化注释、用刻文字体显示的刻文异体），词源链与关系图，特征、重音规则与音节边界 σ（「书面语 → 口语」规则集，测试台每一列都带着 ˈ）、对重音影响（代词、小品词传了词性不重读，telikaso 标了特殊重音读 teliˈkaso）、姊妹语 Merun 的自定义重音规则（hara 标了特殊重音）、故意没写释义的 vesa（词库底栏点得到），一套卢恩刻文与一个手写的字（「刻痕句读」）、构形套构形（「动名词」加 -mAk 之后套名词的格：sörmek、sörmekde——sör- 在变位之外另外加了这个构形）、从这个动名词生成到词库的 sörmek（词源、关系自动填好），「Ael 语系」节点（点它看数量、音位对照、同源比例、对应词表），Aelith 内部的两个历时阶段 CAe → Ae 与词条的历史形式（kaso 显示 PAe kasu → CAe kaso → Ae kaso），名词复数各格从「复数.主格」继承、只接格后缀，位格影响发音（kasoda 读 ˈkasoða），按维度取值挑的异体形（复数标记在与格前是 -lAn：kasolanka），动词第三人称那几格故意不写、简洁模式下接着「极性.时」两个维度的槽位往下变，和已 gloss 并确认的例句（人名 Mira 故意没进词库，悬浮时是「没有找到」）。
- **Tsahun**：孤立声调语，声调、双正字法（音位填了罗马化写法，ts、ng 算一个音：强调重叠 tsing55 → tsitsing55）、音节文字拼合与竖排、文字的括号设置，`@词条` 引用推出带空格的屈折形（`ngo21 tui55`），同形词 hok33 的候选，用音节文字字体显示的「异体字」模块，按字号逐词写的意音文字「Tsahun 刻符」（语料、短语的文字行逐词查词库，虚词照原文）。

两个项目文件也在仓库的 `examples/` 里。
