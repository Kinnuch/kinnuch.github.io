# 语言

[← 指南目录](/cerf/qonlang/) · 导航栏第一项

「语言」页管理项目里的所有语言以及它们之间的谱系关系。一个项目可以只有一门语言，也可以是一整个语系。

## 1. 语系树

主区是一棵树：根语言在上，子语言缩进在下。每个节点显示名称、缩写、颜色，以及该语言的词条数 / 语素数 / 例句数。

- **新建语言**：顶部按钮。新语言默认没有父语言（平行语言）。
- **改变父语言**：在检视器里选「父语言」。软件会拒绝造成环的选择（A 的父语言是 B，B 的父语言又是 A）。
- **删除语言**：检视器底部。删除后可撤销；语言下的词条不会自动删除，只是失去归属，请先在词库里处理。

## 2. 语言属性（检视器）

| 字段 | 说明 |
|---|---|
| 名称 | 显示在各处的名字 |
| 缩写 | 用于文档页列表、导出文件名等紧凑场合 |
| 颜色 | 徽章颜色，方便在多语言项目里一眼分辨 |
| 父语言 | 语系树位置 |
| 模糊匹配时忽略的字符 | 关系图跨语言找词、词源来源搜索时，先去掉这些字符再比形式。比如喉音 `H1` / `H2` / `H3` 都算 `H` 就填 `1 2 3`，词根里分音节的点就填 `.`（空格随意）。变音符（长音符、成音节符号……）与大小写一直是忽略的 |
| 备注 | 自由文本 |

音系（音位、音类、正字法、音节、配列）与文字都挂在语言之下，但各自有独立页面编辑，见[音系](/cerf/qonlang/phonology/)与[文字](/cerf/qonlang/script/)。

## 3. 方言 / 语域

每门语言可以定义任意多个「方言」标签（也可以拿来当语域、时代、文体）。词条与义项可以勾选所属方言，短语与语料的标签也常用它。Lexicanter 导入时，其 lects 会自动变成这里的方言。

## 4. 当前语言

顶栏的「当前语言」下拉决定了大多数页面显示谁的数据：

- 音系、文字、词库、语素、构形测试台、语料、短语、文档只显示当前语言（文档还会显示「整个项目」的页面）。
- 选「全部语言」时词库、语素会列出所有语言的条目，多一列语言，表头漏斗可按语言筛选。
- 新建词条、例句、短语、文档时默认归入当前语言。

进入「语言」页时，树会自动选中当前语言。

## 5. 与其他模块的关系

- **音变**页里每个阶段快照可以绑定到一门语言；整库演化用这些绑定决定源语言和目标语言的默认值。
- **词库**的词源来源可以指向另一门语言的词条（继承、借词）。
- **文档**页可以归属某门语言，也可以是整个项目通用。
- **词库**的关系图、**词源**编辑器搜来源时，在哪门语言里找，就按那门语言的「模糊匹配时忽略的字符」比较。
