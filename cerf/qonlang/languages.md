# 语言

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/languages/) · 导航栏第一项

「语言」页管理项目里的所有语言以及它们之间的谱系关系。一个项目可以只有一门语言，也可以是一整个语系。

## 1. 语系树

主区是一棵树：根语言在上，子语言缩进在下。每个节点显示名称、缩写、颜色，以及该语言的词条数 / 语素数 / 例句数；分了[历时阶段](#历时阶段)的语言后面写着阶段缩写，如 `CAe → Ae`。

- **新建语言**：顶部按钮。新语言默认没有父语言（平行语言）。
- **添加分组**：顶部按钮，菜单里选「语系」「语族」「语支」。选着一个分组时，新分组建在它下面；选着一门语言时，建在那门语言所在的分组下。
- **改变父语言**：在检视器里选「父语言」。软件会拒绝造成环的选择（A 的父语言是 B，B 的父语言又是 A）。
- **删除语言**：检视器底部。删除后可撤销；语言下的词条不会自动删除，只是失去归属，请先在词库里处理。
- **搜索**：顶栏搜索也搜分组的名字和缩写，搜到的分组下面整个都显示。
- **拖着排**：列表里的卡片可以按住拖——拖到一张分组卡片上，这门语言就进那个分组；拖到一张语言卡片上，就成为它的子语言；分组拖到分组上就嵌进去。拖到一张卡片的**上边缘或下边缘**是插在两者之间（跟同级的换顺序）；拖动时树的最下面出现一条「放到最外层」，拖进去就挂到最外层。放不下去的落点整个描红，松手时卡片从指针那儿滑回原位。每一下都能 `Ctrl+Z` 撤销。

### 树状图

页面标题右边的「列表 / 树状图」切两种看法。树状图是一张从上往下画的谱系图：分组节点画成虚线框——语系 / 语族 / 语支只是用来结构化的，它的代表原始语排在分组节点下面，下一级的语支再挂在这门原始语下面（跟列表里的摆法一致）；一门语言的[历时阶段](#历时阶段)写成一行小字挂在它下方（`PThsr › AThsr › OThsr › Thsr`），鼠标停上去看完整的。滚轮缩放，按住空白处拖动平移，左上角有放大、缩小和「适应窗口」。点一个节点就选中它（跟列表里一样，顶栏的当前语言也跟着换）；**右键**一个节点收起 / 展开它下面的那一支，收起时节点下边挂一个小牌子写着「+几」——底下还有几个节点没画出来。拖着排只有列表里有。

### 语系 / 语族 / 语支

分组在列表里画成一个**虚线框，把里面的东西整个包起来**：标题行是层级徽标（语系、语族、语支）和名字，它的原始语、下一级分组、别的语言都在这个框里。原始语跟标题行左对齐（分组只是个分类，它的代表原始语不算低一级），下一级的语族、语支和别的语言往里缩一格。标题左边的箭头收起 / 展开这一组，收起时后面写着里面有几门语言（含各级下面的），收起状态记在本机。框上的「+」是「在这里添加语言」。点分组只选中它，不换当前语言。分组的检视器：

| 字段 | 说明 |
|---|---|
| 名称、缩写 | |
| 层级 | 语系 / 语族 / 语支 |
| 上一级 | 挂在哪个分组下面；「（不分组）」是最外层 |
| 原始语 | 可不填：这个分组的代表原始语。原始语本身还是一门普通语言，在框里排最前面，正好在语系和下一级的语族、语支之间 |
| 备注 | 自由文本 |

下面一行数出下一级分组几个、语言几门（含各级下面的）。「在这里添加语言」新建一门挂在这个分组下的语言；「删除」去掉分组，下一级分组和语言提到上一级，提示条上可以撤销。

一门语言在树里挂在哪：检视器「所属分组」选了分组、而父语言不在这个分组里时，挂在分组下；否则挂在父语言下。子语言自己没选分组时跟着父语言算进同一个分组，下拉里显示「（跟父语言同组）」。

### 统计与对比

选中一个分组，主区出现「「分组名」统计与对比」卡片，四个页签（选哪个会记住）：

- **数量**：分组下各级的每门语言一行，列出词条、语素、例句、短语，最后一行是合计。点语言名选中那门语言。
- **音位对照**：几门语言音位表的并集，一个音位一行，哪门语言有就在那一列打勾；最后一行是各语言的音位数。
- **同源比例**：一个矩阵，格子里是「行语言的词条里，在列语言里有同源词的占多少」，比例越高底色越深，鼠标放上去看是几个词。同源按词源算：两个词顺着词源往上追到同一个来源（词条、不是词缀的语素、祖语里写的形式），或者一个就是另一个的来源。
- **对应词表**：勾上要比的语言（至少两门），一个共同来源一行，各列是每门语言里从它来的词；几层来源底下正好是同一批词时只列最近的那层。只列前 300 行；点词跳到词库里那一条。

### 两门语言的对比

想直接比两门语言，不必先建分组：选中一门之后，按住 `Ctrl`（macOS 是 `Cmd`）点第二门语言，或者点卡片上的「加入对比」。

- 上方出现一条，写出这两门语言和它们的**最近公共祖先**（碰不到一起时写「没有，两条谱系碰不到一起」）。公共祖先**只在语言里找**：语系 / 语族 / 语支只是用来结构化的，不会被当成公共祖先；一门本身就是另一门的祖先时，写的就是那门祖先。
- 这两条谱系一路到公共祖先的节点与连线闪着虚线标出来，列表和树状图里都标。
- 下面的统计卡片改成只比这两门：数量、音位对照（每行后面写着「共有 N 个 · 只有 A 有 N 个 · 只有 B 有 N 个」）、同源比例、对应词表，页签跟分组的统计一样。
- 点「清除对比」回到原样。

## 2. 语言属性（检视器）

| 字段 | 说明 |
|---|---|
| 名称 | 显示在各处的名字 |
| 缩写 | 用于文档页列表、导出文件名等紧凑场合 |
| 颜色 | 徽章颜色，方便在多语言项目里一眼分辨 |
| 父语言 | 语系树位置 |
| 所属分组 | 挂在哪个语系 / 语族 / 语支下（见上）。子语言选「（跟父语言同组）」就跟着父语言 |
| 历时阶段 | 这门语言内部的几个时期，见下 |
| 模糊匹配时忽略的字符 | 关系图跨语言找词、词源来源搜索时，先去掉这些字符再比形式。比如喉音 `H1` / `H2` / `H3` 都算 `H` 就填 `1 2 3`，词根里分音节的点就填 `.`（空格随意）。变音符（长音符、成音节符号……）与大小写一直是忽略的 |
| 备注 | 自由文本 |

音系（音位、音类、正字法、音节、配列）与文字都挂在语言之下，但各自有独立页面编辑，见[音系](/cerf/qonlang/phonology/)与[文字](/cerf/qonlang/script/)。

### 历时阶段

一门语言分几个时期（上古 → 中古 → 现代），又不想拆成几门语言时用。检视器「历时阶段」旁点「添加阶段」，每个阶段填阶段名和缩写，按时间先后排、最早的在上；右边的箭头上移、下移，× 删掉。音系、词库还是整门语言一套，阶段只是标明时期：

- 树里语言后面写出阶段链，如 `CAe → Ae`。
- 音变的阶段标记可以绑到这门语言的某个阶段（见[音变 · 阶段快照与语言绑定](/cerf/qonlang/sound-changes/#2-阶段快照与语言绑定)）。
- 词条可以标属于哪个阶段（词库录入模式的「历时阶段」，留空是最新阶段）；词条卡上的「历史形式」按阶段缩写显示（见[词库 · 历史形式](/cerf/qonlang/lexicon/#history)）。

### 合并为阶段

以前把上古语、中古语、现代语建成了几门父子相连的语言，想改成一门语言的几个阶段：选中最新的那门（要有父语言），在「历时阶段」下面的下拉「从哪一门开始合并为阶段…」里挑从哪一门祖先开始，点「合并为阶段」，确认。合并时：

- 链上每门语言变成最新这门的一个阶段（本来就分了阶段的，把它的几个阶段搬过来），最新这门自己也补一个阶段；
- 词条、语素、例句、短语、文档都挪到最新这门语言，词条和语素记下原来属于哪个阶段；
- 音变里绑到被合并语言的阶段标记，改绑到「最新这门语言 · 对应的阶段」；
- 正字法、文字、方言按名字对上；对不上的文字和方言搬过来，对不上的正字法下的发音丢掉，提示条里写着丢了几条；
- 音系只留最新这门语言自己的；
- 挂在被合并语言下面的别的语言，改挂到最新这门语言。

合并能用 Ctrl+Z 撤销。

## 3. 方言 / 语域

每门语言可以定义任意多个「方言」标签（也可以拿来当语域、时代、文体）。词条与义项可以勾选所属方言，短语与语料的标签也常用它。Lexicanter 导入时，其 lects 会自动变成这里的方言。

## 4. 当前语言

顶栏的「当前语言」下拉决定了大多数页面显示谁的数据：

- 音系、文字、词库、语素、构形测试台、语料、短语、文档只显示当前语言（文档还会显示「整个项目」的页面）。
- 选「全部语言」时词库、语素会列出所有语言的条目，多一列语言，表头漏斗可按语言筛选。
- 新建词条、例句、短语、文档时默认归入当前语言。

进入「语言」页时，树会自动选中当前语言；在树里（或检视器的谱系里）点一门语言，顶栏的「当前语言」也跟着换成它，反过来在顶栏换了当前语言，树里也选中它。

## 5. 与其他模块的关系

- **音变**页里每个阶段快照可以绑定到一门语言（分了历时阶段的，还能挑哪个阶段）；整库演化用这些绑定决定源语言和目标语言的默认值，词条卡的「历史形式」也靠它们一路推下来。
- **词库**的词源来源可以指向另一门语言的词条（继承、借词）。
- **文档**页可以归属某门语言，也可以是整个项目通用。
- **词库**的关系图、**词源**编辑器搜来源时，在哪门语言里找，就按那门语言的「模糊匹配时忽略的字符」比较。
