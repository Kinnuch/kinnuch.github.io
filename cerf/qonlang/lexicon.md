# 词库

[← 指南目录](/cerf/qonlang/) · 导航栏第六项

词库是项目的核心：每条记录是一个**词位**（lexeme）——词头、词类、义项、词源、词干与屈折形、发音、文字写法、关系、标签。

## 1. 两个子页、两种模式

- **词条**：列表 + 检视器。
- **词类与维度**：定义词类（名称、缩写、绑定的范式）和语法维度（如「数：单 / 复」「格：主 / 宾 / 位」，每个取值有名称与缩写）。这些都是项目数据，软件不预设任何术语。

「词条」子页有两种模式：

- **显示模式**：检视器是只读的词条卡，排版简约，适合查阅：词头、文字、发音、词类、维度取值、义项、标签、词源、屈折形、关系、派生词。卡里的词都可以点，跳到那个词。
- **录入模式**：检视器变成表单，逐字段编辑。

顶部还有「关系图」按钮：以当前词为中心画出派生、组成、同源、近义等关系的图，点节点切换。

## 2. 列表

- 搜索词头或释义；按词类、标签筛选；「全部语言」时可按语言筛选。
- **列**按钮自定义显示哪些列：词类、各释义语言、标签、原始形、发音、各维度、各词干槽、各屈折形、各套文字、更新时间。选择存在项目设置里。
- 排序：字母表（按当前语言的自定义字母表，没有则按 Unicode）、最近修改、按词类、**自定义顺序**（选中后每行出现上下移动按钮，顺序存在项目里）。
- 重复词头会有警告图标。

## 3. 词条字段（录入模式）

| 字段 | 说明 |
|---|---|
| 词头 | 按主正字法录入 |
| 词类 | 从「词类与维度」里选 |
| 维度取值 | 该词的固有语法特征（名词类别、性等） |
| 方言 | 语言页定义的方言标签 |
| 义项 | 多个，每个含各释义语言的释义、标签、语域、方言、例子 |
| 词源 | 类型（词根派生 / 复合 / 借词 / 派生 / 继承（音变）/ 未知）、原始形、来源列表（指向语素、词条或外部语言的形式）、备注 |
| 词干 | 自定义词干槽（名称 → 形式），范式生成器可引用 |
| 屈折形 | 由范式推导或手填，见下 |
| 发音 | 每套正字法一个 IPA；勾「!」表示不规则，重新标音不会覆盖 |
| 文字写法 | 每套文字一个，留空则按映射规则自动生成 |
| 配图 | 若干张图 + 说明。统一尺寸在「设置 → 词条配图尺寸」（默认 320×240）：尺寸相符的原样保存，比例相同的等比缩放，其余弹出裁剪框（拖动选区、滚轮 / 滑块缩放）。PNG / GIF 无损保存，JPEG / WebP 沿用原格式高质量编码。显示模式下首图在词头右侧，其余为缩略图 |
| 关系 | 种类（同义 / 反义 / 相关 / 自定义…）+ 目标词 |
| 标签、备注 | |

## 4. 屈折形与范式

词类绑定了范式后，录入模式会出现**槽位面板**：每个槽位（如「复数.宾格」）一格，可以点「推导」让范式生成器填入，也可以手填。手填的格子标为覆盖，之后批量推导不会动它。范式页还有「对账」功能，比较推导结果和手填值的一致率。

槽位标签是维度取值名用 `.` 连接（如 `复数.宾格`），CSV 导入时列名与之相同即可直接进屈折形。

## 5. 导入

- **CSV**：向导里选文件或直接粘贴表格（TSV），逐列指定含义：词头、词类、释义（某语言）、标签、原始形、备注、维度、词干、屈折形、忽略。列映射可存为预设。目标可以是词条或语素。
- **Lexicanter**：读 `.lexc`，词库、义项、方言、发音规则、字母表、词源、短语簿、文档一次进来，并报告数量。

## 6. 导出

导出菜单：

- **词条 CSV / 语素 CSV**：全字段表格。
- **导出词典 / 模板…**：打开面板——
  - **HTML**：双栏打印样式，按首字母分组，词头、文字、发音、词类、义项、词干与屈折形、词源、备注（各项可选，义项语言可选）。
  - **Markdown**：适合放进 wiki。
  - **PDF**：桌面版直接输出文件，网页版走打印对话框。
  - **逐条模板**：`{{lemma}} {{ipa}} {{pos}} {{script}} {{definition}} {{etymology}} {{notes}} {{tags}} {{language}}`，块 `{{#senses}}{{n}} {{text}} {{lang}}{{/senses}}`、`{{#forms}}{{label}} {{text}}{{/forms}}`。右侧实时预览前几条；模板可保存进项目，导出文本或复制。

## 7. 联动

| 来源 | 表现 |
|---|---|
| 音系 → 正字法规则 | 「发音」自动生成 |
| 文字 → 映射规则 | 「文字」列与词条卡的文字行 |
| 范式 | 槽位面板、屈折形、词条卡的屈折表 |
| 语素 | 词源来源 |
| 语料 | 悬停例句里的词显示本页的词条卡，点击跳回这里并选中 |
| 文档 | `[[词头]]` 链接跳到这里 |
| 命令面板 | `Ctrl+K` 搜词头或释义直接定位 |

## 8. 提示

- 删除词条可撤销；引用它的关系与词源会显示为 `?`，不会报错。
- 多语言项目里想批量看祖语与子语言的对应，用「全部语言」+ 列里勾「原始形」。
- 想把词库贴进自己的网站，优先用逐条模板，输出格式完全由你定。
