# 词库

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/lexicon/) · 导航栏第六项

词库是项目的核心：每条记录是一个**词位**（lexeme）——单词、词类、义项、词源、词干与屈折形、发音、文字写法、关系、标签。

## 1. 子页与模式

- **词条**：列表 + 检视器。
- **统计**（需先在顶栏选一门语言）：版式与操作见[通用操作习惯](/cerf/qonlang/#通用操作习惯)。指标：词条总数、有释义 / 发音 / 词源 / 屈折形 / 配图 / 关系的数量与占比、语料里出现过与没出现过的、义项数、平均词长、同形词头、近期新增；分布按词类、标签、首字母、词长、词源类别、方言、各维度（词类、标签、首字母、各维度可点，回列表按它筛选）；排行是语料里最常用的词条，点了跳到那条。
- **词类与维度**：定义词类（名称、缩写、绑定的构形、词干槽、复合词类的组成）和语法维度（如「数：单 / 复」「格：主 / 宾 / 位」，每个取值有名称与缩写）。这些都是项目数据，软件不预设任何术语。
  - **改名跟着走**：词条的词干按词干槽的名字存、屈折形按槽位名（取值名用 `.` 连接）存。给词干槽或维度取值改名，改完离开输入框时，用到它的词条里旧名下的内容挪到新名下，词库的「列」、文字的「转写来源」、构形流水线里写的词干名也一起改，提示条会说挪了几个词条；新名下已经有内容的不动。词类名、缩写、维度名本来就按内部编号存，改了立刻反映到词库。
  - **词干槽**：这个词类的词条有哪几个词干，比如名词的强形 / 中形 / 弱形、动词的词干元音。每个槽写名称和说明（从哪来、怎么用），点「+ 词干槽」添加。录入模式里这个词类的词条会按槽逐个列出词干输入框，构形流水线的「词干」下拉也从这里给候选。
  - **复合词类**：词类卡片下方的「组成」里加上几个词类，这个词类就是它们组成的复合词类，比如一个词既是名词又是动词时用「名词/动词」（名字、缩写没改过时按组成自动拼成 `名词/动词`、`n./v.`）。「组成」里的圆框按住拖可以换先后，名字、缩写没改过时跟着重拼。复合词类自己没绑构形、没设词干槽时沿用组成词类的（构形用第一个绑了的）；按词类筛选、`pos=` 搜索、整库演化的词类过滤都把组成算上。
  - **维度只给某几个词类用**：语法维度卡片里的「用于词类」加上几个词类，词条录入时就只列出对得上的维度（已经填了值的照样显示）；不选就是所有词类。
  - **检视器模块**：页面最下面点「新增模块」，给词条加一块词库本身没有的内容，比如意音文字的异体字、文化注释、地域分布，不用等软件为某门语言加字段。每个模块写标题（按释义语言），选内容是「一段文字」还是「几项（顿号隔开）」，选放在词条卡的哪里：释义上方 / 释义与词源之间（默认）/ 词源下方 / 最下面；「用于」可以只给某几门语言，「字体」可以用某套文字的字体显示（异体字这类）；「导入时也认的列名」里写上表格里可能出现的列名。
    录入模式里按同样的位置出现输入框，词条卡里显示成一节（「几项」一项一个框）。顶栏搜索可以写 `标题=内容`，词库的「列」里也能把它加成一列。删掉模块时各词条里填的内容一起删，可以撤销。
  - **逐条收起**：每个词类、维度、检视器模块前面有个小三角，点一下收成一行——名字、缩写，后面小字写着它绑的构形、词干槽、取值、用于哪些词类；每块标题旁的「全部收起 / 全部展开」一次收放整块。收起状态记在本机，下次打开还是收着。

「词条」子页有两种模式：

- **显示模式**：检视器是只读的词条卡，排版简约，适合查阅：词头、文字、发音、词类、维度取值、义项、标签、词源、历史形式、词干、屈折形、关系、派生词，以及自己加的检视器模块。词源、历史形式、词干、屈折形各是单独一块（屈折形只列构形推出来的形式，词干另算一块），卡片的字号与各块顺序在「[皮肤](/cerf/qonlang/skin/) → 词条卡」里逐块调；发音两边的符号（`/…/`、`[…]`、不加）在「设置 → 应用」里选。义项的语域显示成方框标签（中文取一个字，如 `文`；英文显示缩写，如 `lit.`），「设置 → 词条卡里语域的显示」可以改成全称；义项自己选了词类、又跟词条的不一样时（复合词类的词条常见），释义前面用淡色标出它的缩写（如 `n.`）；例句列在词条卡下方，用分割线隔开。卡里的词都可以点，跳到那个词。
- **录入模式**：检视器变成表单，逐字段编辑。

**历史形式** <a id="history"></a>：显示模式里词条卡和例句之间可能有一行「历史形式」，把这个词从来源一路推下来的形式连成一串，如 `PAe kasu → CAe kaso → Ae kaso`。出现的条件：词源来源是词条、语素，或者语言名对得上某门语言、某个[历时阶段](/cerf/qonlang/languages/#历时阶段)的自定义来源，并且有一套音变规则集，从来源所在的阶段到这个词所在的阶段，中间每个阶段标记都绑了语言（或语言的某个阶段）。每一步前面的标签是阶段缩写，没有就用语言缩写，再没有用阶段标记名；行首的规则集名点了跳到那套音变。推到最后跟词库里的写法对不上时，旁边标出「不一致」（鼠标放上去写着「按音变推到最后跟这个词的写法对不上，检查规则或词源」）。默认顺序里这一块排在词源与词干之间；不想看的话，「设置 → 应用 → 显示 → 词条卡里显示历史形式」可以整块关掉（默认开）。

**改某一步**：推得不对的那一步，点一下那个形式，填上正确的写法，回车（或者点到别处）——这个写法存进词源的**中间态**，后面每一步都从改过的接着推。改过的那一步用强调色显示、后面带一支小铅笔，旁边的 ↺「改回推出来的形式」把它撤掉；填成跟推出来的一样、或者清空，也等于撤掉。只有词库检视器里能改，悬浮词卡与开始页画廊里的卡片只显示这一行。

顶部还有「关系图」按钮 <a id="graph"></a>：以当前词为中心画出派生、组成、同源、近义等关系的图，点节点切换。自定义来源与中间态里拼接的形式（`gēs-sal`、`a + b`、`x·y`）会拆成多个节点，每个成分到来源语言里找同形的词条或语素，找到的可以点过去——这就是跨语言跳转。比较形式时忽略变音符与大小写，以及来源语言设置的「模糊匹配时忽略的字符」（见[语言](/cerf/qonlang/languages/)）。点了别的语言的词，按「返回」会回到原来那门语言的那一条。

- **拖动与缩放**：按住空白处拖动画布；Ctrl + 滚轮以指针为中心缩放；左上角三个按钮是放大、缩小、回到中心。
- **展开与收起**：右键节点，「展开以它为中心的节点」把它自己的来源、派生、同源、关系……再画一圈，已经在图上的词不重复画，只连一条线；「收起以它为中心的节点」把这一圈收回去（从它那里展开出去的也一起藏起来，再展开时照旧）。中心词也能收起、再展开。语素节点展开能看到用到它的词条（来源里直接挑了这个语素的，和自定义来源里写到它的）；对不上词条的来源成分（虚线框）展开能看到来源里写到它的词。右键词条节点还有「以它为中心」。空白处右键是「回到中心」「全部收起」。
- **对比** <a id="compare"></a>：跟中心词同一个词根来源的词有两个以上时，画布右上角出现「对比」和组数。词根按词源一路往上找（词条、语素，以及自定义来源按语素边界拆开的每个成分），前缀、后缀、中缀、环缀、附着词这类语素不算词根；中心词自己也是它派生出来的词的词根。对比视图里：
  - 上面一排是几组词根（跨语言的排前面，其次离中心词近的、词少的），下面勾要比的词，最多 6 个；
  - 表里一列一个词：发音；意思（几个词共有的意思成分标底色）；来源（从词根到这个词的每一步和词源类别）；构成（一路加进来的其他成分——前缀、后缀、复合的另一半——只有部分词有的高亮）；音变（找一个音变规则集，它有绑定到来源语言的阶段、后面又有绑定到这个词的语言的阶段，把来源形重新推一遍，列出每个阶段的形式和用上的规则；推出来跟词库里的写法不一样时标黄）；词类、语域、标签、方言（不一样的标出来）；点列头的词换成以它为中心；
  - **音变差异**：几个词是同一套规则推出来的时候，按规则逐行列出每个词在这条规则前后的形式，默认只看部分词经历了的（勾「显示全部」看全部）——比如同一个词根带不带前缀，走的音变不一样；
  - **语音对应**：不同语言、直接从词根来的词（没有另外加成分）有两个以上时，列出词根里的每个音在各个词里变成了什么，只列有变化的，`∅` 是脱落。
  - 示例工程 Aelith 里打开 kaso 或 teli 的关系图点「对比」，就能看到跟姊妹语 Merun 的同源词（hasu、tel）的音变、语音对应与意思的差别。

## 2. 列表

- 搜索词头、释义、屈折形、发音；也可以只搜一个字段：`word=`（单词）、`gloss=`（释义）、`form=`（屈折形）、`stem=`（词干）、`ipa=`（发音）、`pos=`（词类）、`tag=`（标签）、`register=`（语域）、`etym=`（词源）、`note=`（备注）、`script=`（文字）、`feature=`（语法维度的取值；也可以直接拿维度名当字段，如 `性=阴`）、`dialect=`（方言），或者 `/正则/`，写法见[通用操作习惯](/cerf/qonlang/#通用操作习惯)。表头排序与漏斗筛选见[通用操作习惯](/cerf/qonlang/#通用操作习惯)；本页可筛的列：首字母、词类、标签、各维度、方言，「全部语言」时多一列语言也可筛。要按最近修改排序，先在「列」里勾上「修改时间」再点它的列名。
- **列**按钮自定义显示哪些列：词类、各释义语言、标签、词源、发音、各维度、方言（语言里定义了方言才有）、各词干槽、各屈折形、各套文字、修改时间。选择存在项目设置里。不同来源撞出同名的列时，列表上方会给出提醒，建议回到来源处改名。
- 列宽按表格所在区域**铺满**，右边不留空：没拖过的列按种类给默认宽（释义宽一些，词类、维度窄一些）；加了列先按比例匀出已有各列的宽，每列不低于最小宽，实在放不下才横向滚动。每列右缘可以**拖动改宽**，右边紧挨的那一列反着让，列宽记在本机偏好里；列菜单底部有「重置列宽」。
- 多个词条有多个义项时，释义列显示成「1、… 2、…」。
- 默认按字母表排序（当前语言的自定义字母表，没有则按 Unicode）；表头最左侧的按钮切**自定义顺序**，顺序存在项目里。
- 重复的单词会整行淡黄高亮，并带一个警告图标。不想要高亮可以在「设置 → 高亮重复词条」里关掉，只留图标。检视器里还有「尝试合并」：把同语言的同形词条并成一条，义项按顺序接起来；词类不一样时各义项记下自己原来的词类，合并后的词条设成它们组成的复合词类（如 `n./adj.`）。合并可撤销。
- **没写释义**的词条标红：行底色淡红，词头旁一个红色圆圈。
- 列表底部右边是**状态栏**：缺释义（红）、词头重复（黄）各有几条；鼠标放到徽章上列出是哪些词条，点一条就跳过去（清掉搜索与筛选、滚到那一行闪一下）。都没有时写「没有问题」。
- 按住 `Ctrl` 逐个点选、按住 `Shift` 选一段。选中多条后列表上方出现一条：「批量标签」「删除」「取消选择」。
- **批量标签**：点「批量标签」打开一个小面板。上面的框里输入标签、按回车（或点「加上」），选中的词条全都加上这个标签。下面列出选中这批词条**已经用过**的每个标签，后面写着有几条带着它（`3/5`），再往后三个按钮：加给还没有的那几条、改名（只改选中的这些词条）、从选中的词条上去掉。
- **双击**一行：选中这一条，右侧检视器打开并切到录入模式，直接改。

## 3. 词条字段（录入模式）

| 字段 | 说明 |
|---|---|
| 单词 | 按主正字法录入（旧称「词头」） |
| 词类 | 从「词类与维度」里选 |
| 历时阶段 | 语言分了[历时阶段](/cerf/qonlang/languages/#历时阶段)时才有：这个词属于哪个阶段，默认「（最新阶段）」。历史形式按它算 |
| 维度取值 | 该词的固有语法特征（名词类别、性等） |
| 方言 | 语言页定义的方言标签 |
| 义项 | 多个，每个含各释义语言的释义、语域、方言、例子。语域可以填几个（回车添加），给了日常 / 正式 / 口语 / 文学 / 宗教 / 神祇等常用值，也可以自己填。义项序号旁可以单独选这个义项的词类（默认「词类跟词条」，复合词类的词条先列出它的组成） |
| 词源 | 读作「来源 > 中间态… > 本身」的一条链，见下 |
| 词干 | 词类里定义了词干槽的，按槽逐个列出（输入框里的灰字是槽的说明，没填就用词头）；另外也可以给单个词加自定义词干（名称 → 形式），名称填完按 Tab 直接跳到旁边的形式框，改成已有的名称会提示重名、不改。构形流水线的「词干」引用它们 |
| 屈折形 | 由构形推导或手填，见下 |
| 发音 | 每套正字法一行「基于正字法的 IPA」（有几套正字法时写成「基于正字法的 IPA（正字法名）」）：按那套正字法的转音标规则从拼写推出来。勾「!」表示不规则，是手填的，重新标音不会覆盖 |
| 对重音影响 | 默认不勾。勾上后出现「传递词性」「传递特殊重音」：传递词性时，重音规则里写了 `<词类>` 的条目按这个词的词类挑；传递特殊重音时选重音落在第几个音节、倒数第几个或不重读，规则里写了 `@` 的就按它（见[重音规则](/cerf/qonlang/sound-changes/#stress-rules)）。改了马上重新标音 |
| 文字写法 | 每套文字一个，留空则按映射规则自动生成 |
| 配图 | 若干张图 + 说明。统一尺寸在「设置 → 词条配图尺寸」（默认 320×240）：尺寸相符的原样保存，比例相同的等比缩放，其余弹出裁剪框（拖动选区、滚轮 / 滑块缩放）。PNG / GIF 无损保存，JPEG / WebP 沿用原格式高质量编码。显示模式下首图在词头右侧，其余为缩略图 |
| 关系 | 种类（同义 / 反义 / 相关 / 词根 / 复合 / 派生 / 音变 / 借词 / 自定义…）+ 目标词。在词源里挑了词条来源后会自动补一条同名关系。种类下拉里选「自定义」后旁边出一个输入框，**打完回车或者移开焦点**才算数（不会打了一个字母就把输入框收走） |
| 标签、备注 | 标签按住拖到另一个标签上可以换先后 |

语素来源里的**环缀**在链条、词条卡、「来源」列与关系图里都写成「前半…后半」（如 `e…ce`）。

**一处写了几个异写**：单词、词干、屈折形里用斜线或逗号分开几种写法（`fóros/fauros`）时，每种写法各自入索引——语料、例句里写哪一个都认得出是这个词；语料原文里也这么写的词（`Degnes/Degnant`）同样认得出。

**隔开写的词**：单词里用 `…`（或 `...`）分成几段（`ma…gò`），表示这个词在句子里是隔着别的词写的。语料里 `ma 某某某 gò` 也认得出来，每一段挂上同一个词条、gloss 一样，文字那一行每段只写自己那一半（见[语料 · 自动分析](/cerf/qonlang/corpus/#2-自动分析)）。

## 4. 词源链

词源不再是一个「原始形」输入框，而是一条链：

```
[来源]  >  [中间态 A]  >  …  >  本身
```

1. 先选**类别**：词根、复合、派生、音变、借词、继承、未知，或者自己填一个。
2. 类别决定来源怎么挑：词根去**语素**里找（显示时前面加 `*`），复合在**词库**里找 A + B，借词用自定义来源（语言 + 形式 + 意义）。
3. 需要记历史上的过渡形式时，加**中间态**，可以加多个，按时间顺序排。
4. 挑了词条来源后会自动进关系图；**语素**也有同样的词源编辑器，于是语素与词条的关系图连成一片。

## 5. 屈折形与构形

词类绑定了构形后，录入模式会出现**槽位面板**：每个槽位（如「复数.宾格」）一格，可以点「按构形推导」让生成器填入，也可以手填。手填的格子标为覆盖，之后批量推导不会动它。

手填过的格子随时能**重新按构形推**：每个这样的格子旁边一个 ↺「恢复推导值」（表格、树形图里在格子右上角），点了就按构形重推这一格。「按构形推导」旁边还有「**全部重推**」，连手改过的形式一起，把每一格都按构形重推一遍。

面板上方还可以给这个词**指名一个构形**（不按词类走）和**选一个变体**；换了之后推导出来的形式会重算，手填的不动。词类绑了几个构形时（比如动词的变位法一、变位法二，见[构形 · 结构](/cerf/qonlang/paradigms/#1-结构)），下拉里「这个词类的构形」单列一组，第一项「按词类」后面写着默认的是哪一个。构形页标题旁的「一致性检查」比较推导结果和手填值的一致率。

一个词还按**另一个构形**变（比如既是名词又是动词：一个变格、一个变位）：点屈折形旁边的「加一个构形」，再在构形下拉下面新出来的那一行挑是哪个构形、哪个变体（右边的 × 去掉）。也可以再挑**同一个构形的另一个变体**（书面一套、口语一套）。槽位面板按每一套分组，组名是构形名，挑了变体时后面带上变体名；跟前面重名的槽位，名字前面加「这一套的名字·」，几套形式各存各的。「推导」把每一套的槽位都推一遍。

推导出来的每一格旁边有**生成词条**：弹出新词条表单，词头是这个形式，词源（派生 ← 这个词，备注写构形与槽位）和关系（派生 → 这个词）已经填好，词类、构形、各释义语言的释义、标签可以现填，点「生成」；这门语言里已经有同样的词头时表单里会提醒一句。点「**只生成形式、词源和关系**」就不填别的直接建——这样的词条没有释义，词库里会标红提醒。建好后提示条上点「在词库中查看」跳过去。构形页测试台里的结果也能这样生成。

屈折形有三种看法，标题右边三选一（录入模式一直显示，显示模式把鼠标放到这一块上才出现，两边用同一个选择）：

- **列表**：一格一行，默认。
- **表格**：第一个维度作行、第二个维度作列，第三个维度起每种取值各一张表（表上写着是哪一种，如「人称 第一人称」）。录入模式里格子就是输入框，可以直接在表里填。
- **树形图**：按维度一层层分叉，叶子是各个形式；分叉点可以收起。

选好的看法**悬浮词卡和开始页画廊里的词条卡也照着显示**（那里只看，不给切换）。

构形里生成器选了「组合（流水线）+ 影响发音」的槽位（见[构形 · 影响发音](/cerf/qonlang/paradigms/#slot-pron)），推导时把发音也存在形式上，词条卡里列表、表格、树形图三种看法都在形式后面用小字跟着这个发音。

标题右边还有个三角，**把整块屈折形收起来**（显示、录入两种模式各记各的），收起后写着「几格、填了几个」，再点一下展开。

槽位标签是维度取值名用 `.` 连接（如 `复数.宾格`），CSV 导入时列名与之相同即可直接进屈折形。

## 6. 例句

词条下方会列出**用到这个词的例句**，语料、短语、文档都算：语料按分析里认的词条算，没认出的词再按词头、屈折形整词比；词干不拿来比（词干槽里常只是词根、词干元音这种不单独成词的片段），带连字符的词头（`al-`）只认它的屈折形；一个词已经确认成了别的词条，写法一样也不算。默认 3 条（在「设置 → 词条下方默认显示的例句条数」里改）。点「查看全部例句」弹出一页，把所有出处列出来，往下滚动才继续加载，词多也不卡。

**这个词在句里的位置标出来**：整词对上的标整个词；认的是屈折形，或者只是复合词、带词缀的词里的一段时，只标那一段。原文手改过、分词结果旧了这类定不下来位置的，仍然算这条例句，只是不标。

「[设置](/cerf/qonlang/settings/) → 应用 → 显示」里勾上「词条下方的例句也显示文字行与出处」之后，每条例句上面多一行这门语言各套**文字**的写法（跟语料页一样），后面也带上**出处**；默认不勾。

一个词条有**几个义项**、语料里整词正好对上它时，候选里每个义项各给一条（gloss 各取各的释义），挑得出这里是哪个意思。

## 7. 导入

- **导入样例**：导入时右侧检视器显示「导入样例」——按现在的设置导入后前几条是什么样子（单词、词类、义项的词类与语域、标签、发音、词源等）；改了列映射、选项、标记的处理，样例马上跟着变，变了的地方先高亮再慢慢褪掉。项目里已经有同名单词的标「已有同名」。
- **CSV**：向导里选文件或直接粘贴表格（TSV），逐列指定含义，下拉里按「导入为」只列能填的字段：词条可以填单词、语言、词类、释义（某语言）、语域、义项标签、标签、方言、语法特征、发音（哪套正字法）、文字写法（哪套文字）、词源类别、词源来源（来源语言）、词源中间态（说明）、词源说明、关系（种类）、词干、屈折形、构形、构形变体、备注（前缀）、检视器模块（标题）、对重音影响；语素可以填形式、语言、类型、第二形式、gloss、意义、异体形、语法特征、标签、词源各项、备注、对重音影响。列映射可存为预设。目标可以是词条或语素。向导右上角的「格式说明」打开下面的 [CSV 格式](#csv-format)。
  - 勾上「释义按分号拆成多个义项」（默认开）后，`A；B；C` 会变成三个义项，列表里显示成「1、A 2、B 3、C」；原文里已有的 `1、` 编号会去掉。
  - **释义开头的编码**（目标为词条时）：释义开头紧挨着文字的数字（「1离开；2前往」；「1、」这种序号和「2020年」这种长数字不算）识别到了才出现这张表，逐个选：**设为义项标签**（右边填标签，比如 `1` → 一价，填了就自动设为标签）、**只去掉编码**、**原样保留**（默认）。编码可以连写（`01` = `0` + `1`）。选择随列映射预设一起保存，老预设里写的「编码=标签」自动转过来。
  - **方括号标记**（目标为词条时）：单词、释义、备注里出现 `【专】`、`【神】`、`〔古〕`、`[arch.]` 这类标记时，选项下方会列出每种标记的次数、所在列和一个例子，逐个选怎么处理：**设为语域**（默认，右边填语域名，比如「古」→「古语」，也可以从常用语域里挑）、**设为义项标签**、**只去掉标记**、**原样保留**。
    - 序号（`1、`、`2.`、`3)`）后面紧跟的第一组括号也算标记，圆括号也一样：「1、（古）宅第；2、（方）玉米」与「【古】宅第；【方】玉米」一样处理，序号照常去掉。
    - 小括号算不算标记由选项里的「小括号也识别成语域等标记」管（默认勾着）：不勾时这一条和下一条里的小括号一律原样留在释义里，不进标记表，只认 `【】`、`〔〕`、`[]` 这类括号。这一项随列映射预设一起保存。
    - 词类缩写（`n.`、`adj.`）后面紧跟的第一组圆括号也算，括号里可以是几个词：`n. (archaic) she-cat`、`adj. (slang, vulgar) …`；设为语域时逗号隔开的算几个语域。括号里像一句说明的（`(placed before the noun)`、`(+ abs.)`）默认原样保留，要设成语域或标签就在表里改。同一个词类缩写管着的后几个义项（`n. (a) …; (b) …`）开头的括号也算。
    - 释义里的标记管到下一个标记或分号为止，前后拆成不同义项：「房屋；【古】宅第」是两个义项，第二个的语域是「古语」；「经常的【引】流动的」也拆成两个。
    - 备注里以标记开头的一段（`【人】某某`）变成新的义项，其余仍是备注；单词前的标记管整个词条的每个义项。
    - 紧挨字母的方括号（`colo[u]r`）、后面没跟文字的括号（行尾的音标）、纯数字的脚注、前面既没有序号也没有词类缩写的圆括号都不算标记。选择随列映射预设一起保存。
  - **词类标记**（目标为词条时）：释义开头像 `n.`、`v.`、`adj.`、`v因.` 这样「拉丁字母 + 几个字 + 点」的写法（序号、方括号标记后面的也算，`n./v.` 这样隔开的算两个）列在「词类标记」表里，同样逐个选：**设为词类**（右边写词类名；常见缩写已经对好，如 `n.` 名词、`v.` 动词、`adj.` 形容词）、**设为义项标签**、**只去掉标记**、**原样保留**。右边写已有词类的名字或缩写就用那个词类，旁边标「已有」；写 `名词/动词` 这样斜杠连着的是复合词类；项目里没有的标「新建」，导入时建出来。认不出来的长串（`house.`、`e.g.`）默认原样保留。
    - 一个词类标记管到同一格里下一个词类标记为止：「n.石头；卵石；v.跑」前两个义项是名词、第三个是动词。
    - 词类标记后面紧跟方括号标记也行（`n.[中古][文学]金石`），不会切出一个只剩 `n.` 的义项。
    - 一个词条的义项都是同一个词类时，这就是词条的词类；分属几个词类时，词条设成它们组成的复合词类，义项各自记自己的。表里有词类列时词条的词类以那一列为准，词类列里写 `n.`、`n./v.` 也按这张表认。选择随列映射预设一起保存。
  - **链到项目里已有的东西**：词源来源填了来源语言、而且是项目里的语言时，同形的单词或语素直接链过去（`kal ‘石头’ + ri` 拆成两个来源，引号里是意义），找不到的记成外部来源；关系按单词名找目标（先找同一门语言，这次导入的其他行也算），找不到的在报告里列出；方言按名称或缩写找，没有的新建；构形、构形变体按名字找（构形变体写基础那套的名字也认）。
  - **检视器模块**：列名跟某个检视器模块的标题或「导入时也认的列名」一样时自动对上；也可以手动选「检视器模块」、填标题，项目里没有这个模块就在导入时新建（报告里列出）。「列映射」标题旁的「?」有说明。
- **Lexicanter**：选了 `.lexc` 文件后，主区先列出会新建几门语言、多少词条、短语、规则集、文档，可以改义项文本放进哪种释义语言，检视器里是导入样例；点「导入」才并进项目。词库、义项、方言、发音规则、字母表、词源、短语、文档一次进来。

## 8. 导出

导出菜单：

- **词条 CSV / 语素 CSV**：全字段表格。
- **导出词典 / 模板…**：打开面板——
  - **HTML**：双栏打印样式，按首字母分组，词头、文字、发音、词类、义项、词干与屈折形、词源、备注（各项可选，义项语言可选）；义项自己的词类跟词条不一样时写在释义前面。
  - **Markdown**：适合放进 wiki。
  - **PDF**：桌面版直接输出文件，网页版走打印对话框。
  - **逐条模板**：`{{lemma}} {{ipa}} {{pos}} {{script}} {{definition}} {{etymology}} {{notes}} {{tags}} {{language}}`，块 `{{#senses}}{{n}} {{pos}} {{text}} {{lang}}{{/senses}}`（`{{pos}}` 是义项自己的词类，跟词条一样时为空）、`{{#forms}}{{label}} {{text}}{{/forms}}`。右侧实时预览前几条；模板可保存进项目，导出文本或复制。

### CSV 格式 {#csv-format}

导入时列名不必固定，向导里逐列指定就行；表头写成下面这些名字会自动认出来。导出的 CSV 用的就是这些列名，改完可以直接导回来。文件用 UTF-8（导出的带 BOM，Excel 打开不乱码），逗号、分号、Tab、竖线分隔都能自动识别，单元格里有逗号或换行时用英文双引号括起来。

**词条**

| 表头（任选其一） | 字段 | 写法 |
|---|---|---|
| `lemma`、`word`、`词头`、`单词`、`字典形` | 单词 | 必须有这一列；单词为空的行默认跳过 |
| `pos`、`词类`、`词性` | 词类 | 词类名或缩写；`n.`、`n./v.` 这样的缩写按向导里的「词类标记」表认，`名词/动词` 这样斜杠连着的是复合词类；项目里没有的会新建 |
| `definition_zh`、`释义`、`中文`；`definition_en`、`english` | 释义（这种语言） | 其他语言写 `definition_ja` 这样的语言代码；分号（`;` `；`）隔开多个义项，义项前的 `【古语】` 这类标记可以设成语域，`n.` 这类缩写是这个义项的词类 |
| `tags`、`标签` | 标签 | 逗号、顿号隔开 |
| `proto`、`原始形`、`source` | 词源来源 | 原始形式 |
| `notes`、`备注` | 备注 | |
| `ipa`、`发音` | 发音 | 写进主正字法，记为手填 |
| `stress`、`对重音影响`、`重音` | 对重音影响 | `pos`（`词性`）是传递词性；`special:-2`（`特殊:-2`、`倒数第2`、`第1`，或者直接写数字）是传递特殊重音，`0`、`不重读` 是不重读；几项用逗号隔开，如 `pos, special:-1`。有词条勾了才导出这一列 |
| `语言`、`方言`、`词源类别`、`中间态`、`同义词`、`反义词`、`关系`、`构形`、`文字`（英文 `language`、`dialects`、`etymology type`、`stages`、`synonyms`、`antonyms`、`relations`、`paradigm`、`script`） | 对应的字段 | 方言、关系目标几个用逗号或顿号隔开；关系按单词名找；词源类别认得 `inherited`、`borrowing` 和 `bor.`、`inh.` 这类缩写，认不出的原样当自定义类别 |
| 检视器模块的标题或「导入时也认的列名」 | 检视器模块 | 「几项」的模块用顿号隔开；项目里还没有这个模块时，手动选「检视器模块」、写上标题，导入时新建 |
| 其他列 | 词干、屈折形、语法特征、语域、义项标签、构形变体…… | 在向导里选字段，再填词干名、槽位名或维度名；语域列里几个语域用逗号或顿号隔开 |

```csv
lemma,pos,definition_zh,tags,proto,notes
kala,名词,【古语】宅第；房屋,基础,*kal-a,
tavi,动词,看见,,,
seru,名词/动词,n. 光；v. 照亮,,,
```

导出时每个义项的语域写在义项前面成 `【语域】`，几个语域就连写几个（`【古语】【文学】宅第`；语域名里别带空格），再导入时在「单词、释义、备注里的标记」里选「设为语域」就回来了。义项自己的词类跟词条不一样时写在最前面成 `n. `（`n. 【古语】宅第`），词条的词类列写成 `名词/动词` 这样的复合词类，再导入时在「词类标记」表里设为词类就都回来了。检视器模块每个一列、列名写标题，再导入时自动对上。义项标签、词干、屈折形、配图、词间关系不在这份 CSV 里；要完整搬家请用项目文件或「导出为文件夹」。

**语素**

| 表头（任选其一） | 字段 | 写法 |
|---|---|---|
| `form`、`词根`、`lemma` | 形式 | 必须有这一列；前缀、后缀带连字符（`sa-`、`-lar`） |
| `type`、`类型` | 类型 | `root` `prefix` `suffix` `infix` `circumfix` `clitic` `pattern` `particle`，也认「词根」「前缀」「后缀」这些中文名；认不出的记成标签 |
| `gloss`、`缩写` | gloss | |
| `meaning_zh`、`释义` | 意义（这种语言） | 其他语言同样写语言代码 |
| `allomorphs`、`异体形` | 异体形 | 几个用分号隔开，形式和环境之间用斜杠：`lar / _V；ler / Front_` |
| `form2`、`第二形式` | 第二形式 | 环缀的后半、中缀的位置等 |
| `tags`、`标签` | 标签 | |
| `notes`、`备注` | 备注 | |
| `stress`、`对重音影响` | 对重音影响 | 跟词条一样，另外可以写 `as:名词`（`算作:名词`）选算作哪个词类 |

导入时在向导里把「导入为」切成「语素」。异体形不在 CSV 里，导入后到语素页的检视器里补。语料与短语的表格格式见[语料](/cerf/qonlang/corpus/#table-format)与[短语簿](/cerf/qonlang/phrasebook/#table-format)。

## 9. 联动

| 来源 | 表现 |
|---|---|
| 音系 → 正字法规则 | 「发音」自动生成 |
| 文字 → 映射规则 | 「文字」列与词条卡的文字行 |
| 构形 | 槽位面板、屈折形、词条卡的屈折表 |
| 语素 | 词源来源 |
| 语料 | 悬停例句里的词显示本页的词条卡，点击跳回这里，左侧列表会滚到那个词并短暂高亮 |
| 文档 | `[[词头]]` 链接跳到这里 |
| 命令面板 | `Ctrl+K` 搜词头或释义直接定位 |

## 10. 提示

- 删除词条可撤销；引用它的关系与词源会显示为 `?`，不会报错。
- 多语言项目里想批量看祖语与子语言的对应，用「全部语言」+ 列里勾「词源」。
- 想把词库贴进自己的网站，优先用逐条模板，输出格式完全由你定。
