# 语素

[← 指南目录](/cerf/qonlang/) · 导航栏第五项

语素页是**词根、词缀、附着词、小品词的统一表**。它和词库的分工是：词库存「词位」（有词类、义项、屈折形的成品词），语素页存「零件」。祖语的词根表通常放在这里。

列表操作与词库相同（见[通用操作习惯](/cerf/qonlang/#通用操作习惯)），可筛的列：首字母、类型、标签（「全部语言」时多一列语言也可筛）。标题旁还有**统计**子页（点分布项回列表筛选，点排行项跳到那条），指标：数量、有 gloss / 意义 / 异体形 / 词源的占比、语料分析 / 词源 / 构形里用到的数量、没被用到的语素清单、同形同类的重复；分布按类型、标签、首字母。

标题旁有**显示 / 录入**两种模式：显示模式给只读卡片（形式、类型、gloss、意义、异体形、词源、用到它的词条），录入模式才是逐字段的表单，与词库一致。

## 1. 字段

| 字段 | 说明 |
|---|---|
| 形式 | 语素本身。词缀用连字符标位置：`-lar`（后缀）、`ka-`（前缀）、`-in-`（中缀）；附着词用 `=` |
| 形式 2 | 备用形式（如词根的第二词干） |
| 类型 | 词根 / 前缀 / 后缀 / 中缀 / 环缀 / 附着词 / 小品词 / 其他——只是标签，可按需选 |
| gloss | 出现在行间 gloss 里的缩写，如 `PL`、`LOC`、`1SG` |
| 意义 | 多语言释义（按项目的释义语言顺序） |
| 异体形 | 若干「形式 + 环境」，环境用规则语言的环境写法（如 `_#`、`V_`、`Back?_`）；构形生成器引用语素时按环境挑选 |
| 特征 | 自定义键值 |
| 标签、备注 | |

列表只显示当前语言的语素（「全部语言」时多一列语言）。默认按语言的自定义字母表排序。

## 2. 异体形怎么写

环境用的就是[规则语法](/cerf/qonlang/sound-changes/#rule-language)里环境那一截，`_` 是这个语素本身：后缀看前面的词干结尾（`V_` 在元音后），前缀看后面的词干开头（`_d` 在 d 前、`_Vr` 在「元音 + r」前）。`_CC` 是**任意两个**辅音，`_C1C1` 才是**同一个辅音双写**（编号相同就是同一个音）。音类按 IPA 写（`C` 里是 `k`）、词干却是拼写（`c`）也不要紧：环境会拿拼写和按主正字法转出来的读音各比一次。异体形旁的「?」与标题旁的「查语法」都能随时查写法。

一个后缀在不同环境有不同形式（元音和谐、辅音同化）时，不要建多个语素，而是在同一个语素下写异体形：

```
形式: -lar
异体形:
  -ler   / Front?_      ; 前一个元音是前元音时
  -lar   / _            ; 默认
```

环境从上到下第一个命中的生效；默认值写成 `_` 放最后。

## 3. 语素的词源

语素也有和词条一样的**词源链**：类别（词根 / 复合 / 派生 / 音变 / 借词 / 未知或自定义）、来源、中间态、备注。写了之后，语素会和引用它的词条连进同一张关系图，从词条一路看到更早的语素来源；关系图的用法（含拼接来源拆节点、跨语言跳转）见[词库 · 关系图](/cerf/qonlang/lexicon/#graph)。

## 4. 在构形里引用

构形页的生成器可以写 `@语素名`（或 `@` 后跟语素形式），软件按上面的环境规则挑异体形，再拼接到词干上。这比在生成器里硬写字面后缀好：改了语素，所有构形跟着变，gloss 缩写也统一。

## 5. 在语料里的作用

语料页自动分析例句时，除了查词库，还会用这里的词缀做**多层剥离**（最多两层）：`kasolarda` → `kaso-lar-da`，每个片段的 gloss 取语素的 gloss。附着词用 `=` 连接。

## 6. 在音变规则里引用

音变、正字法、文字映射的规则文本都能写 `@名`，名是语素的 gloss 或去掉连字符的形式（`@lar`、`@PL`）。它相当于一个音类，成员是该语素的全部异体形，所以 `@lar > @ler / Front?_` 这样的辅音 / 元音交替可以直接写在规则里；替换侧的 `@名` 与目标侧的音类按位置对应。

## 7. 与词库的关系

- 词条的**词源来源**可以指向语素（「词根派生」），词条卡里会显示 `← 词根 ‘意义’`。
- 标题栏「导入 → 从 CSV 导入」直接打开列映射向导，目标已经选好「语素」；词库页的 CSV 向导把目标切成「语素」也一样。
- 整库演化的「输入字段」可以选源语言的语素表，把祖语词根整体推到子语言的词库里。

## 8. 提示

- 同一门语言里形式相同但意义不同的两个语素（同形异义）可以并存，gloss 不同即可。
- 标题栏「导出」导出语素 CSV（跟着当前语言走）；词库页的导出菜单里也有。
