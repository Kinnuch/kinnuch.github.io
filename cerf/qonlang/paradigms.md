# 范式

[← 指南目录](/cerf/qonlang/) · 导航栏第七项

范式（paradigm）把**语法维度**组合成**槽位**，再给每个槽位一个**生成器**，就能从词干自动推导全部屈折形。屈折、黏着、模板交替、重叠都能表达；没有屈折的语言可以完全不用这一页。

## 1. 结构

- **维度**在词库的「词类与维度」子页定义（如 数：单 / 复；格：主 / 宾 / 位）。
- 范式选若干维度，做**笛卡尔积**得到槽位：`单.主`、`单.宾`、`复.主`…… 槽位标签就是取值名用 `.` 连接，也是词条 `forms` 的键。
- 不需要的槽位可以**禁用**。
- 范式可以**继承**另一个范式：子范式只写差异槽位，其余沿用父范式。
- 词类绑定范式后，该词类的词条在词库录入模式里出现槽位面板。

## 2. 主区：槽位表

每行一个槽位：标签、生成器类型、参数（公式样式显示）、**微调**列、示例输出。点行在检视器编辑。

## 3. 五种生成器

| 类型 | 参数 | 适合 |
|---|---|---|
| **拼接** | 词干槽名、前缀、后缀 | 黏着 / 屈折后缀。前后缀可写字面，也可写 `@语素`，按语素的异体形环境挑形式 |
| **拼接后跑音变** | 同上 + 规则集、起始阶段、终止阶段 | 后缀形式由音变决定的情况（元音和谐、同化）。先拼接，再把整词送进规则集从起始阶段推到终止阶段 |
| **模板交替** | 模板，如 `C1aC2C2aC3`、`{root}-i-{root}` | 闪语式词根 - 模板；`C1 C2 C3` 取词干的第 n 个辅音，`V1…` 取元音 |
| **重叠** | 重叠范围（整词 / 首音节 / 末音节）、连接符 | 重叠构形 |
| **查表** | 每词手填 | 完全不规则的槽位；或者用来锁定 |

**无**：该槽位不推导。

### 微调列

每个槽位在生成器之外还能加一组**微调**，在生成之前（`pre`）或之后（`post`）执行：

| 写法 | 含义 |
|---|---|
| `-at` | 末尾去掉 `at` |
| `+u` | 末尾加 `u` |
| `^-e` | 开头去掉 `e` |
| `^+a` | 开头加 `a` |
| 任意规则行 | 如 `a > e / _#`，用规则语言 |

典型用途：某个格在生成后要脱落词尾 `-at`，或先去掉词干的词尾再拼。

## 4. 词干槽

生成器引用的「词干」来自词条的**词干槽**（词库录入模式的「词干」字段，名称自定，如「强形」「弱形」）。没有词干槽时默认用词头。

## 5. 检视器：测试台

- 选一个词（默认当前语言绑定了本范式的第一个词条），看全部槽位的推导结果与每步轨迹。
- **推导写入**：把结果写进这个词的屈折形（手填覆盖的格子不动），写入后表格闪一下绿色。
- **全部推导**：对绑定本范式的所有词条批量写入。

## 6. 对账报告

「报告」视图对比推导结果与词条里**手填**的屈折形（CSV 导入的、录入模式手填的），逐槽位给出一致率与差异列表。用它检验规则是否覆盖了你的语料：一致率低的槽位通常意味着漏了一条音变或微调。

## 7. 与其他模块的关系

- **语素**：`@语素` 引用，异体形按环境挑。
- **音变**：「拼接后跑音变」引用规则集与阶段。
- **词库**：绑定词类、槽位面板、屈折形。
- **语料**：自动 gloss 用屈折形反查，gloss 里的形态缩写来自维度取值的缩写。

## 8. 示例

Aelith（示例项目）的名词范式：维度 数 × 格，生成器全部是「拼接后跑音变」：后缀写成带原音位的形式 `¢lAr`、`¢dA`，规则集里 `A` 按前面元音的前后性实现为 `a / e`，`Ŭ` 是连接元音，词干以元音结尾时脱落，`¢` 最后删掉。
