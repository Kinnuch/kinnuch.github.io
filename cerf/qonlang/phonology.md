# 音系

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/phonology/) · 导航栏第二项

音系页有五个子页：**音位**、**音类**、**正字法**、**音节与韵律**、**配列与造词**。所有内容都属于顶栏选中的当前语言。

## 1. 音位

主区是 IPA 表（肺部辅音表、非肺部音、元音图、其他），点一个符号就把它加入 / 移出音位表；也可以在检视器手动输入任意符号（不一定是 IPA，声调字母、自定义符号都行）。辅音表里有**塞擦音**一行（`t͡s`、`d͡z`、`t͡ʃ`、`t͡ɕ`……）；带连音弧的写法和 `ts` 这样的写法算同一个音，特征照样推得出来。表头右边的三角可以把整张表收起来。已经加进来的音位按辅音 / 元音 / 其他分行排成小圆框，按住一个拖到同一行的另一个上就换位置（「按音位表填充」照这个顺序填）。

每个音位的**特征**（类型、清浊、部位、方式、高度、前后、圆唇……）会从 IPA 符号自动推断，也可以手改或增加自定义维度。特征在两处用到：

- 「音类」子页按特征查询生成成员。
- 「音节与韵律」按类型区分辅音 / 元音做音节划分。

「各正字法中的写法」：给每个音位填它在各正字法里的拼写（θ 写作 th）。填了之后，主正字法里的这些写法算一个音：「音节与韵律」按拼写测试、构形里数音（中缀位置、模板、重叠）时 th 不会被拆成 t、h；正字法没写「正字法 → IPA」规则时，也按这些写法把拼写换成音位。

## 2. 音类

音类就是规则语言里的 `V`、`C`、`{Vlong}` 这类集合。两种建法：

- **按成员**：直接列出成员；没有分隔符时按字符拆，多字符成员请用空格或逗号分隔，例如 `ts ng`。
- **按特征**：选择特征条件，如「类型 = 元音」「清浊 = 浊 且 方式 = 塞音」，成员根据音位表计算；编辑时可点击「按条件刷新成员」重新计算。

点击音类卡片或「编辑」进入表单；「新增音类」也会直接打开表单。名称、成员和特征条件都先保留在草稿中，点击「完成」才写入工程；点击「取消」或按 Esc 会放弃本次编辑，新增后取消不会留下空音类。「删除」会立即移除该音类，通知里的「撤销」可恢复完整内容。纯欣赏工程不能新增、编辑或删除音类。

「一键生成 C / V」按类型直接建立两个基本音类。

**多合字母**：把 `th`、`ng` 这样的两个字母声明成一个单位，规则匹配时当成一个字符处理，输出时换回。在「音变」页的规则列表视图里也能编辑同一份表。

音类与多合字母会自动提供给：音变规则集、正字法规则、文字映射规则。规则文本里再声明同名音类会覆盖这里的定义。

按特征生成的音类（包括快速生成的 C / V）会同时识别普通键盘的 `g` 和 IPA `ɡ`。例如，在 IPA 表选了 `ɡ`，词尾输入 `g` 也能匹配辅音类 `C`。软件会保留输入的写法。工程显式使用两种字符、指定了它们的替换，或手动定义音类时，以工程和规则的设置为准。

## 3. 正字法

一门语言可以有多套正字法（拉丁转写、西里尔转写、学术转写……），其中一套是**主正字法**——词库的词头就按它录入。上方一套正字法一个按钮，按住拖到另一个上可以换先后。

在音位检视器的「各正字法写法」里填写拼写，然后在「正字法」选中同一套方案，即可在「音位写法条目」里看到对应行。比如为音位 `ʃ` 填入 `sh`，就会生成 `sh → ʃ`。有多种写法时，正向转写都能接收。

可以逐行改来源、结果或启用状态。「恢复自动」使这一行重新跟随音位写法。条目按最长写法一次匹配，再执行下方拼写→IPA的高级规则。在旧工程里，可先预览已有写法，再点击「从音位写法生成」启用。

常规正字法页只显示**正字法 → IPA**。**大小写同音**默认勾选，新旧工程都按同一设置处理：例如有 `f > ɸ` 时，`Aufidel` 和 `aufidel` 都转为 `auɸidel`。取消勾选后，可分别定义大写和小写的转写。此开关仅用于这套正字法的拼写输入，不改写词头、音位、音变规则或规则输出。

- **正字法 → IPA**：词库「发音」列、语料 IPA、短语发音都由它生成。一段里有几个词时（`A B`、短语），按空白逐词转写：每个词的末尾都算词尾，`_#` 的规则对每个词都生效；词两头的逗号、引号不挡词末规则。多合字母的内部符号本来就是音标的（`th|θ` 的 θ、音位表里有的音）照原样出现在转出来的 IPA 里，不会变回 th。
旧工程已有的反向条目和规则不会删除；到「配列与造词」展开「旧版 IPA → 拼写规则」即可按名称查看各套正字法并继续编辑、试写；切换查看对象不改变造词使用的基准正字法，IPA模式造词仍使用原有规则。新项目不需要另写一套反向规则。

规则语言与音变页完全相同（见[规则语言](/cerf/qonlang/sound-changes/#rule-language)），有「规则列表」和「源代码」两种视图，检视器里有试写框，输入若干词立刻看到结果。规则列表里的规则可以**拖**到别的位置或别的阶段（落点会空出一行）；写了 `-* 阶段名` 时，试写的结果按阶段分列显示，跟音变的测试台一样，表格各格居中。规则里也可以写**重音规则**（`ˈ = …`，写法见[重音规则](/cerf/qonlang/sound-changes/#stress-rules)）：放在锐音符这类标重音的写法换掉之前，转出来的 IPA 就带着 `ˈ`，试写结果里橙色标出，「音节与韵律」照这个记号划。

修改大小写设置后，试写立即采用新设置；已有普通自动读音在词条卡、检视器和语料悬浮卡中按当前词惰性显示，不会打开工程就扫描全库或改写存盘。发音搜索、过滤与排序仍用已存字段，需要时可用下面的按钮更新全库。**重新标音**按钮把当前语言全部词条按主正字法重算一遍；词条里标了「不规则」的发音不会被覆盖。

## 4. 音节与韵律

- **音节划分**：两种策略。**模板法**按你写的音节模板（如 `(C)(C)V(C)`，引用音类名）切分；**最大起首**原则把尽可能多的辅音归到后一个音节的起首。可以关闭（孤立语、音节文字自己带音节的情况）。
- **重音**：固定位置（词首、第二、词末、倒数第二、倒数第三）、按音节重量、逐词手标，或者**自定义重音规则**：选了之后下面出现逐条编辑的表单——先看音节数（不限 / 恰好 / 至少）、第几个音节（第 / 倒数第 / 从前、从后找第一个合条件的）、音节核里要有什么、环境、排除，一条对不上看下一条；下面「按符号分段」填 `·` 时复合词各段分开算，「主重音在」挑最后一段或第一段。表单底下同步显示写成文本的样子，写法跟规则里的[重音规则](/cerf/qonlang/sound-changes/#stress-rules) `=` 后面那一截一样；写错时下面列出提示。「说明 / 例外」仍是随手写的备注。
- **声调**：声调表（名称、符号、描述）。分析时声调字母会被忽略，不影响音节划分。

主区的「测试」框写几个词看划分和重音。右边「输入按」选**拼写**（默认）时先用主正字法转成 IPA，再划音节——`ce·theurian` 里的 th 是一个音 θ，切出来是 `ˌke̞·ˈθɛʊ̯r.jän`，不会切成 cet.heurian；选 **IPA** 时直接按写的音标划。`·` `-` 这类分隔符两边各自划音节，显示时照原样留着；音标里已经带 `ˈ`（正字法规则标的、手填的）就照记号标，没有才按上面的重音设置。下面还用词库前十几个词展示划分结果，读音按主正字法现转（手标为不规则的照用），改了正字法规则马上看得到；词条勾了「对重音影响」的，按它的词类和特殊重音标。

自定义重音规则的表单最上面勾「先看词条标的特殊重音（@）」就是规则里的 `@`，每条前面的「词类」对应 `<词类>`，第几个音节里选「不重读」是 `0`（见[重音规则](/cerf/qonlang/sound-changes/#stress-rules)）。

IPA 长度符号 `ː`（长）和 `ˑ`（半长）会保留在前面的音段上。基础元音已设为音节核时，它的长音和半长音也能作为核，例如 `aːhalur` 可划为 `aː.ha.lur`；如果工程明确把完整单位设为辅音，仍以该设置为准。此判断不会改写音位或词中的字符。

## 5. 配列与造词

配列表描述合法音节：**起首**、**核**、**尾**各是一个允许的序列列表（按当前模式填写拼写或 IPA），**禁止序列**列出不允许出现的片段，**权重**给某些序列更高出现概率，还有最少 / 最多音节数。

先选择**拼写**或 **IPA**。两个模式分别保存配列表，切换不会改写或清空另一张表；旧工程默认保持原IPA表。拼写模式直接按写法造词，再用基准正字法转出读音，无需IPA→拼写规则。IPA模式按音位生成；有旧反向规则时仍显示对应拼写，没有时，点击「加入词库」会先请你填写词头，避免把音标直接当成拼写。

**按音位表填充**：IPA模式用音位表里的辅音填起首和尾音、元音（能作音节核的）填核；拼写模式填入这些音位在基准正字法里的写法。空着的栏直接填；已经有内容、又跟音位表不一样的栏先弹框问要不要重填——重填会把原来特意删掉的限制换回来，可以撤销。填完右下角提示各填了几个；已经和音位表一致时也会说一声。辅音还是元音按这个顺序认：音位上手填的特征、名叫 `C` / `V`（或「辅音」「元音」）的音类、IPA 表；表里没有的多字母写法（`ng`、`aa`）按里面的字母认，普通键盘打的 `g` 也算 IPA 的 `ɡ`。实在看不出来的音位不填，提示条里会列出来，到音位表里给它填上「类型」就行。

- **检查词库**：逐词按配列表检查，列出违反的词与原因。
- **造词**：按配列表生成 N 个词（可指定音节数范围）。勾上「参考词库」时（默认勾着；词库里这门语言有 8 个词以上才能勾），先照着词库里已有的词学：词首和词中的起首、词中和词尾的尾音各自多常见，几个音节的词多，音和音怎么搭配；再按学到的频率撒一大把候选，按像不像这门语言排好，挑出彼此不太像的一批，尽量避开跟已有词只差一个音的形式。排在前面的最像；鼠标放到结果上显示「像：……」，是词库里跟它最接近的词。不勾时只按配列表和权重造。
  两种都把配列表当硬规定：每个结果都重新划一遍音节、按配列表查过，起首、核、尾音、禁止序列和音节数都合规；已存在的词头会跳过。拼写模式同时显示按正字法推导的IPA；IPA模式保留旧反向规则产生的拼写。每个生成结果旁边有「加入词库」按钮，也可以一键复制全部。

## 6. 与其他模块的关系

| 这里定义的 | 被谁使用 |
|---|---|
| 音位与特征 | 音类的特征查询、音节划分 |
| 各正字法中的写法 | 按拼写划音节、构形里数音、没写转写规则时的拼写 → 音位 |
| 音类、多合字母 | 音变规则、正字法规则、文字映射规则（都可直接引用） |
| 正字法 → IPA | 词库发音列、语料、短语 |
| 旧版 IPA → 拼写规则 | 旧工程IPA模式造词的拼写与兼容试写 |
| 配列表 | 造词与检查 |

## 7. 常见问题

- **配列检查全报错**：先确认当前模式。IPA配列表按读音检查，软件先按主正字法规则把词头转成IPA再比对；拼写配列表直接按词头检查。如果还没写转写规则，检查就是在拿拼写硬比。
- **声调符号影响划分**：把声调字母加进声调表，分析时会忽略它们。
- **th 这类写法被拆成两个音**：在正字法规则或多合字母里把它转成一个音（`th > θ`、`th|θ`），或者在音位的「各正字法中的写法」里填上 th；测试时「输入按」选拼写。
- **一个符号想同时算辅音和元音**：给它单独建一个音类，在音节模板里引用。
