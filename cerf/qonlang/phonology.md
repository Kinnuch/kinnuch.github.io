# 音系

[← 指南目录](/cerf/qonlang/) · 导航栏第二项

音系页有五个子页：**音位**、**音类**、**正字法**、**音节与韵律**、**配列与造词**。所有内容都属于顶栏选中的当前语言。

## 1. 音位

主区是 IPA 表（肺部辅音表、非肺部音、元音图、其他），点一个符号就把它加入 / 移出音位表；也可以在检视器手动输入任意符号（不一定是 IPA，声调字母、自定义符号都行）。

每个音位的**特征**（类型、清浊、部位、方式、高度、前后、圆唇……）会从 IPA 符号自动推断，也可以手改或增加自定义维度。特征在两处用到：

- 「音类」子页按特征查询生成成员。
- 「音节与韵律」按类型区分辅音 / 元音做音节划分。

「各正字法中的写法」：给每个音位填它在各正字法里的默认拼写，供以后写规则时参考。

## 2. 音类

音类就是规则语言里的 `V`、`C`、`{Vlong}` 这类集合。两种建法：

- **按成员**：直接列出成员（单字母音类的成员按字符拆，长名音类用空格分隔）。
- **按特征**：写一个特征查询，如「类型 = 元音」「清浊 = 浊 且 方式 = 塞音」，成员从音位表自动算出，音位表变了会跟着变。

「快速生成 C / V」按钮按类型一键建两个基本音类。

**多合字母**：把 `th`、`ng` 这样的两个字母声明成一个单位，规则匹配时当成一个字符处理，输出时换回。在「音变」页的规则列表视图里也能编辑同一份表。

音类与多合字母会自动提供给：音变规则集、正字法规则、文字映射规则。规则文本里再声明同名音类会覆盖这里的定义。

## 3. 正字法

一门语言可以有多套正字法（拉丁转写、西里尔转写、学术转写……），其中一套是**主正字法**——词库的词头就按它录入。

每套正字法有两个方向的规则：

- **正字法 → IPA**：词库「发音」列、语料 IPA、短语簿发音都由它生成。
- **IPA → 正字法**：随机造词时把生成的 IPA 拼回拼写；也可以用来把别的正字法的词转过来。

规则语言与音变页完全相同（见[规则语言](/cerf/qonlang/sound-changes/#rule-language)），有「规则列表」和「源代码」两种视图，检视器里有试写框，输入若干词立刻看到结果。

**重新标音**按钮把当前语言全部词条按主正字法重算一遍；词条里标了「不规则」的发音不会被覆盖。

## 4. 音节与韵律

- **音节划分**：两种策略。**模板法**按你写的音节模板（如 `(C)(C)V(C)`，引用音类名）切分；**最大起首**原则把尽可能多的辅音归到后一个音节的起首。可以关闭（孤立语、音节文字自己带音节的情况）。
- **重音**：固定位置（词首、第二、词末、倒数第二、倒数第三）、按音节重量，或手动。也可以写规则文本。
- **声调**：声调表（名称、符号、描述）。分析时声调字母会被忽略，不影响音节划分。

检视器有试分框；主区还会用词库前十几个词展示划分结果，方便调模板。

## 5. 配列与造词

配列表描述合法音节：**起首**、**核**、**尾**各是一个允许的序列列表（用 IPA 写），**禁止序列**列出不允许出现的片段，**权重**给某些序列更高出现概率，还有最少 / 最多音节数。「从音位表填入」按钮用现有辅音 / 元音先填一版。

- **检查词库**：逐词按配列表检查，列出违反的词与原因。
- **随机造词**：按配列表和权重生成 N 个词（可指定音节数范围），跳过已存在的词头；若主正字法有「IPA → 正字法」规则，会同时给出拼写。每个生成结果旁边有「加入词库」按钮，也可以一键复制全部。

## 6. 与其他模块的关系

| 这里定义的 | 被谁使用 |
|---|---|
| 音位与特征 | 音类的特征查询、音节划分 |
| 音类、多合字母 | 音变规则、正字法规则、文字映射规则（都可直接引用） |
| 正字法 → IPA | 词库发音列、语料、短语簿 |
| IPA → 正字法 | 随机造词的拼写 |
| 配列表 | 造词与检查 |

## 7. 常见问题

- **配列检查全报错**：配列表要用 IPA 写，而词库词头是拼写；检查时软件先按主正字法规则把词头转成 IPA 再比对。如果还没写转写规则，检查就是在拿拼写硬比。
- **声调符号影响划分**：把声调字母加进声调表，分析时会忽略它们。
- **一个符号想同时算辅音和元音**：给它单独建一个音类，在音节模板里引用。
