# 短语

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/phrasebook/) · 导航栏第九项

短语收**常用语句**：问候、数字、旅行手册式的对话、教程里的固定句式。它和语料页的分工：例句用于 gloss 分析，短语用于整理和展示。Lexicanter 的 Phrasebook 导入后就落在这里。

### 工程共享目录 {#shared-folders}

**工程共享目录**：语料、短语和文档现在使用同一棵多级目录树。在任一页新建、改名或移动文件夹，另外两页立即使用同一个目录。旧语料与文档文件夹会保留内容和层级；没有目录的记录归 `Default`，同名旧目录会自动编号以免混并。记录的语言不随目录移动而改变。

点击路径中的「根目录」进入目录视图。它左侧的小三角可以展开或收起整列侧栏，默认收起。选定文件夹即可浏览其中的内容，打开例句、短语或文档会进入相应页面。可切换「图标视图／详细信息」，在「设置 → 根目录」选择标签、创建时间、文件大小和类型等列。大小是记录数据的 UTF-8 估算值，不是磁盘占用，也不含独立附件；旧记录没有创建时间时显示「—」。

「根目录」与 `Default` 不同：根视图只列出 `Default` 和顶层文件夹；打开 `Default` 才查看未归档记录。`Default` 不是其他顶层目录的父层。目录数字汇总本层与所有后代中的例句、短语和文档，根数字则是全工程合计；点击树中箭头可展开或收起某一分支，数量不随折叠改变。面包屑从根目录开始，可逐层返回。

`Default` 不接收子目录；请在根目录新建、移动或粘贴文件夹，也可将文件夹拖到根目录图标上。记录仍可拖入 `Default`。在根目录粘贴只有记录的内容时，会自动进入 `Default` 展示实际落点。

右键文件夹或记录可「复制」「剪切」「粘贴」，也可在选中记录后使用页面工具栏及 `Ctrl/⌘+C`、`Ctrl/⌘+X`、`Ctrl/⌘+V`。文件夹复制包含整棵子树和其中的三类记录；粘贴建立新 ID，保留分析与已有词条、语素引用。剪切只在成功粘贴时移动原对象，取消或失败不会先删内容。整条记录剪贴板仅用于当前打开的工程会话；重新打开工程或重新启动软件后，请重新复制。文本框中的普通文字复制粘贴不受影响。只读项目不能改动目录或记录。

## 1. 布局

侧栏会列出当前语言在所选文件夹内的短语和各分类的数量。选择分类可缩小列表，点击短语可打开对应卡片和检视器。根目录可查看当前语言的全部短语。顶部可搜索原文或译文，只显示当前语言。卡片按住拖到另一张上，松手就换到那个位置。

原文里能在词库里找到的词（含屈折形与词缀剥离）会带下划线：悬停显示词条卡，点击跳到词库。认词跟[语料](/cerf/qonlang/corpus/)是同一套（屈折形、词缀、反推构形都认，语素也认得出来）。

卡片上的「**改**」跟[语料](/cerf/qonlang/corpus/)页是同一套：短语也会存下自己的分析，所以切分里点中哪一块，「改」改的就是那一块（同一个词条在一个词里出现两次也分得清），挑义项、挑切法都在。搜词条或语素点一下，**默认只改挂接，原文一个字不动**；要连原文一起换，勾上「**同时改原文**」（默认不勾，只在改整个词时才出现）——原文换了，发音与文字行按规则重算（手改成不规则的不动）。两种情况都是一次撤销整体退回。认不出的那一段悬停是「没有找到」，点一下在同一个搜索框里指定。原文改过之后分析会重新算一遍，已经确认过的词按原样留着。

## 2. 短语字段

| 字段 | 说明 |
|---|---|
| 原文 | 按主正字法 |
| 译文 | 默认只有当前界面语言一栏；要填别的语言，在[设置](/cerf/qonlang/settings/) → 当前项目 → 语言与字体 →「释义输入的语言」里加 |
| 分类 | 自由文本，有已用分类的提示；左栏按它分组。**双击**左栏分类可重命名（该分类下所有短语一起改） |
| 发音 | 每套正字法一行「基于正字法的 IPA」（有几套正字法时写成「基于正字法的 IPA（正字法名）」），后面的「!」勾选框表示不规则。原文改完会自动按「正字法 → IPA」规则标音；手改发音会自动勾上不规则，之后标音不再覆盖它，提示条会说有几个没动，点提示条上的「也按规则重算」一并重算；勾掉「!」也马上按规则重算这一套 |
| 变体 | 若干「写法 + 说明」，用于语域、场合、方言差异 |
| 标签 | |

删除可撤销。

**译文工作台**：在检视器「译文」旁点「工作台」，从译文倒着组出原文，用法跟[语料的译文工作台](/cerf/qonlang/corpus/#workbench)一样：写译文，把浮在下面的词拖上来排好，点词在[附着台](/cerf/qonlang/corpus/#bench-attach)里挑形式、加词缀和小品词，最后点「添加到短语」。选中的那条原文还空着就填进去，不然在当前分类里新加一条；挑定的词直接存成这条短语的分析，发音按规则标好。已有原文的标点和已确认分析会载入草稿，默认优先保留原有格式；新组短语沿用译文明确写出的标点，不强制大写或补句号。请在最终原文框核对，需要时展开「排版设置」。 同一处译文有多个候选时，选中一个会把其他候选收进右上角的垃圾桶。点击图标并把需要的词拖回待选区，即可重新选用。

## 3. 与其他模块的关系

- **音系**：发音规则。
- **文字**：卡片顶部一行文字。
- **主题**：原文与译文用语料的字体槽。
- **命令面板**：`Ctrl+K` 搜原文或译文可直接跳到某条。

## 4. 提示

- 标题栏的「导入」「导出」：从表格（CSV / TSV / 一行一条）导入，按表头猜原文、各语言译文、分类、标签、变体，原文重复的跳过；导入在页面主区的面板里挑列，检视器实时显示导入样例（改了设置马上跟着变，变了的地方先高亮再褪掉）。也能导入导出 JSON（导入同样先看样例）、导出 CSV（跟着当前分类与搜索走）。
- 分类可以用「/」做层级感的命名（如「旅行/问路」），左栏按字母排序。

## 5. 表格格式 {#table-format}

| 表头（任选其一） | 字段 |
|---|---|
| `text`、`原文`、`短语`、`phrase` | 原文（必须有） |
| `translation:zh`、`译文`、`翻译`、`释义`，后面带上语言 | 这种语言的译文 |
| `category`、`分类`、`类别` | 分类，可以用「/」分层（`旅行/问路`） |
| `tags`、`标签` | 标签（逗号隔开） |
| `variants`、`变体` | 变体（分号隔开几种说法，末尾括号里写备注：`你好（口语）`） |
| `发音`、`ipa`，或正字法名 | 这套正字法的发音（主正字法写「发音」，其余写正字法名） |

导出的 CSV 就是这几列，可以直接导回来；原文重复的条目跳过。导入面板右上角的「格式说明」打开这一节。
