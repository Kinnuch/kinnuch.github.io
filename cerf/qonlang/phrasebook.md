# 短语

[← 指南目录](/cerf/qonlang/) · 导航栏第九项

短语收**常用语句**：问候、数字、旅行手册式的对话、教程里的固定句式。它和语料页的分工：例句用于 gloss 分析，短语用于整理和展示。Lexicanter 的 Phrasebook 导入后就落在这里。

## 1. 布局

左栏是**分类**（「全部」+ 各分类及计数），中间是短语卡片（文字行、原文、发音、译文、变体），检视器编辑当前短语。顶部可搜索原文或译文，只显示当前语言。

原文里能在词库里找到的词（含屈折形与词缀剥离）会带下划线：悬停显示词条卡，点击跳到词库。

## 2. 短语字段

| 字段 | 说明 |
|---|---|
| 原文 | 按主正字法 |
| 译文 | 各释义语言 |
| 分类 | 自由文本，有已用分类的提示；左栏按它分组。**双击**左栏分类可重命名（该分类下所有短语一起改） |
| 发音 | 每套正字法一个 IPA。原文改完会自动按「正字法 → IPA」规则标音；手改后标为不规则，不再自动覆盖；「按规则标音」按钮可强制重算 |
| 变体 | 若干「写法 + 说明」，用于语域、场合、方言差异 |
| 标签 | |

删除可撤销。

## 3. 与其他模块的关系

- **音系**：发音规则。
- **文字**：卡片顶部一行文字。
- **皮肤**：原文与译文用语料的字体槽。
- **命令面板**：`Ctrl+K` 搜原文或译文可直接跳到某条。

## 4. 提示

- 标题栏的「导入」「导出」：从表格（CSV / TSV / 一行一条）导入，按表头猜原文、各语言译文、分类、标签、变体，原文重复的跳过；也能导入导出 JSON、导出 CSV（跟着当前分类与搜索走）。
- 分类可以用「/」做层级感的命名（如「旅行/问路」），左栏按字母排序。
