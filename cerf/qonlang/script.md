# 文字

[← 指南目录](/cerf/qonlang/) · 导航栏第三项，位于音系与音变之间

「文字」页管理语言的**自定义书写系统**：你自己设计的字母、音节文字、附标文字，或者借用 Unicode 里现成的文字块（卢恩、腾格瓦私用区、天城文……）。定义好之后，词库会多一列「文字」，语料与短语会多一行文字，词典导出也会带上，全部按规则自动生成。

一门语言可以有多套文字（例如正式体与草书体）。

## 1. 新建文字与基本属性

顶部「新建文字」，检视器里设置：

| 字段 | 说明 |
|---|---|
| 名称 | 如「Aelith 刻文」 |
| 类型 | 全音素文字 alphabet / 辅音音素文字 abjad / 元音附标文字 abugida / 音节文字 syllabary / 语素文字 logographic / 特征文字 featural / 混合 / 其他。类型不影响引擎，只决定「映射规则」页给你的提示 |
| 书写方向 | 从左到右 / 从右到左 / 从上到下。RTL 会让显示处使用 `dir="rtl"` |
| 字体 | 系统字体名，或导入字体文件内嵌进项目 |
| 备注 | 自由文本 |

## 2. 字体

- **系统字体名**：机器上装了的字体直接写名字。
- **导入字体文件**：TTF / OTF / TTC / WOFF / WOFF2。文件会以 data URL 存进项目文件，换机器也能显示。TTF / OTF / TTC 还能顺便读出字符表（见下）。
- 没有指定字体时，文字显示会回落到皮肤里「自定义文字」槽的字体，再回落到语言数据字体。

## 3. 字形表

三种来源，可以混用：

1. **从字体读字形**：解析字体的 cmap（字符到字形的映射）与 post 表（字形名）。FontCreator 之类软件导出的字体，每个字形起的名字会出现在「名称」里。基本拉丁字母和数字的转写值会自动填成字符本身（很多自制字体把字形映射在 a–z 上，这样立刻可用），其他字符转写留空等你填。
2. **粘贴字符表**：每行「字符 转写 名称」，Tab 或空格分隔，例如 `ᚠ f fehu`。
3. **新增字形**：手动一个个加。

每个字形有：

| 字段 | 说明 |
|---|---|
| 字符 | 字形本身（可含组合符号；私用区码位也行） |
| 转写 | 主正字法里对应的拼写，**映射规则由它自动生成**；留空则不参与自动映射 |
| 名称 | 字形名 |
| 分类 | 字母 / 元音符号 / 辅音 / 音节 / 附标 / 数字 / 标点 / 私用区字形 / 空白 / 其他，或自定义。「自动分类」按 Unicode 类别粗分 |
| 备注 | |

字形卡片按分类过滤；点卡片在检视器编辑。

## 4. 映射规则

规则语言与音变页相同（见[规则语言](/cerf/qonlang/sound-changes/#rule-language)），有列表视图与源代码视图。

特别之处是一行 `@glyphs`：它会展开为**由字形表自动生成的映射**，每个有转写值的字形一条 `转写 > 字符`，按转写值长度降序排列（`th` 先于 `t`，避免短的先吃掉长的）。展开结果在页面底部「自动映射」可以展开查看。

写在 `@glyphs` **前面**的规则先执行，**后面**的规则最后执行。这就是处理各种文字类型的方法：

| 类型 | 典型写法 |
|---|---|
| 全音素 | 通常只需 `@glyphs`；多合字母给单独字形填更长的转写值即可 |
| 辅音音素（abjad） | 在 `@glyphs` 前删掉不写出的元音：`[aiu] > / C_` |
| 元音附标（abugida） | 先删辅音后的固有元音 `a > / C_`，再让其他元音映射成附标；词末无元音的辅音加去元音符号，如 `C > C◌्`（`◌` 只是示意，写实际字符） |
| 音节文字 | 每个音节一个字形并填转写（ka、ki…），最长匹配自动处理 |
| 语素文字 | 逐词在词库的「文字写法」里手填，规则只处理能规律推导的部分 |
| 特征文字 | 先把音类映射为部件，再用规则拼合 |
| 混合 | 各部分写成不同规则段，用 `-*` 阶段快照观察中间结果 |

规则里可以引用音系页的音类与多合字母。检视器的「试写」框输入转写，按空格分词，立刻看到文字。

## 5. 预览

「预览」子页用词库前 40 条与语料前 10 句展示转换结果，方便检查规则。

## 6. 联动

| 位置 | 表现 |
|---|---|
| 词库列表 | 「列」里勾选「文字: 名称」，多出一列，用该文字的字体显示 |
| 词库录入模式 | 「文字写法」字段可手工覆盖自动结果（语素文字、不规则写法用） |
| 词条卡 / 悬浮词卡 | 词头下方一行文字 |
| 语料 | 编辑器与列表卡片顶部一行文字；导出（莱比锡、Markdown、HTML、LaTeX）都带文字行；自定义模板用 `{{script}}` |
| 短语 | 卡片顶部一行文字 |
| 词典导出 | 词头后跟文字（可关闭） |
| 字符面板 | 「项目字符」页列出当前语言全部字形，点击即插入 |
| 皮肤 | 「自定义文字」字体槽是没有内嵌字体时的默认字体 |

## 7. 提示

- 想让文字**只对部分词生效**？把不想转换的词的「文字写法」填成与词头相同即可。
- 私用区（PUA）字形没有系统字体能显示，务必内嵌字体。
- 字体文件较大（数 MB）时项目文件也会变大，这是有意的取舍：项目自带一切。
