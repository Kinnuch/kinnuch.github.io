# 文字

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/script/) · 导航栏第三项，位于音系与音变之间

「文字」页管理语言的**自定义书写系统**：你自己设计的字母、音节文字、附标文字，或者借用 Unicode 里现成的文字块（卢恩、腾格瓦私用区、天城文……）。定义好之后，词库会多一列「文字」，语料与短语会多一行文字，词典导出也会带上，全部按规则自动生成。

一门语言可以有多套文字（例如正式体与草书体）。标题旁先是「字形表 / 映射规则 / 预览」三页的切换，再往右是这门语言的各套文字，一套一个书签页签，点页签切换，按住拖到另一张页签上可以换位置。

## 1. 新建文字与基本属性

标题栏最右的「新建文字」，检视器里设置：

| 字段 | 说明 |
|---|---|
| 名称 | 如「Aelith 刻文」 |
| 类型 | 全音素文字 alphabet / 辅音音素文字 abjad / 元音附标文字 abugida / 音节文字 syllabary / 语素文字 logographic / 特征文字 featural / 混合 / 其他。类型不影响引擎，只决定「映射规则」页给你的提示 |
| 书写方向 | 从左到右 / 从右到左 / 从上到下。RTL 会让显示处使用 `dir="rtl"`；选「从上到下」本身就会竖排 |
| 竖排显示 | 默认关。勾上后凡是显示这种文字的地方（语料、短语、词库、词条卡、字符面板、本页预览）都竖着排（`writing-mode`），字形直立；列从右往左，书写方向选「从左到右」则列从左往右 |
| 括号 | 原文里的括号怎么写成文字（半角、全角都算）：**括号照留，里外分开转写**（默认，如「kala（mira kala）」）/ **去掉括号，内容并进词里**（「tal(a)n」这种可省的字母拼进词里；成句的括号换成空格）/ **括号连内容都不写** |
| 字体 | 系统字体名，或导入字体文件内嵌进项目 |
| 备注 | 自由文本 |

## 2. 字体

- **系统字体名**：机器上装了的字体直接写名字。
- **导入字体文件**：TTF / OTF / TTC / WOFF / WOFF2。文件会以 data URL 存进项目文件，换机器也能显示。TTF / OTF / TTC 还能顺便读出字符表（见下）。
- 有了字体，字形表的字形卡、检视器标题、「字符」输入框都用这套文字的字体显示；私用区字形没有字体时只能显示成方框。
- **在皮肤里换字体**：[皮肤 → 字体槽](/cerf/qonlang/skin/#4-字体槽)下方列出当前项目的每套文字，可以单独指定字体（字体库里装的、本地导入的都行），优先于这里的设置；只改本机显示，不动项目文件。
- 没有指定字体时，文字显示会回落到皮肤里「自定义文字」槽的字体，再回落到语言数据字体。
- **导出字体** <a id="export-font"></a>：「字形表」页上方的「导出字体」菜单。「导出 TTF」「导出 WOFF」把内嵌字体里的字连同每个画过、改过的字（画过的盖掉原来的）重新写成一份字体存出来；「写回内嵌字体」用重新写成的 TTF 换掉这套文字的内嵌字体，项目里带的就是改好的字体，提示条上可以撤销。
  - 内嵌的是 **TrueType** 字体时，是在原字体上动手术：只把画过、改过的那几个字换进原文件，字形编号一个不动、新字接在最后，所以**原字体的字距、连字和其他字的 hinting 都原样留着**。
  - 留不住的几样：改过的那几个字**自己的 hinting** 跟新轮廓对不上，只能去掉；**复合字形**引用了改过的字就跟着变（改了 `A`，`Á` `À` `Ä` … 也跟着变）；**数字签名**总会去掉。
  - 内嵌的是 **OTF（CFF 轮廓）、WOFF / WOFF2、TTC，或者根本没有内嵌字体**时，只能从零写一份：只带对应了字符的字形，全部缩放到一个 em 1000 单位，字距、连字、hinting 都留不住。内嵌的是 WOFF2 时原字体本身也读不了，只出画过、改过的那些字。

## 3. 字形表

四种来源，可以混用：

1. **从字体读字形**：解析字体的 cmap（字符到字形的映射）与 post 表（字形名）。FontCreator 之类软件导出的字体，每个字形起的名字会出现在「名称」里。基本拉丁字母和数字的转写值会自动填成字符本身（很多自制字体把字形映射在 a–z 上，这样立刻可用），其他字符转写留空等你填。选了字体后先在字形表上方确认：检视器里是导入样例（字形卡片用这个字体显示，已经有的字符淡掉、会跳过），点「导入字形」时连字体一起内嵌进文字。
2. **粘贴字符表**：每行「字符 转写 名称」，Tab 或空格分隔，例如 `ᚠ f fehu`。边粘贴边在检视器里看导入样例，改了哪一行，对应的卡片闪一下；已经有的字符淡掉、会跳过。
3. **新增字形**：手动一个个加。
4. **手写字形**：字形表上方的「手写字形」（或者字形检视器里的「手写这个字」「改手写」）打开**手写板**，现场画一个字，或者改字体里的字，用法见下面的[手写板](#glyph-pad)。点「保存」后，软件把这套文字里手写的字做成一个字体，挂在这套文字的字体最前面——字形表、检视器、词库的文字列、词条卡、语料、转写结果里都照样显示，别的字仍用原来的字体。字符空着时自动分一个私用区码位（跳过项目里各套文字已经用了的、内嵌字体里已经有的）；字符填了现成的字（比如 `a`），这套文字里的 `a` 就显示成手写的样子。「改手写」重画，「去掉手写」恢复成普通字形。

每个字形有：

| 字段 | 说明 |
|---|---|
| 字符 | 字形本身（可含组合符号；私用区码位也行） |
| 转写 | 「转写来源」那一栏里对应的写法（默认是单词的拼写；意音文字可以填字号，如 `aa01`），**映射规则由它自动生成**；留空则不参与自动映射 |
| 名称 | 字形名 |
| 分类 | 字母 / 元音符号 / 辅音 / 音节 / 附标 / 数字 / 标点 / 私用区字形 / 空白 / 其他，或自定义。「自动分类」先看转写值：按主正字法读成音（「转写来源」选了某套发音的文字直接当音），全是元音算元音符号、全是辅音算辅音、辅音元音都有算音节，转写值本身是标点、数字的照算；没填转写值的才按字符本身分（字母、附标、私用区字形……）。自己起名的分类不动，分完提示各分了几个。从字体读取或粘贴导入的新字形也这样分 |
| 备注 | |

字形卡片按分类过滤；点卡片在检视器编辑。

### 手写板 {#glyph-pad}

画板上画着上伸线、大写高、x 高、基线（绿线）与下伸线，灰色是字身框，左右两条竖线是字的起点和字宽，右边竖线下的圆点拖着改字宽（也可以直接填「字宽」）。一个字由**笔画**（画笔画的线）和**轮廓**（填实的闭合形状：从字体载入的、用形状拉出来的）叠成。

**从字体载入**：这个字还没手写过、这套文字的内嵌字体里又有这个字时，一打开就把字体里的轮廓载进来，直接在上面改。标题旁的「从字体载入」随时重新载入，换掉画板上现在的内容（可撤销）。WOFF2 字体读不了。

| 工具 | 用法 |
|---|---|
| **画笔** | 随手画，「粗细」调线宽。「防抖」0–10，默认 5，记在本机：笔尖挂在指针后面一根绳子上走，画的时候看得到那根绳子和指针处的圈，越大线越稳、也越跟不上手；抬笔时这一笔自动顺一遍。按着拖的时候光标不会再变成「禁止」、笔画也不会断（原来浏览器自己起了一次拖拽）；笔尖划出画板还接着画 |
| **形状** | 拖出矩形、椭圆、正多边形（「边数」可调），这三种是实心轮廓；直线是一笔，用「粗细」。按住 Shift 拉正方形、正圆、45° 线 |
| **选择** | 点选或框选笔画和轮廓（Shift 加选）；拖着挪，拖右上角的方块缩放（Shift 等比）；方向键一次挪 10，Shift 一次 50；Ctrl+A 全选，Delete 删掉 |
| **节点** | 点一个轮廓或笔画显示节点：方块是线上的点，小圆是曲线控制点，拖着改形状；Delete 删掉选中的节点 |
| **橡皮** | 点到哪一笔、哪个轮廓就删哪个 |

工具下面一排操作对选中的东西生效，没选东西时对整个字（最左边写着「选中 n 个」或「整个字」）：

- 「宽」「高」按外框改大小，左下角不动，笔画粗细不变；中间的链条是「锁定宽高比」。
- 水平翻转、垂直翻转。
- 「反向」：反转轮廓走向，洞被填实了、实心变成了洞时用；笔画则把点的顺序倒过来。
- 「勾线」：把实心轮廓变成沿边一圈的笔画（空心字），粗细用「粗细」。
- 「加粗」：一键加粗，每边加粗旁边填的字体单位数（笔画变粗，轮廓往外长、洞往里缩）。
- 复制一份（往右下错开）、「删除」：要先选中。

Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做，只管画板里的操作；垃圾桶按钮「全部清掉」从头画。滚轮缩放，按住中键拖动平移，点百分比按钮还原。点「保存」才写回字形，点画板外面（或者没选东西时按 Esc）是不保存关掉。

## 4. 映射规则

规则语言与音变页相同（见[规则语言](/cerf/qonlang/sound-changes/#rule-language)），有列表视图与源代码视图。

特别之处是一行 `@glyphs`：它会展开为**由字形表自动生成的映射**，每个有转写值的字形一条 `转写 > 字符`，按转写值长度降序排列（`th` 先于 `t`，避免短的先吃掉长的）。展开结果在页面底部「自动映射」可以展开查看（右边的字形用这套文字的字体显示）。转写值里有 `?` `.` `#` `*` 这类在规则里有特殊意思的符号、或者跟音类同名的大写字母时，展开时自动在前面加反斜杠（`\? > ⸮`），按字面对应——给问号之类的标点配字形，不会把整个词都换成它。

写在 `@glyphs` **前面**的规则先执行，**后面**的规则最后执行。这就是处理各种文字类型的方法：

| 类型 | 典型写法 |
|---|---|
| 全音素 | 通常只需 `@glyphs`；多合字母给单独字形填更长的转写值即可 |
| 辅音音素（abjad） | 在 `@glyphs` 前删掉不写出的元音：`[aiu] > / C_` |
| 元音附标（abugida） | 先删辅音后的固有元音 `a > / C_`，再让其他元音映射成附标；词末无元音的辅音加去元音符号，如 `C > C◌्`（`◌` 只是示意，写实际字符） |
| 音节文字 | 每个音节一个字形并填转写（ka、ki…），最长匹配自动处理；拼合规律复杂的用下面的「音节拼合」 |
| 语素文字 | 逐词在词库的「文字写法」里手填，规则只处理能规律推导的部分 |
| 特征文字 | 先把音类映射为部件，再用规则拼合 |
| 混合 | 各部分写成不同规则段，用 `-*` 阶段快照观察中间结果 |

规则里可以引用音系页的音类与多合字母。检视器的「试写」框输入转写，按空格分词，立刻看到文字。

检视器里还有「**转写来源**」：这套文字默认按词条的**单词**转写，也可以改成某个**词干**、某套**正字法的发音**，或某个**检视器模块**（比如专门存另一种转写的那一栏）；选中的那一栏空着时回落到单词。词库的文字列、词条卡、语料里这套文字的写法都按它来。

选的是**检视器模块**时（意音文字：字形的转写填字号，每个词条在一栏里写它用哪几个字），语料、短语、文字页预览和导出里的文字行不再直接转句子，而是**逐词找到词条**——语料按分析里认的词条，没认出的按词头、屈折形找——用词条那一栏写，找不到的词照原文。词库、例句里手填的文字写法里写字号，也会换成字。

**一个词由几个语素组成时**（`naegō-moh` 这种带连字符的词，或者在语料里用「改」切分过的词），文字那一行**每一段各自写**：先看这一段自己挂的词条，再看整个词的词条认不认这一段的写法，再按这一段挂的语素的写法、这一段本身的写法去词库里找，用找到的词条那一栏写。找不到的那一段单独退回按它自己的写法转写，不影响别的段；几段全写不出来才算这个词没写出来。

「音节拼合」与「自动映射」是规则列表下面两块带标题的内容，标题右边的三角可以收起；点「新增规则」把规则列表撑高时，它们照样往下排。

### 音节拼合

规则标签下方的「音节拼合」是给 **CV / VC 音节文字**准备的另一条路：开启后不再走规则链，而是按字形读音把转写拼成音节。

**拼格是从字形表自己推出来的**：凡是读音切开正好「一个辅音 + 一个元音」（或反过来）的字形，就是一个拼格；比它更长的读音（整词、词根块）优先整块取用。因此你只要把字形的读音填对，拼合就有了。

余下几项是软件推不出来、需要你告诉它的：

| 设置 | 说明 |
|---|---|
| 消音符的读音 | 用来去掉元音或标出清音的那个字形的读音值，如 `∅` |
| 借用的元音 | 辅音后面没有元音可拼时借哪个元音，之后由消音符消掉 |
| 要标出的清音 | 空格分隔。这些辅音单独出现时读作浊音，所以要么跨两格重复出现，要么配消音符 |
| 元音 | 空格分隔，告诉软件哪些单位是元音 |
| 转写的切分单位 | 空格分隔，含二合字母，如 `th dh ch á â a e …` |
| 写法 → 字形字母 | 每行一条，如 `dh=th`、`b=p`、`ch=h`，把浊音与二合字母折成字形表里用的字母 |
| 元音写几份 | 如 `á é = 2`、`â ê = 3`，半长与全长元音在中央多写一次 |
| 长元音的基础元音 | 如 `á=a`，告诉软件带附加符号的元音本体是谁 |

拼合的逻辑是：短元音在两个拼格之间会写两次；清音跨两个拼格出现，浊音只出现一次；词首的清音与没有元音可拼的辅音配消音符；中点前的词头里，消音符与长元音标记可以省。**没填消音符**时，词尾没有元音可拼的辅音就直接写辅音本身，不再借元音——免得预览里凭空多出一个元音。

瑟乌丝林语的科飒尔文就是照语法书《书写规则》配的这一套，拿语法书里 414 个词的拼写对照，完全一致约六成，其余多是语法书按词根整词用本征音字形的情形——这类写法属于词汇信息，可以在词条的「文字写法」里手填覆盖。

## 5. 预览

「预览」子页用词库前 40 条与语料前 10 句展示转换结果，方便检查规则。

## 6. 联动

| 位置 | 表现 |
|---|---|
| 词库列表 | 「列」里勾选「文字: 名称」，多出一列，用该文字的字体显示 |
| 词库录入模式 | 「文字写法」字段可手工覆盖自动结果（语素文字、不规则写法用） |
| 词条卡 / 悬浮词卡 | 词头下方一行文字 |
| 语料 | 编辑器与列表卡片顶部一行文字；导出（莱比锡、Markdown、HTML、LaTeX）都带文字行；自定义模板用 `{{script}}` |
| 短语 | 卡片顶部一行文字 |
| 词典导出 | 词头后跟文字（可关闭） |
| 字符面板 | 「项目字符」页列出当前语言全部字形，点击即插入 |
| 皮肤 | 可以给每套文字单独指定字体（优先于文字自己的字体）；「自定义文字」字体槽是没有字体时的默认字体 |

## 7. 提示

- 想让文字**只对部分词生效**？把不想转换的词的「文字写法」填成与词头相同即可。
- 私用区（PUA）字形没有系统字体能显示，务必内嵌字体；皮肤里给文字指定的字体只在本机生效，发给别人的项目要靠内嵌。
- 字体文件较大（数 MB）时项目文件也会变大，这是有意的取舍：项目自带一切。
- 手写的字存的是笔画（几十到几百个点）和轮廓，项目文件里自带，换机器打开照样显示，不用另外带字体。想在别的软件里用，就[导出字体](#export-font)。
