# 设置

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/settings/) · 导航栏最底部

设置页从上往下是「应用（本机）」「当前项目」「数据」「关于」四块，每块里再按卡片分组。

## 1. 应用（存在数据目录，跟随本机）

**界面**

| 项 | 说明 |
|---|---|
| 界面语言 | 中文 / 繁體中文 / English / 日本語 / 한국어 / Français / Español / Русский / العربية 九种。繁體中文由简体自动转换（台湾用词）并跟着简体走，其余是逐条翻译的；个别没译到的会自动回落（繁体回落简体，其余回落英文），不会露出键名。选阿拉伯语时只有**文字本身**从右往左排（每一段按它第一个有方向的字符定，夹在里面的拉丁字母和数字照旧），导航、检视器的位置不动。选简体或繁体时各处的「使用指南」打开中文版，其余打开[英文版指南](/cerf/qonlang/en/) |
| 明暗 | 跟随系统 / 浅色 / 深色；主题的配色按这里的结果切换（这一项 0.12.1 之前叫「主题」，为了不跟[主题](/cerf/qonlang/skin/)模块重名改成了「明暗」） |
| 显示板块旁的「?」用法提示 | 各模块与检视器面板旁的小圆问号，悬浮给一句说明 |
| 点「使用指南」时每次都先看图文引导 | 默认关：每个模块的图文引导只自动讲一次，之后点「使用指南」直接打开本站；打开后每次都先讲。引导结束弹窗里的勾选项是同一个开关 |

**保存与启动**

| 项 | 说明 |
|---|---|
| 自动保存间隔 | 秒，0 关闭。另有每 5 秒的崩溃恢复快照，与此无关 |
| 保留备份份数 | 每次保存前把旧文件复制到 `Backups/`，超出份数删最旧的 |
| 启动时打开上次的项目 | |

**更新**

| 项 | 说明 |
|---|---|
| 自动检查新版本 | 打开软件几秒后问一下 GitHub 上有没有更新，之后程序开着就每隔几分钟再问一次，有新版本立刻在右下角提示；「稍后再说」之后同一个版本这次不再弹，「跳过这个版本」以后都不提示；也可以在这里整体关掉。下载与安装见下方「更新」，想马上查一次用「关于」里的「立即检查更新」 |
| 每隔几分钟检查一次新版本 | 默认 20 分钟（以前的版本默认 5 分钟、没改过的升级时改成 20），可以填 1–1440；关掉自动检查时不生效 |

**显示**

| 项 | 说明 |
|---|---|
| 词条卡里语域的显示 | 默认「方框里一个字」：中文取第一个字（`文`、`古`），英文显示缩写（`lit.`、`arch.`）；选「方框里写全称」就整个写出来 |
| 发音两边的符号 | 音位标注 `/…/`（默认）、音值标注 `[…]`，或者什么都不加；词条卡与词库的发音列都跟着变 |
| 词条下方默认显示的例句条数 | 默认 3，词条页只列这么多，其余在「查看全部例句」里看 |
| 词条下方的例句也显示文字行与出处（像语料页那样） | 默认关。开了之后每条例句上面多一行这门语言各套文字的写法，后面带上出处（见[词库 · 例句](/cerf/qonlang/lexicon/#6-例句)） |
| 高亮重复词条 | 词库里同形的词整行淡黄高亮；关掉只留警告图标 |
| 词条卡里显示历史形式 | 默认开：词源能按音变一路推到这个词时，词条卡里列出每个阶段的形式（见[词库 · 历史形式](/cerf/qonlang/lexicon/#history)）；关掉就不显示这一块 |
| 给构形推导出来的形式标齿轮 ⚙ | 词条卡里区分推导值与手填值；不想看这个标记就关掉 |

窗口与面板的尺寸（检视器宽度、词库列宽、主题选择）也记在本机偏好里，下次打开照旧。检视器的宽度默认**跟着窗口走**：主区留够语言、设置这类页面的内容宽（960），剩下的都给检视器（在 360～900 之间），窗口不太宽的时候两边正好对齐；拖了分隔条就按拖的宽，双击分隔条回到跟着窗口走；旧版本记下的宽度升级时先改回跟着窗口走一次。开始页右侧的面板不跟着变。窗口大小头一次启动时跟着屏幕走：2K 屏（2560 × 1440）上是 1853 × 920，别的屏幕宽高各按同样的比例（高分屏按系统缩放算，看上去占的地方一样大），最小 900 × 600，屏幕放不下就占满工作区。旧版本记下的比默认值小的窗口会先放大一次。

### 更新

提示框里点「下载并安装」：

1. 应用内下载安装包，不点就什么都不做。还没真正开始下载（增量更新先比对要下多少）、以及下完在核对校验码的时候显示「校验中」，真正开始下载才出进度条。**Windows 安装版只下载跟上一版不一样的部分**（小改动时通常只有一两 MB），拼好后按 Release 上的校验码整个核对；对不上、Release 上缺更新信息或者中间出错，都会自动改成下载完整安装包——装上去的一定跟 Release 上的安装包一模一样。这从装着 0.8.1 正式版之后的下一次更新开始有效；更早的版本、免安装版、本地打的包仍下载完整安装包。**macOS** 下载对应芯片的完整 zip（Apple 芯片上跑的是 Intel 版时下载原生版），下完按 GitHub 给这个文件算的 sha256 核对。每次下载是怎么走的，记在数据目录的 `update.log` 里；
2. 下好先保存当前项目（安装会关掉软件；工程文件不会被动到）：存过盘的直接存；从没存过的项目弹「另存为」，点了取消会先问「这会导致更新进度归零，继续吗？」——继续就这次不装，取消就再弹一次另存为；
3. Windows 安装版按上次的安装目录与选项**静默安装并自动重开**；免安装版（解压运行的）会弹出安装向导，由你选目录；**macOS** 解开 zip、核对是完整的新版本，退出后把原来位置上的千语集换成新的再**自动重开**（替换出错会把旧的放回去；从 0.8.3 装好之后的下一次更新起生效）。千语集放在换不了的地方——直接从 dmg 或「下载」文件夹里打开的（系统会把它挪到一个只读的临时位置）、或者所在文件夹没有写入权限——时改下 dmg 并打开，提示框写明接下来把千语集拖进「应用程序」替换，之后同[开始使用 · 安装与启动](/cerf/qonlang/getting-started/#1-安装与启动)（含 Gatekeeper 处理）；Linux 打开安装包所在目录。

检查新版本时先看 GitHub 发布页的「最新版本」跳到哪个版本，这一步不占 GitHub 接口的额度（接口不登录时每个网络出口每小时只能问 60 次，几个人共用一个代理或校园网很快就用完）。发现比当前新，才去接口拿一次安装包的校验值与更新说明；接口被限流或连不上时，按安装包的命名规则直接找本机的安装包（Windows 安装包按 `latest.yml` 里的 sha512 校验，这时提示里没有更新说明），接口会等 GitHub 说的恢复时间过了再问。提示新版本时本机的安装包还没传到 Release 上（Windows 与 macOS 的包是先后传的）的，之后再查到会换成能直接下载安装的。

## 2. 项目（存在项目文件里）

「当前项目」下面四张卡片。

**基本信息**

| 项 | 说明 |
|---|---|
| 项目名称、作者、简介 | |
| 记号符号 | [词库](/cerf/qonlang/lexicon/)里勾了「记号」的词，前面显示的符号；留空就是 `*` |

**语言与字体**

| 项 | 说明 |
|---|---|
| 默认语言 | 打开项目时的当前语言 |
| 释义语言顺序 | 逗号分隔的语言代码，如 `zh, en`。义项、维度名、语素意义等多语言文本按这个顺序显示与回落 |
| 语言数据字体 | 项目级字体（词头、IPA 等），也用于词典导出；留空用默认 |
| 词条配图尺寸 | 所有配图统一裁到这个像素尺寸（默认 320×240）；改了之后新导入的图按新尺寸处理，已有的不变 |

**分词与 gloss**

| 项 | 说明 |
|---|---|
| 语素边界符号 | 空格分隔，默认 `-` `=`；语料分词时视为显式边界。写上 `'` 时撇号也算边界，并按缩略补回省掉的元音（`t'am` = `ta` + `am`） |
| 分词方式 | 语料原文怎么切成词：**按空白**（默认）/ **逐字**（汉语式、日语式这种不用空格的表记）/ **自定义分隔符**（填一个 JS 正则，写错了退回按空白） |
| 算作字母的符号 | 写在这里的符号不会被当成标点从词两头剥掉（阿拉伯语转写里的 `'` 这类）。词库里有词以某个撇号开头或结尾时自动算上，一般不用填 |

**构形**

| 项 | 说明 |
|---|---|
| 复杂模式：维度多的槽位各写各的 | 默认不勾（简洁模式）：维度多的槽位（「极性.时.人称」）没写法时，接着维度少的那个（「极性.时」）往下变。勾上之后各算各的，维度多的那格不写就没有形式。见[构形 · 简洁模式与复杂模式](/cerf/qonlang/paradigms/#simple-mode) |

## 3. 导出为文件夹格式或一个 CSV

「数据」块里有「导出」（本节与第 5 节的纯欣赏副本）和「清空内容」两张卡片。

把项目拆成一个文件夹：`project.json`（元数据与设置）、`languages.json`、`lexemes.json`、`morphemes.json`、`paradigms.json`、`sentences.json`、`phrasebook.json`……规则集另出一份 `.txt`，文档页导出为 `docs/*.md`。适合放进 git 看 diff。文件夹也可以再导入回单文件。

「导出为一个 CSV」把整个项目放进一个表格文件：第一行是格式标记，往下一段一张表（`#table,表名,中文名` 一行开头，下一行是列名），项目信息、语言与音位、正字法、文字与字形、规则集、词类与维度、语素、词条与义项、构形、例句、短语、缩写表、文档都在里面。嵌套的内容拆成子表，用 `@parent` 列指回上一层的 `id`；列名后缀表示类型（`:opt` 可以没有、`?` 可以为空、`:num` 数字、`:bool` 真假、`:json` 复杂内容），名称、释义这类多语言文字拆成 `name.zh`、`name.en` 几列；`~` 开头的列（语言名、词类名）只是方便看。超过 30000 字的内容（内嵌字体、配图）分段放在最后的 `chunks` 表里，Excel 打开也不会截断。

在表格软件里改完（改字、加行都行，新加的行 `id` 留空会自动补），用「打开项目」选这个 `.csv` 就能读回来；读回来的是一个还没保存的项目，保存时会问存到哪。

## 4. 清空内容

挑一个模块整块清掉，方便重新导入或重新来过：词库、语素、语料、短语、文档、音变规则集、构形、词类、语法维度、检视器模块、缩写表、文字（各语言）、词条配图。下拉里带着现在的条数；点红色的「清空」会先弹窗确认，清完可以按 `Ctrl+Z` 撤销。

## 5. 纯欣赏模式

「导出纯欣赏副本」另存一份**加密的**只读项目文件（整个文件压缩后加密，拿记事本之类的软件打开只是一串乱码，改动过的文件也打不开）。别人用千语集打开这份文件时顶栏显示「纯欣赏」徽标，编辑入口收起、改动不会保存；另外：

- 另存文本、导出（词库 / 语素 CSV、词典、语料与短语的表格、规则集、文档、导出为文件夹、PDF）和「复制」结果都不做，提示条写明「内容只能在软件里看」；
- 正式版里开着纯欣赏项目时，开发者工具打不开；
- 「另存为」照样可以，存出来的仍是加密的纯欣赏副本。

适合把作品发给别人看，而不担心被改乱、被整个拿走。原文件不受影响。旧版本导出的纯欣赏副本（没加密的）照样打开，同样不能导出。

## 7. 联动提示

各页面顶部的蓝色联动提示关掉后会记在应用偏好里；想全部重新显示，删除数据目录 `prefs.json` 里的 `dismissedHints` 即可（后续版本会加按钮）。
