# 皮肤

[← 指南目录](/cerf/qonlang/) · 导航栏左下角的 T 恤图标

皮肤是**应用级设置**（存在数据目录的偏好里，不进项目文件）：配色、各处字体、字体库。检视器是实时预览：十五项颜色与七个字体槽在预览里**各有一处对应的样例**（词条卡、例句、gloss、文字、按钮、徽章、列表、代码，底部还有一排全部颜色的色块）。左边改哪一项，右边对应处就闪一下；悬停左边某项时右边描边提示。

## 1. 预设

内置六套：**默认**、**中国古代**（纸色底、朱砂强调、楷体界面）、**竹林**、**西幻**、**海蓝**、**墨夜**。每套都有浅色与深色两组配色，随「设置 → 主题」自动切换。

**自定义预设**：调好颜色和字体后点「存为我的预设」，起个名字；重名会覆盖。自定义预设卡片显示自己的配色缩略图，悬停可重命名或删除（删除可撤销）。

改了任何颜色或字体，当前预设就变成「自定义」状态；随时可以再点一个预设整体切换。

## 2. 颜色

十五项，按当前主题（浅色 / 深色）分别保存：页面背景、面板背景、凹陷背景、悬停背景、边框、强边框、文字、次要文字、弱文字、强调色、强调悬停、强调底色、强调文字、危险、警告。每项一个取色器，改过的项高亮并有重置按钮。

## 3. 字体槽

| 槽 | 影响 |
|---|---|
| 界面 | 菜单、按钮、说明文字 |
| 语言数据 | 词头、规则、IPA 等造语数据（默认 Gentium Plus，内置拉丁子集） |
| 等宽 | 规则源代码、gloss 默认 |
| 语料原文 | 例句原文与切分行、短语原文 |
| 语料译文 | 译文、文档预览正文 |
| gloss 行 | |
| 自定义文字 | 没有内嵌字体的文字的默认字体 |

每格可写多个字体名，逗号分隔作为回落链；留空用默认。输入时有已安装字体与常见系统字体的提示。

## 4. 字体库

内置 31 款 **可免费商用**（OFL / Apache）的字体目录，一键下载到数据目录（重启仍在）：

- 中文：霞鹜文楷（简 / 繁）、思源宋体、思源黑体、马善政毛笔、志莽行书、龙藏体
- **gilatod unicode**：【荏苒之境】百科标准字体，随软件一起带，点「安装」即可，不用联网
- 拉丁 / IPA：Charis SIL、Gentium Plus、Andika、Cardo
- 界面无衬线：Inter、Noto Sans、Fira Sans、IBM Plex Sans
- 正文衬线：Noto Serif、EB Garamond、Libre Baskerville、Lora、Source Serif 4、Merriweather
- 西幻风格：Cinzel、Uncial Antiqua、MedievalSharp
- 文字：Noto Sans Runic、Noto Sans Old Turkic、Noto Sans Symbols 2
- 等宽：JetBrains Mono、Fira Code、Noto Sans Mono

下载有进度显示；国内网络可以填一个 GitHub 加速前缀（如 `https://ghfast.top/`）。也可以**从本地文件添加**自己的字体（TTF / OTF / WOFF / WOFF2），软件会读出字体家族名注册。已安装的字体名直接填进字体槽即可。

## 5. 与其他模块的关系

- **文字**页内嵌了字体的文字不受皮肤影响；没内嵌的用「自定义文字」槽。
- **设置 → 语言数据字体**是项目级的（跟项目走），皮肤的「语言数据」槽是应用级的；两者都填时项目设置优先。
- 词典导出的字体用项目设置里的语言数据字体。
