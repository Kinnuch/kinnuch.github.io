# 主题

[← 指南目录](/cerf/qonlang/) · [English](/cerf/qonlang/en/skin/) · 导航栏左下角的 T 恤图标

主题是**应用级设置**（存在数据目录的偏好里，不进项目文件）：配色、背景图、各处字体、字体库。检视器是实时预览：十五项颜色与七个字体槽在预览里**各有一处对应的样例**（词条卡、例句、gloss、文字、按钮、徽章、列表、代码，底部还有一排全部颜色的色块）。例句取自当前项目语料里第一句分析好的（当前语言优先），原文、切分、gloss、译文、文字行都是这一句的；没有例句时用内置示例。左边改哪一项，右边对应处就闪一下；悬停左边某项时右边描边提示。

## 1. 预设

内置十套，排成两行，名字是「品名·颜色」：

- 第一行：**亚夜花园·青**（默认的样子，原「默认」）、**林中幻想·绿**（原「竹林」）、**契耶西塔·紫**（原「西幻」）、**海岛诺连·靛**（偏蓝的靛色，比契耶西塔冷）、**蓝地渐歌·蓝**（原「海蓝」）。
- 第二行：**星月夜·黑**（原「墨夜」；蓝黑的夜空，整个窗口撒着淡淡的黄、蓝星点，深色主题下强调色是星星的黄）、**山海经·褐**（原「中国古代」；纸色底、褐色强调、楷体界面）、**梅珠撒·红**（红白两色）、**瓦其夫·黄**（深藏青底、金黄强调、警告用红；浅色主题是米色底、藏青字）、**雪利兹·橙**（暖白底上的柔和橙色）。

每套都有浅色与深色两组配色，随「设置 → 主题」自动切换；以前选好的预设照样生效。强调色特别亮的几套，主按钮上用深色字。点一个预设时，新配色从点的地方像墨水一样晕开（系统设了减少动态效果时直接换）。

**导出 / 导入**：「导出皮肤」把当前这套存成一个 `.qonlang-skin.json`（配色、字体、给各套文字指定的字体都在里面）；有背景图时旁边会出现「带上背景图」的勾选框，**默认不带**——一张图几 MB，会整个塞进文件。「导入皮肤」选好文件后**先整窗试看**：界面和预览卡当场变成导入后的样子，上方出现一条「正在试看…套用 / 取消」，点「套用」才存下来；没确认就离开主题页会自动还原。认不出记号的文件会说「这不是皮肤文件」，来自更新版本的也会说清楚。

**自定义预设**：调好颜色和字体后点「存为我的预设」，起个名字；重名会覆盖。自己存的预设排在第三行，卡片显示自己的配色缩略图，悬停可重命名或删除（删除可撤销）。

改了任何颜色或字体，当前预设就变成「自定义」状态；随时可以再点一个预设整体切换。

## 2. 背景图

「选择图片」（点缩略图或按钮都行）挑一张图，盖在整个窗口上：半透明，不挡任何点击；浅色主题下跟页面正片叠底，深色主题下滤色，字始终看得清。

| 项 | 说明 |
|---|---|
| 铺法 | 铺满 / 完整显示 / 平铺 / 居中 / 拉伸 |
| 对齐 | 居中 / 靠上 / 靠下 / 靠左 / 靠右；「完整显示」「平铺」「居中」时出现 |
| 不透明度 | 0–100%，默认 18% |
| 缩放 | 5–300%，用于「平铺」「居中」 |
| 模糊 | 0–30px |

「换一张」换图，「移除背景图」去掉。图片的长边缩到最多 2400 像素，存在本机偏好里，不进项目文件；切换预设、「恢复默认」都不会去掉背景图。

## 3. 颜色

十五项，按当前主题（浅色 / 深色）分别保存：页面背景、面板背景、凹陷背景、悬停背景、边框、强边框、文字、次要文字、弱文字、强调色、强调悬停、强调底色、强调文字、危险、警告。每项一个取色器，改过的项高亮并有重置按钮。

## 4. 字体槽

| 槽 | 影响 |
|---|---|
| 界面 | 菜单、按钮、说明文字 |
| 语言数据 | 词头、规则、IPA 等造语数据（默认 Gentium Plus，内置拉丁子集） |
| 等宽 | 规则源代码、gloss 默认 |
| 语料原文 | 例句原文与切分行、短语原文 |
| 语料译文 | 译文、文档预览正文 |
| gloss 行 | |
| 自定义文字 | 没有内嵌字体的文字的默认字体 |

每格可写多个字体名，逗号分隔作为回落链；留空用默认。输入时有已安装字体与常见系统字体的提示。

### 每套文字的字体

打开了项目时，字体槽下方还会列出项目里的每套自定义文字（「名称（语言）」），可以给它们单独指定字体：导入了字体文件、或从字体库装好字体后在这里选，字形表、检视器、词库、语料里这套文字都会换过来。这里的选择优先于文字页给文字设的字体（包括内嵌字体），存在本机偏好里、不进项目文件；留空就用文字自己的字体。

## 5. 词条卡

词库检视器里那张只读的词条卡，样子在这里调，改完马上生效（存在本机偏好里，不进项目文件）：

- **每一块的字号**：列表里每一块（词头与发音、义项、标签、词源、历史形式、词干、屈折形、关系、派生词、备注）右边一个滑块，直接是像素（10–30，默认 15，调过的数字显示成主色）；这一块里大大小小的字按原来的比例一起变。「词头与发音」固定在最上面，只调字号、不参与排序。0.8.0 设过的倍数打开时自动换算成字号。
- **各块顺序**：义项、标签、词源、历史形式、词干、屈折形、关系、派生词、备注这九块，按住整行往上下拖就换位置（按在滑块上拖只调字号，不会拖动这一行），鼠标放上去会描一圈虚线；「恢复默认」把顺序与字号都还原。
- **预览**：右边检视器的预览里有一张真的词条卡（用项目里义项、词源、屈折形、关系这些填得最全的一个词；项目里还没有词条时用内置示例），字号、顺序一改马上看到；鼠标放在左边哪一行，预览卡里描一圈虚线标出那一块（这个词没有这一块内容时没有框）；开始拖动或调滑块时预览卡会滚进视野。
- 自己加的**检视器模块**不在这张表里——它们按各自的「位置」跟着义项、词源走（见[词库](/cerf/qonlang/lexicon/)）。

## 6. 字体库

内置 31 款 **可免费商用**（OFL / Apache）的字体目录，一键下载到数据目录（重启仍在）。每款后面跟一行**预览**：拉丁字体写 `The quick brown fox jumps over the lazy dog`，中日韩字体后面再带四个笔画全的汉字，卢恩、古突厥文这类没有拉丁字形的文字写的是同一句话的转写，符号字体摆一排常用符号。**这一行一直用这款字体本身显示**——随软件带了每款字体的一小块子集（只含预览这一行用到的字，一款几 KB），所以还没下载也看得到它真正的样子；装好之后换成装的那一整套。有通行中文名的字体，中文名用灰字排在英文名下面。

- 中文：霞鹜文楷（简 / 繁）、思源宋体、思源黑体、马善政毛笔、志莽行书、龙藏体
- **gilatod unicode**：【荏苒之境】百科标准字体，随软件一起带，点「安装」即可，不用联网
- 拉丁 / IPA：Charis SIL、Gentium Plus、Andika、Cardo
- 界面无衬线：Inter、Noto Sans、Fira Sans、IBM Plex Sans
- 正文衬线：Noto Serif、EB Garamond、Libre Baskerville、Lora、Source Serif 4、Merriweather
- 西幻风格：Cinzel、Uncial Antiqua、MedievalSharp
- 文字：Noto Sans Runic、Noto Sans Old Turkic、Noto Sans Symbols 2
- 等宽：JetBrains Mono、Fira Code、Noto Sans Mono

下载有进度显示；国内网络可以填一个 GitHub 加速前缀（如 `https://ghfast.top/`）。也可以**从本地文件添加**自己的字体（TTF / OTF / WOFF / WOFF2），软件会读出字体家族名注册。已安装的字体名直接填进字体槽即可。

## 7. 与其他模块的关系

- **文字**：主题里给某套文字指定了字体就用它；没指定时用文字页里设的字体（系统字体名或内嵌字体），都没有再用「自定义文字」槽。
- **设置 → 语言数据字体**是项目级的（跟项目走），主题的「语言数据」槽是应用级的；两者都填时项目设置优先。
- 词典导出的字体用项目设置里的语言数据字体。
