# M1 单人版实装说明（与审核定稿的差异清单）

> M1 目标是核心循环可玩。以下简化项将在 M2（全量内容）中按审核文档精确实装。

## 已实装

- 8 人对局（你 + 7 AI），完整回合流程：1-1 发牌 → 1-2~1-4 野怪 → 每阶段 3 场对战 / X-4 发牌 / 2 场对战 / X-7 野怪。
- 经济全套：回合收入、利息、连胜连败奖励、胜利金币；商店概率表、卡池张数、2 金币刷新、4 金币买经验、锁定。
- 六维亲和度 → 派生属性、升星（主×1.6/其他×1.2/HP×1.8）、3 合 1 合成、人口=等级。
- 战斗引擎：固定 0.1s 步长确定性模拟（同种子必然同结果，为 M3 联机铺路）、六边形寻路、四系伤害与光暗相克（×1.2/×0.8）、护甲/双抗减免、暴击（15%/150%）、护盾、吸血、韧性减控、法力（攻击+10/受击按公式）、破法、45 秒加时与双败。
- 状态效果：灼烧、重伤、冰冷、眩晕、缴械、嘲讽、不可选取、免控。
- **25 个棋子**全技能：1费 格里什纳赫/杜伊林/古斯拉夫/梅里/法拉米尔/卡哈洛斯/埃伦玛奇尔/可哈穆尔；2费 吉姆利/加尔多/皮聘/索伦之口/希奥顿/波洛米尔；3费 图奥/山姆/勾斯魔格/洛格/安格玛巫王；4费 格洛芬德尔/安卡拉刚/图林/弗罗多；5费 都林（含传承被动）/魔苟斯（含黑星风暴与堕落爱努汲取）。
- 羁绊运行时：诺多（光明装分发）、刚多林（击杀冲刺+易伤）、魔多（邪黑塔）、洛希尔（移速转攻+击退）、霍比特（败北骰子）、杜内丹、人类（永久击杀成长）、哈多、矮人（减伤+交界装备）、安格班（偷取）、战士、掌旗官（专属加成池）、盾骑兵、游侠（叠攻速）、冒险家、重创之手（恰好1/4处决）。
- 装备：19 散件 + 全部 135 种成装配方名称 + 自适应属性 + 约 30 件成装特效 + 9 件光明装特效；点击穿戴、散件自动合成。
- 野怪 6 类波次（食人妖回满血、座狼攻速、冷龙/炎魔 AOE 特性）与按阶段掉落、袋子开箱。
- 战斗回放 UI：移动/弹道/飘字/施法特效/护盾提示/倍速/跳过；拖拽布阵、出售、锁店；羁绊面板、战报、玩家列表。

## 本地运行

ES 模块需要 http 协议：仓库根目录运行任意静态服务器（如 `python -m http.server` 或 VSCode Live Server），访问 `/gell/EPT/`；或推送后经 GitHub Pages 访问。
开发参数：`?auto=1` 跳过大厅自动开局，`&seed=N` 固定随机种子（复盘用），`&fight=1` 自动开战。
