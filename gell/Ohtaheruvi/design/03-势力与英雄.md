# Ohtaheruvi · 势力、英雄与神器

> 力量值（1~9）决定英雄的战斗强度与统率加成（4~6 → 统率 +1；7~8 → +2；9 → +3）。
> 英雄的取舍与力量标定是全文档最需要你把关的部分。

## 〇、君主英雄制（对原作的一处调整）

原作的英雄全靠随机求聘。但精灵宝钻的势力是**有王的**，所以：

- 每势力有一名**君主英雄**，开局即在都城，不占雇佣名额、不会拒绝你。
- 君主阵亡：该势力全部城市防御 −1、当回合起 3 回合内不再触发英雄求聘（「王陨之丧」），然后由名录中的**继位者**免费继任。
- 其余英雄按名录顺序随机求聘（1/6 概率/回合，酬金 = 力量 × 30）。
- 正典英雄死亡即永久离场，名录耗尽后改为无名领主（力量 4~6，程序生成名字）。

## 四、【待裁决】

- 势力名单（尤其第一纪元把法拉斯与蓝山矮人算作独立方）是否合意？备选：拿掉法拉斯，换成「东来者（乌方格与乌勒多之民）」作为第二黑暗方，这样泪雨之战的背叛可以做成机制。
- 每位英雄的力量值请逐个过目——这是最容易引战也最影响手感的一张表。
- 「三戒」和「君主不可移动」这两条是我加的，原作没有对应物。
- 各势力名与地名的**精灵语拼写**（Barad Eithel / Himring / Menegroth / Eglarest / Belegost / Angband…）以及是否在 UI 中双语显示，等你定。
