# Ohtaheruvi · 美术与界面

> 目标：**Warlords Classic HD 的风格与质感，精细度提到当代水平**。参照 Warbarons 的信息布局，但不要它那种偏干净的现代扁平感。

## 一、视觉定调

Warlords HD 的质感可以拆成四条可执行的规则：

1. **厚涂手绘、暖调、低饱和**。地形像一幅摊开的旧地图上又压了一层水彩，不是像素画也不是矢量扁平。
2. **深色描边**。每块地形、每个单位、每座城市都有一圈深褐色的收边，这是那种「棋盘感」的来源，也是让高密度信息不糊掉的关键。
3. **正俯视 45° 的建筑**。地形是正俯视，但城市、森林、山脉的**立绘略带正面视角**（山有阳面阴面，塔有侧墙），这是老 Warlords 最标志性的一点，比纯俯视好认得多。
4. **UI 是物理材质**：羊皮纸底、皮革包边、青铜铆钉、烫金字。面板是「被放在桌上的东西」，不是浮层。

现代化的部分只加在**精细度**上，不加在风格上：更高分辨率的笔触、更细的地形过渡、柔和的方向光与投影、动态的水面与旗帜——但**不加**发光特效、不加渐变玻璃、不加粒子。

## 二、瓦片体系

- **基准格 48 CSS px**（缩放档 24 / 32 / 48 / 64 / 96）。素材按 96px 绘制，按 `devicePixelRatio` 选 1x/2x，缩小采样比放大干净。
- **自动拼接（autotiling）**：海岸线、森林边缘、山脉边缘、道路、河流各用一套 **47 格 blob 位掩码**，保证任意形状的边界都自然。这是「现代精细度」最划算的一笔投入——没有它，再好的笔触也会露出方格。
  - **已实装于 `js/tiles.js`**，但不是图集：位掩码算出来后**用路径实时画**——四条边与同类邻格相连时顶到格子边界，四个角两侧都相连就是直角、否则倒圆角。这样一个二进制素材都不用，也就彻底绕开了版权红线。
  - 一个实现上的坑：填充路径若直接 `stroke()`，两个相邻同类格会在交界处各画一条线，色块内部就横七竖八全是接缝。必须**填充与描边分两趟**，描边只画没有同类邻格的那几条边和外凸的圆角。
- **变体**：每类地形 4 个随机变体，用格子坐标做确定性哈希选取（保证存档回放一致）。
- **地物层**：城市（2×2，按规模四种立绘 × 八势力旗帜）、遗迹、祭坛、先知之所、桥、港口、关隘标记。
  - **四级城市的形制各不相同**：村镇是没有围墙的一撮屋舍；城有墙与一座居中角楼；大城有墙与两侧角楼；都城四角带楼、中央另有主堡，旗杆也更高。城名后缀规模（「米斯林·大城」）。
  - **道路按邻接方向绘制**（路口与拐弯都能画对），**桥画在浅滩格上**、朝向随相邻道路，一眼能看出河上唯一的通道在哪。
  - **驻军徽章画在城池右下角**，不遮挡城市立绘。
- **氛围层**（可关）：海面 3 帧循环、城市炊烟、旗帜摆动、战场遗留的乌鸦。都是低频 2~4 帧，成本极低但「活」。

## 三、单位与军团的呈现

**关键决策：格子上不画 8 个小人，画一枚「军团徽章」。**

```
┌──────────┐
│  ╭────╮  │  ← 势力色圆环 + 纹章缺口
│  │肖像│8 │  ← 堆叠内最强单位的肖像；右上角数字 = 堆叠数量
│  ╰────╯  │
│ ♔ ▮▮▮▮   │  ← 有英雄则显示金冠；下方为剩余移动点条
└──────────┘
```

- 点击军团 → 底部展开**队列条**：8 个槽位横排，显示每个单位的肖像、强度、耐久点、是否受祝福，可拖拽调整出战顺序、可拖出单位分队。
- 悬停/长按任一单位 → 浮出完整数值卡（强度、修正来源逐条列出：地形 +2、统率 +2、城防 +1……）。**把战斗修正的来源摊开给玩家看**，这是原作没做好而现代玩家一定要的。
- 单位肖像：52 × 52 圆形，手绘半身像，深描边。26 + 26 个兵种 + 76 名英雄 ≈ 128 张肖像（英雄用兵种底图 + 个性化重绘）。

## 四、界面布局（iPad 横屏优先）

```
┌────────────────────────────────────────────────────────────┐
│ 回合 12 · 希斯路姆   金库 340 (+62/−48)   ⚙ 速度 ▸  [结束回合]│
├──────────┬──────────────────────────────────┬──────────────┤
│ 小地图    │                                  │ 城市：米斯林  │
│ (势力着色)│                                  │ 规模 大城     │
├──────────┤          主 地 图                 │ 防御 6        │
│ 选中军团  │      (Canvas，可拖可缩)           │ 生产 ▾ 骑兵   │
│ 8 槽队列  │                                  │ 进度 ▮▮▯ 2/3  │
│          │                                  │ 投送 → 巴拉德 │
├──────────┤                                  ├──────────────┤
│ 英雄与神器│                                  │ 生产总览      │
├──────────┴──────────────────────────────────┴──────────────┤
│ 战报 / 日志（可收起抽屉）                                     │
└────────────────────────────────────────────────────────────┘
```

- **手机竖屏**：地图全屏，左右面板收为两个抽屉按钮，底部保留队列条。
- **必做的报表**（HD 版被夸的就是这个）：生产总览（所有城市在产什么、几回合完成、投送去向，一屏看完并可直接在表里改）、军力对比（八方的城市数/单位数/收入曲线）、战史（每场战斗的完整逐次决斗记录）。
- **交互**：单指拖拽平移，双指缩放，点选军团 → 高亮可达格（按移动点着色：本回合可达/两回合可达），点目标格移动，点敌方格发起战斗前先弹**战前预估**（双方 MS 与胜率区间，胜率由 5000 次蒙特卡洛模拟即时算出，几毫秒的事）。
- **键盘**（桌面）：`空格` 跳过动画 / 结束回合，`Tab` 循环未行动军团，`E` 打开生产总览，`1~8` 快速选中队列位。

## 五、动画与音

- 移动：每格 90ms 缓动，路径上留下短暂的足迹虚线。
- 战斗：两侧肖像对冲，命中时对方耐久点熄灭一颗并抖动；单场战斗封顶 2.5 秒，可一键跳过。
- 攻城：城市立绘上叠加破损贴图并腾起烟尘。
- 音（M4，可选且默认音量低）：环境（风、海、林）、行军、金属交击、城破。原版音乐不能用，需另找 CC 授权的中世纪/凯尔特配乐或自制。

## 六、性能

- 地形绘在**离屏 canvas** 上，只在缩放或地形变更（如阿德加兰焦土化）时重绘；每帧只 `drawImage` 可视区域。
- 单位与 UI 在上层 canvas，按脏矩形重绘。
- 视口裁剪：只处理可见格 ±2。
- 目标：iPad 上 140×110 地图、8 方满编（约 300 单位）稳定 60fps；AI 单回合逻辑 < 1.5s。
- 素材总量控制在 **6 MB 以内**（PNG 走 `oxipng`/`pngquant`，肖像用 WebP 带 PNG 兜底）。

## 七、素材来源与版权红线

**红线：不得直接使用 Warlords / Warlords Classic HD 的任何原始素材**（地形图、单位图、肖像、音乐、字体），也不得从截图上抠图或做「描图」级的临摹。我们复刻的是**规则与信息架构**——规则不受版权保护，美术受。所以美术全部另起炉灶。

允许的来源：
- **自绘**（主体）：地形、城市、单位肖像、UI 框架。工作流为 SVG/矢量绘制 → 烘焙 PNG 图集。
- **game-icons.net**（CC BY 3.0，作者 Lorc / Delapouite / Willdabeast / sbed）：UI 小图标与部分兵种符号。EPT 已在用，署名方式沿用其页脚写法。
- **公有领域素材**：19 世纪版画、古地图纹理可作笔刷与底纹。
- **中土世界观本身**：托尔金作品的设定受版权保护，本项目为**非商业同人**，不得售卖、不得投放广告、页面需注明「非官方同人作品，与 Tolkien Estate 及 Middle-earth Enterprises 无关」。

## 八、【待裁决】

- 基准格 48px 与「军团徽章而非画 8 个人」这两条，决定了整个视觉密度，请优先确认。
- 你要的「精细度提到当代水平」我理解为**笔触与过渡的精细**，而非改变画风（不做写实光照、不做 3D）。若你其实想要 EPT 那样的 2.5D 倾斜视角，现在说，这会改变整个渲染架构。
- ~~128 张肖像是最大的一笔工作量~~ —— 最终没有手绘，改为 **`js/portraits.js` 程序化生成**：按族裔与兵种类型选一个原型（头盔／弓／马首／龙头／炎魔角／骷髅／船帆／翼／兽首），套上兵种色板画成圆形剪影，按「类型+尺寸」缓存。加新兵种不用画图，给对 tags 就有肖像。
- 音效同理：`js/sound.js` 用 WebAudio 现场合成，不加载音频文件。原版音乐本来就不能用，而回合制需要的也只是几声短促反馈。
